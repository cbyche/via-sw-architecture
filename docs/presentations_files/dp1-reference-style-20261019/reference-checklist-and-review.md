# DP1 레퍼런스 제작 원칙과 평가

2026-10-19

이 체크리스트는 사용자가 제공한 비교 장과 선택 보완 장을 직접 대조하여 정리했다. 선택 보완 장은 비교판의 대안과 배치를 유지하고, 선택한 열 안에서 구조 변경과 QA 변화가 연결되도록 만든다. 상세한 보완 실험 설명은 4장에 둔다.

## 레퍼런스에서 확인한 원칙

- **23 DP04 방안과 24 DP04 채택:** 같은 대안과 행을 유지한다. 선택한 열 전체를 파란 선으로 둘러싸고 빨간 체크를 추가한다. 변경된 내부 처리, 단점 아래 보완 문구, 해당 QA의 전후 값을 파란색으로 연결한다.
- **18 DP02 채택:** 선택한 구조 안에 추가한 Data Module과 Shared Memory를 표시하고, 처리시간의 개선과 메모리 증가를 함께 남긴다.
- **적용 범위:** 색, 표의 반복, 선택 강조, 구조와 QA의 연결 원칙을 따른다. 레퍼런스의 측정값과 점수는 VIA에 옮기지 않는다.

### 검토 중 발견해 수정한 사항

1. C의 게시 근거 연결선과 `현재 요청`, `원본으로 보완` 문구가 겹쳤다. 선과 문구를 분리했다.
2. A의 보완이 다음 요청에만 반영되는 것으로 읽힐 수 있었다. 현재 Request Interpreter로 보완 근거가 반환되는 화살표를 추가하고, 채택 후 문맥 갱신 경로와 구분했다.
3. 시간값의 괄호가 성공률로 오해될 수 있었다. `시간 괄호: 관측/예정 건수`를 추가했다.

시각 검토와 설계·수치 검토를 별도로 수행했고, 수정 후 두 검토에서 추가 수정 사항이 보고되지 않았다.

### 확인 범위와 한계

- 원격 모델의 제한된 기존 PoC 수치를 보존했다. 이번 작업에서 새 측정이나 모델 실행을 수행하지 않았다.
- A2는 정정 사례에서 재조회 감소를 확인한 보완 후보다. 전체 비교의 QA03을 21.433초로 대체하지 않으며 C 대비 격차 해소도 주장하지 않는다.
- PowerPoint 패키지 구조, 편집 개체, 렌더와 재가져오기를 확인했다. Microsoft PowerPoint 앱에서 직접 렌더링한 결과까지 확인한 것은 아니다.
- 4장은 사용자 요청에 따라 이전 상세 장을 보존했다. 현재 요청의 보완 왕복을 포함한 최신 상세 흐름은 2·3장에 표현했다.

## 수치 표시 규칙

- QA03 기본 전체 비교는 A 13.617초, B 14.242초, C 12.364초를 유지한다.
- A2의 전후 값은 **정정 사례 3회 별도 비교 21.822→21.433초**로 표시한다. 13.617→21.433초로 연결하지 않는다.
- A2는 원본 읽기 12→9회, 모델 호출 12→12회, 본문 충족 3/6 동일이다. 큰 지연 개선이나 C 대비 격차 해소를 입증한 값으로 쓰지 않는다.
- 공통 첫 안내 정책의 별도 비교와 추가 비용은 기존 상세 장을 옮긴 4장에서 설명한다. A2와의 결합 효과는 미측정이다.
