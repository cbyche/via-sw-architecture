# 설계 문제 지도와 DP 배경 검수 기록

## 45의 필요성과 여러 활동 참조 사례 — 2026-10-09

사용자가 전달한 Senior SW Architect 지적에 따라 기존 표현 방식 사례를 대표에서 내렸다. 새 사례는 VIA 직접 설명 E20의 실제 전달 P20, 제품 비교 T21/D21@v2, 견적 T22/D22@v1을 현재 제안서 요청 R23에 연결한다. ID는 [45 본문 §3.1](../../architecture/12-decisions/decision-packages/04-45-memory-and-context.md#31-그림-한-장의-발표-순서)의 공통 정의를 따른다. VIA는 발췌/참조를 연결하고 기준 적용과 제안서 작성은 Agent가 수행한다. 기존 실행 맥락 재사용과 A의 작은 index/cache로 충분할 수 있음을 인정한다. 기존 A/B와 비용, 미선정/미측정 상태 및 예상 수치는 유지한다.

이전 독립 리뷰는 당시 판본의 이력이다. 이번 수정은 그 지적을 전달받아 수행한 자료 보완과 작성자 검수이며 새 독립 심사나 품질 측정이 아니다.

- 배경은 실선 시간 흐름과 점선 과거 참조를 구별하며 Component/저장소를 답으로 미리 제시하지 않는다. 전체 지도에서는 45 위험 설명만 맞췄다.
- MAIN/수명과 발표 비교를 실제 렌더하고 사례/책임/선 방향을 대조했다. 문자 겹침과 폭/범위 초과는 0건이다. MAIN의 제목 관통 배선은 연결을 유지하며 보완했다.
- 세 PPTX의 10/5/5장, native 편집 객체와 0개 이미지, notes, package/layout 및 재가져오기 렌더를 확인했다. `--dp45-only`는 통합 9/10번, 배경 5번, 비교 5번 및 해당 notes/관계만 갱신했다. PowerPoint 앱 검증은 아니다.
- 다른 슬라이드와 공통 package 부분, 모음 draw.io의 41~44 페이지, 개별 원본/PNG 및 초기 04-50/work 변경을 작업 시작본과 대조해 보존했다. 생성기 일치/활성 링크/용어/QA/diff 검사를 통과했다.

공통 파생 관계 계약의 필요성, 실제 품질 이익과 최종 DP/A/B 판단은 원래 리뷰 세션에서 계속한다. 상세 검수는 [45 기록](../../architecture/12-decisions/decision-packages/04-45-memory-and-context-review.md)을 따른다.

검수일: 2026-10-06. [작성 가이드](./README.md#발표-용어와-배경-페이지-작성-기준)에 따라 배경 세 장을 재작성하고 두 독립 리뷰를 수행했다. 42는 사용자가 잠정 완료한 현재 버전을 함께 게시한다.

## 검수 범위와 리뷰 방법

- **설계 문서 대조 리뷰:** 독립 리뷰 담당 `background_review`가 43, 44, 45의 현행 비교 문서와 실제 PNG를 대조했다. 공통 기능, 의미 및 실행 경계와 대안 중립성을 확인했다.
- **심사위원 읽기 리뷰:** 독립 리뷰 담당 `jury_readability`가 원문과 생성기를 읽지 않고 PNG만 확인했다. 각 장의 사용자 상황, 핵심 문제와 SW 구조를 고민할 이유를 설명하고 모호성과 누락을 지적했다.

- 실제 심사위원 대상 이해도 실험, 구현 또는 QA 성능 측정은 아니다. 기존 대안, 우열 미확정과 미측정 상태를 유지한다.

- 모든 배경은 1920×1080의 편집 가능한 native draw.io, 같은 장면의 SVG와 PNG다. 통합 draw.io는 다섯 페이지이며 셀 ID는 페이지별로 유일하다.
- 최종 PNG의 텍스트 경계, 선언 폭과 텍스트 간 겹침 검사는 세 장 모두 문제 0건이다. 선, 문서 실루엣, 색과 시간 관계는 실제 이미지로 확인했다.
- 배경 생성기 `--check`, 현행 용어 및 Markdown 링크, QA 카탈로그와 기존 CI 도식 생성기 검사, `git diff --check`를 수행했다.
- 43~45 작업 시작 시점의 41과 42 배경 파일 및 43~45의 비교 그림 24개 파일을 바이트 수준으로 보전했다. 43~45의 배경 이후 비교 본문도 그대로 유지했다. 42 변경은 이전 사용자 검토의 잠정 완료본이며 이번 commit에 포함한다.
- 참조 Architecture, QA/ADR, 기존 비교 대안과 구현 및 측정 상태를 변경하지 않았다.

## 사용자 경험 도입과 본 발표 흐름 — 2026-10-09

이번 기록은 사용자가 지정한 도입·발표 순서 수정의 원본 대조와 렌더 검증이다. 새로운 독립 Architecture 리뷰나 실제 심사·성능 검증을 수행했다는 기록이 아니다. 이전 리뷰 표와 판정은 당시 이력으로 보존한다.

- 기존 `dp-background-overview`를 하나의 제안서·공유 메일 장면으로 교체했다. 직접 설명의 실제 전달, 제품 조사·견적의 확인된 결과 참조, 표의 대상과 초안 조건, 처리 중 정정·메일 질문·늦은 후보, 과거 정보 재사용과 서로 다른 종료 시점을 표현한다.
- VIA는 상호작용·요청 이해·업무/정보 연결·위임·결과 전달, 외부 Agent는 도메인 분석·계획·도구 선택·업무 실행을 담당한다. Agent에서 사용자로 직접 전달하는 선은 없다. 외부 접수 확인 후 위임 요청 처리 완료와 업무 완료를 구별하고, 음성 종료를 Task 취소로 표현하지 않는다.
- 도입의 보이는 문구에 DP 번호·A/B 이름·다섯 문제 표가 없고 Component·Module·저장소 기호나 살구색 차이 강조를 사용하지 않는다. 실선 전달·점선 과거 참조·가로 진행 구간의 범례와 실제 선을 대조했다. 구간 위치와 길이는 설명용이다.
- SVG와 draw.io는 기존 장면 생성 원본에서 재생성했고 PNG는 같은 SVG의 1920×1080 Chrome 렌더다. 최종 도입의 글자 선언 폭·화면 경계·텍스트 간 겹침 검사 0건. 실제 이미지에서 선 방향·참조의 도착점·설명 글자 관통 여부를 확인하고 접수 확인 라벨 주변을 조정했다.
- 웹은 실제 Chrome에서 모든 이미지 로딩과 가로 넘침 없음, 도입 → 41 → 44 → 45 → 42 → 보충 43 순서를 확인했다. 도입 포함 draw.io도 같은 순서이며 개별 DP 페이지의 셀 내용은 보존했다. 번호순 배경·비교 참조 자료는 유지했다.
- 통합 PPTX는 본 발표 9장과 43 부록 2장으로 총 11장이다. native PowerPoint section으로도 구분한다. 도입은 텍스트 68줄·도형 113개·경로 42개, 이미지 개체 0개로 편집 가능하다. 같은 도입 대본과 첫 주제 연결을 첫 장 노트에, 세 전환을 41·44·45 비교 장의 기존 노트 뒤에 넣었다.
- PPTX package 무결성·16:9 크기·원본 텍스트·노트·native 개체 검사와 Artifact Tool 재가져오기를 통과했다. 최종 11장 전체를 렌더했고 개별 장을 확인했다. **기존 DP 10장의 슬라이드 XML 및 렌더 PNG가 시작본과 바이트 수준으로 동일**하다. 43의 슬라이드·노트, 다른 DP 노트와 공통 package도 필요한 순서/장 추가/section/count 부분 외에는 보존했다. 배경·비교 전용 PPTX의 전체 파일 해시도 시작본과 같다.
- scoped 선택은 DP 번호와 배경/비교 종류로 계산하고 실제 scene 이름·presentation 관계로 part를 찾는다. `--dp41-42-only`, `--dp44-only`, `--dp45-only`, `--comparison-only`, 45 비교 subset 및 도입 재실행을 물리 part 번호가 달라진 후보에서 검사했다. 일반 10건 + subset 9건, 총 19건이 지정한 DP 도형·노트만 바꾸거나 도입 재실행을 그대로 유지했다.
- 배경 및 비교 생성기 `--check`, active Markdown 링크(151문서)·용어·QA 검사, `git diff --check`를 통과했다. 개별 41~45 본문·그림·비교 값, 참조 Architecture·QA·ADR, 시작 시 별도 미커밋 04-50과 `work/` 해시는 보존한다. 설명 순서 변경은 선정·품질 우위·후보 자격의 변경이 아니다.

검증 한계: Microsoft PowerPoint 앱에서 직접 실행한 검사는 아니다. 기존 44 비교의 텍스트 프레임 겹침 경고와 45 비교의 경계 밖 개체 경고 2건은 시작본에도 있었으며, 이번 도입에는 새 경고가 없다. 개별 DP 내용 수정 금지 범위에 따라 기존 경고를 그대로 보존했다. 가독성은 실제 렌더로 확인했으며 발표 대본의 45~60초는 읽기 속도에 따른 예상이다.
