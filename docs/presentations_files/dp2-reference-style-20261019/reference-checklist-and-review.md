# DP2 레퍼런스 제작 원칙과 평가

2026-10-19

DP1 v3에서 사용한 R01~R16 체크리스트를 유지했다. 대안 수와 선택안, 보완안에 해당하는 내용만 DP2의 A/B 비교와 B+B1에 맞게 바꿨다. 선택 및 보완 장은 비교 장 전체를 반복하고, 선택한 B 열 안에서 구조 변경과 QA06의 전후 값을 연결한다.

## 레퍼런스에서 확인한 원칙

- **23 DP04 방안과 24 DP04 채택:** 같은 대안과 행을 유지한다. 선택한 열 전체를 파란 선으로 둘러싸고 빨간 체크를 추가한다. 변경된 내부 처리, 단점 아래 보완 문구, 해당 QA의 전후 값을 파란색으로 연결한다.
- **18 DP02 채택:** 선택한 구조 안에 보완 내용을 표시하고, 개선과 추가 비용을 함께 남긴다.
- **DP1 v3:** 배경은 문제상황과 설계 질문을 먼저 보여준다. 비교 장의 SW 구성요소와 구조 차이를 명시하고, 상세한 보완 설명은 4장에 둔다.
- **적용 범위:** 색, 표의 반복, 선택 강조, 구조와 QA의 연결 원칙을 따른다. 레퍼런스의 측정값과 점수는 VIA에 옮기지 않는다.

### 검토 중 발견해 수정한 사항

1. Request Controller가 의미 판단과 재결합을 직접 하는 것으로 읽힐 수 있는 문구를 `새 의미 판단 시작 요청`, `필요 시 재결합 요청 후 채택`으로 바꿨다.
2. 위·아래의 Request Controller가 별도 Component로 오해되지 않도록 `같은 이름은 같은 Component의 단계별 표시` 범례를 추가했다.
3. 4장의 R1/R2 제목 뒤에 겹쳐 있던 숨은 텍스트 개체를 제거했다. 편집 구조를 정리한 뒤 레이아웃 경고가 0건임을 확인했다.

두 독립 검토자는 수정 후 추가 미해결 사항을 보고하지 않았다.

기본 비교는 기존 발표 캠페인의 안별 4개 작성 사례×3회다. QA03의 A 누락 1건은 제외 사실을 감추거나 벌점으로 바꾸지 않았다. QA01/03의 분모가 다르므로 괄호를 모두 성공률이라고 부르지 않는다. B 선택은 발표를 위한 기존 근거 해석이며 승인된 ADR 변경을 뜻하지 않는다.

### B1 별도 응답 재생

| 동시 문맥 N | 기본 B 최고 RSS | B+B1 최고 RSS | 변화 |
| --- | --- | --- | --- |
| 1 | 30.097MB | 30.294MB | +0.197MB |
| 2 | 30.802MB | 30.507MB | −0.295MB |
| 4 | 32.326MB | 31.867MB | −0.459MB |

- `strict-control-v2`의 순서 제어 재생 정본을 사용했다. N별·안별 12회, 전체 72회, 새 API 0회, 기존 응답 686개 재생이다.
- 최고 RSS는 N별 해당 안 12회 중 최대 동시 Python+Rust RSS다. 평균 trial peak나 요청 할당 byte와 다른 지표다.
- N=4 요청 할당 peak 평균은 573,372→365,413byte이다. 결과·callback은 72/72 동일, 실제 모델 입력 snapshot은 168/168 session 동일했다.
- **46.170→31.867MB는 유효한 전후 비교가 아니다.** 기본 비교와 보완 재생의 실행기가 다르다. 기본 A/B의 0.819MB 차이를 B1 재생만으로 인과 설명하거나 B1이 A보다 메모리를 적게 쓴다고 주장하지 않는다.
- N=1 최고 RSS는 증가했다. 일반 사용의 QA06 우세, 제품 전체 RAM, 원격 모델 weights/KV, 새 지연·정확도·비용 개선을 입증한 결과가 아니다.
- 새 공통 대표 평가의 준비와 부분 진단을 기존 완료된 캠페인에 합치지 않았다.

### 선택 조건의 상세 표

K=2의 독립 질문 첫 응답 A 13.388초/B 6.270초와 B의 API 6.261초 중첩을 표시했다. K=1의 후속 목표 완료 A 13.429초/B 13.087초와 호출 중첩 0을 함께 표시했다. 각 행은 같은 사례 3회 평균이다. 두 행은 첫 응답과 후속 완료로 지표가 다르므로 행 간 직접 속도 비교를 하지 않는다. A는 현재 모델·읽기 step의 경계를 기다리며, 입력 수신이나 앞선 요청 전체를 막는 구조가 아니다.
