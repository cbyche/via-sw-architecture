## 41 표기 및 협력 경로 수정 — 2026-10-08

사용자 심사 과정에서 41의 도형 유형, 같은 Request Controller의 중복 표시 및 조회/반환 경로 오류가 확인됐다. 아래 이전 검수의 미해결 P1/P2 없음은 그 당시 검토 범위의 기록이다. 특히 1차 기록의 **B 조회 응답을 관계 결합기에 직접 반환**한다는 보완은 잘못됐으며 이번 수정으로 대체한다.

- 도형 선 1.0px, 구조 연결선 1.1px로 축소. 양안 공통 Component와 State Store는 흰 바탕 및 검정 선, 서로 다른 해석 구조와 내부 상태는 살구색 바탕 및 검정 선으로 표시.

- A의 읽기 도구 실행기와 B의 미해결 항목 처리기에서 Context Manager와 Task Manager로 직접 조회/응답. 기존 Task Manager→Context Manager의 필수 중계처럼 보이던 선 삭제.

- 양안 모델 호출과 결과 반환, B의 부분 재해석 요청과 반환, A의 검증 실패와 재판단, 임시 해석 상태 접근과 보존 경로 명시.
