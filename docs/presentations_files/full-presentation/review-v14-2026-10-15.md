# v14 DP44 구현 구조 비교 검수

v13의 DP44 비교 20장을 그대로 두고, 구현 구조 확대 비교를 21장에 추가했다. 기존 본문과 노트는 페이지 번호를 제외하고 37장 모두 동일하다. v13의 기존 그림, 개별 발표 파일 및 QA 부록도 삭제하거나 교체하지 않았다.

새 장은 같은 사건에서 A의 중앙 Control Lane, Event Mailbox, Dialogue Dispatcher, Job Index를 B의 Stage별 Control, 입력, Done Queue 및 로컬 상태와 나란히 보여 준다. A의 비동기 완료는 중앙 Mailbox로 돌아오고, B의 완료는 생산 Stage의 Done Queue로 돌아온다. B는 후보와 조건을 Publication Join에서 결합한다. 두 안의 늦은 J1 결과 폐기 위치, 일반 입력 경로, 빨간 제어 경로, 공통 Publication Control과 실제 전달도 표시한다. Queue는 칸이 있는 대기열, 상태는 원통으로 그렸다. 대안 선정이나 품질 우열을 주장하지 않는다.

검증 결과:

- 새 SVG와 draw.io의 생성 원본 일치 검사 통과. Chromium 1920×1080 PNG 렌더링에서 텍스트 캔버스 이탈, 폭 초과, 텍스트 간 겹침 0건.
- 한 장 PPTX는 Artifact Tool로 작성하고 무결성, 슬라이드 크기 및 자체 재수입 검사를 통과했다. 새 통합 슬라이드는 223개 native 편집 도형을 포함한다.
- 통합 v14는 38장이고 기존 37장의 페이지 번호 이외 본문과 노트가 v13과 동일하다. 20장에 기존 비교, 21장에 새 비교가 있다. 원래 media, layout, master 및 theme 파일은 그대로 보존했다.
- 통합 PPTX 무결성 검사 finding 0건, 배치 검사 finding 0건과 warning 0건, Calibri, 한국어 언어 설정 및 정수 pt 정책 위반 0건. LibreOffice PDF 변환에서 38장 확인.

PowerPoint 자체의 Windows 렌더링은 이번 로컬 검수에 포함하지 않았다. 구조 그림은 설계 제안이며 실행 코드나 측정 결과가 아니다.
