# QA 상세 페이지 v11 검수 기록

검수일: 2026-10-15

## 변경 범위

[v11 통합본](../VIA-architecture-presentation_v11.pptx)은 v10 기반의 33장이다. [9개 QA 미리보기와 원문 대응](../qa-metrics-v11/README.md), [페이지 manifest](./manifest-v11.json)에 편집 위치와 hash를 기록했다.

| 항목 | 반영 |
| --- | --- |
| 기존 Appendix | v10의 25~63장 39개를 slide registry와 실제 slide/notes part에서 삭제 |
| 새 Appendix | QA01~QA09를 25~33장에 한 장씩 작성 |
| QA 상세 구성 | 정의, 목표, 측정 조건, 목표 근거, 산식, 계산 예시, 0~6점 점수표, DP 관계 문장 |
| 본문 9~11장 | 최신 QA01~QA06 요약과 세 시간 지표의 경계로 교체 |
| 본문 12/13/16/19/21/23/24장 | QA 이름, 순서, 목표, 공통 28개 모집단과 Appendix 참조 갱신 |
| QA01/QA03 | QA-C01-v3 / QA-C03-v3의 산술평균, 오답의 실제 처리 시간, 미관측 별도 보고 반영 |
| QA06 | 사용자 지정 시스템 요구사항 512 MB 적용. MB는 1,000,000바이트 |
| 발표자 노트 | 출처 URL, 판정 경계, 목표의 적용 한계 및 계산 예시의 가상 값 표기 |

본문의 14개 비대상 페이지 1~8/14/15/17/18/20/22는 페이지 번호를 제외한 본문 XML과 발표자 노트를 보존했다. 남아 있는 원본 media는 bytes까지 동일하다. v10 파일 자체는 변경하지 않았다. 기존 DP 구조 그림과 FR 분류의 전체 개편은 이번 작업 범위에 포함하지 않았다.

## 독립 검토와 보완

`review_measurement`가 QA 문구 JSON과 작성 및 패키징 스크립트를 QA 원문에 대조했다. 검토 범위는 정의, 목표, 모집단, 산식, 예시, 점수표와 측정 경계의 정적 확인이며 렌더링 검토는 작성자가 수행했다.

| 발견 사항 | 조치 | 재확인 |
| --- | --- | --- |
| QA02의 최초 채택 판정이 축약에서 불분명 | 입력 표현과 revision별 첫 집합을 판정하며 사후 정정으로 오류를 지우지 않는 규칙 추가. 30초 미채택 조건은 노트에 명시 | 해소 |
| QA01의 DP44 가설에서 B가 불명확 | 중앙 회수 대기를 줄이는 방안이 B임을 명시 | 해소 |
| 최신 QA01/QA03 평균 기준의 반영 필요 | 요약, 산식, 점수 예시, 경계 표와 Overview를 산술평균으로 갱신 | 해소 |
| 본문 QA09 시작점의 “최종 채택”이 늦은 기준으로 해석될 여지 | “첫 응답 내용 채택부터 실제 첫 요약 음성까지”로 수정 | 해소 |
| DP42의 QA01이 업무 접수 완료 대기를 첫 응답에 부과 | 양안 모두 접수 전 수행 안내가 가능하므로 동점 예상으로 수정 | 해소 |

최종 재검토에서 해당 검토 범위의 미해결 P1/P2는 없었다. 구조별 성능 우열이나 목표의 실험적 달성을 검증한 리뷰는 아니다.

## 파일과 화면 검사

- 최종 파일 SHA-256: `176d5f006a0bfa7f1c0dc28a4db7137e081438d3f7a52a223fee063f725d853f`
- 총 33장과 실제 slide part 33개 확인. 삭제한 Appendix slide/notes와 더 이상 참조하지 않는 자원 정리.
- Artifact Tool에서 최종 PPTX 재열기 성공 및 33장 전체 렌더링. 모든 페이지를 이미지로 확인.
- 새 QA 장마다 상단 표, 예시 표, 점수표를 native table로 작성. 전체 native table 42개와 기존 native chart 1개 확인.
- 패키지 관계와 내장 chart/workbook, slide geometry, bullet/heading geometry 검사에서 오류 및 경고 0건.
- Calibri, 정수 pt, ko-KR 정책 위반 0건. 그림 속 기존 글자는 원본 픽셀로 보존.
- 표의 구간과 예시 산식은 원문 대조 및 독립 검토로 확인. 일반 표 산술 검사기는 이 표 형식에 합계 규칙을 적용하지 않았으므로 그 검사만으로 수치를 검증했다고 주장하지 않는다.

## 검증 범위

이번 작업은 발표자료 제작이다. 모델 실행, PoC 측정과 A/B 선정은 수행하지 않았다. QA07~QA09의 목표는 설계 예산 제안으로 명시했으며 외부 실증 임계값으로 제시하지 않았다. QA06의 요구사항은 사용자가 과제에 지정한 것으로 실제 삼성 내부 승인 문서를 확인한 사실은 없다.

## Windows와 배포 CI

발표자료 배포 commit `88b3b52ec1b52d727e32a7662f7619ac25877309`의 [Architecture CI](https://github.com/cbyche/via-sw-architecture/actions/runs/38602750338)와 [Windows cloud 검사](https://github.com/cbyche/via-sw-architecture/actions/runs/38602763042)가 통과했다.

Calibri가 설치된 Windows Server 2022에서 Microsoft Open XML SDK 3.3.0으로 최종 33장 파일을 열었다. Office2021 스키마 오류는 0건이며 검사 파일의 SHA-256은 위 최종 파일 해시와 일치한다. Calibri, 정수 pt, 한국어 정책 검사도 통과했다.

Windows cloud에는 PowerPoint가 설치되어 있지 않았다. 프로그램 자체 실행, native 글꼴 배치와 GIF 재생은 미검증이다. SDK 검증과 로컬 렌더링의 범위를 구분한다.
