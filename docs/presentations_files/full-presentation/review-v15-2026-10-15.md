# v15 DP44 상황별 경로 비교 검수

v14의 복잡한 종합 구현 그림을 보존하고, 그 앞에 네 상황별 A/B 비교를 추가했다. 통합 발표 21~24장은 일반 사용자 발화, 확인된 Agent 질문, 새 발화 시작, 정정 채택과 늦은 완료를 각각 한 경로로 보여 준다. 기존 높은 수준 비교는 20장, 이전 종합 그림은 25장에 남아 있다. 각 그림의 SVG와 draw.io 원본 및 PNG를 04-44 §3.7.4에 직접 삽입했다.

각 장은 같은 사건을 A와 B 두 행으로 배치하고 사건이 들어가는 Queue, 이를 소비하는 코드, 완료의 반환 위치를 왼쪽에서 오른쪽으로 읽는다. 한 장에 등장하지 않는 분기는 생략했다. 반복된 Event Mailbox와 Stage 이름은 동일 인스턴스의 시간별 재표시다. 발화 감지의 즉시 재생 중단은 양안 공통이며, 새 발화 시작만으로 Job이나 Task의 취소를 확정하지 않는다.

검증 결과:

- 네 SVG와 draw.io의 생성 원본 일치 검사 통과. Chromium의 1920×1080 PNG 렌더링에서 네 장 모두 텍스트 캔버스 이탈, 폭 초과, 텍스트 간 겹침 0건. 각 장을 개별 확인했다.
- 네 장 별도 PPTX는 Artifact Tool로 작성하고 무결성, 슬라이드 크기 및 자체 재수입 검사를 통과했다. 통합본의 새 장은 모두 native 편집 도형이다.
- 통합 v15는 42장이다. 기존 v14의 38장 본문과 노트는 페이지 번호를 제외하고 동일하다. 원래 media, layout, master 및 theme 파일은 그대로 보존했다.
- 통합 PPTX 무결성 검사 finding 0건, 배치 검사 finding 0건 및 warning 0건, Calibri, 한국어 언어 설정 및 정수 pt 정책 위반 0건. LibreOffice PDF 변환에서 42장을 확인했다.

Windows PowerPoint 자체 렌더링은 이번 로컬 검수에 포함하지 않았다. 이 구조는 미선정, 미구현, 미측정 설계안이다.
