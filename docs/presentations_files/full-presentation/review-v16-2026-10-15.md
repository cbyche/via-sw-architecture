# v16 요약 표 삽입 검수

- 입력: v15 통합본 42장. 출력: v16 통합본 43장.
- 설계 Overview 17장 다음에 DP 요약 18장을 추가했다. 공통 장면은 19장, DP44 시작은 20장이다.
- 표는 5열과 머리글 포함 5행의 native PowerPoint 표다. 순서는 44 / 47 / 45 / 42다.
- 기존 슬라이드는 페이지 번호를 복원해 XML 내용을 대조했다. 모든 본문이 동일하다. 기존 노트, media, layout, master, theme 및 chart 자원을 보존했다.
- Artifact Tool로 43장을 렌더링했다. 새 18장의 줄바꿈과 표 셀 배치, 기존 Overview와의 서식 일치를 확인했다.
- package integrity 및 layout 검사 오류와 경고 0건. Calibri, 정수 pt, ko-KR 정책 위반 0건.
- Windows cloud workflow는 저장소에 게시된 파일만 검사하므로 이번 미게시 로컬 판본에는 실행하지 않았다. Windows PowerPoint 자체 실행과 native 글꼴 배치는 미검증이다.
- 구조와 평가 원문은 변경하지 않았다. 평가는 2026-10-15의 구조 기반 예상이며 실측이나 A/B 선정이 아니다.

작성 원본: `scripts/presentations/generate_dp_summary_v16.mjs`, 삽입 및 보존 검사: `scripts/presentations/package_dp_summary_v16.py`.
