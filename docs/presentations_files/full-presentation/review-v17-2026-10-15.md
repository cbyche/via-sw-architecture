# v17 필요성 복원과 DP 비교 추가 검수

- 입력: v16 통합본 43장과 기존 PPTX 세 파일. 출력: v17 통합본 49장.
- 2장: VIA-project-introduction_v10.pptx의 2장. 3장: VIA-project-introduction_v9.pptx의 2장. v9 통합본의 필요성 페이지와도 본문 일치를 확인했다.
- 기존 필요성 5장은 4~8장에 유지했다.
- 20장 DP 요약 바로 뒤의 21~24장에 VIA-DP-comparisons-reference_v1.pptx 4장을 순서대로 삽입했다.
- v16의 43장과 추가한 원본 6장의 XML은 페이지 표시와 신규 slide key를 제외하고 동일하다. 원본 노트와 기존 media, chart, layout, master, theme를 보존했다.
- 원본 6장과 최종 6장의 렌더를 비교해 페이지 번호 영역 외 픽셀 차이 0건을 확인했다. 원본 그림과 표 및 텍스트는 원래 편집 가능성을 유지한다.
- 49장 전체 렌더, 추가 페이지 상세 배치, 전체 발표 순서를 확인했다.
- package integrity와 geometry 및 native table 검사 오류와 경고 0건. Calibri, 정수 pt, ko-KR 정책 위반 0건.
- Windows cloud 검사는 저장소 게시 후 별도로 실행한다. 이 로컬 검사 기록은 Windows PowerPoint 자체 실행이나 native 렌더링을 입증하지 않는다.
- Architecture 정의와 평가 수치를 변경하지 않았다. 수치는 기존 구조 기반 예상이며 실측 결과나 최종 A/B 선정이 아니다.
