# VIA 발표자료 v2 구성 결정

2026-10-11 사용자의 후속 지시와 [독립 리뷰](./review-2026-10-11.md)를 종합한 편집 기준이다. Architecture와 여섯 QA의 정의, 목표, 우선순위는 변경하지 않는다.

## 적용 원칙

- 기존 `VIA-architecture-presentation.pptx`는 보존하고 `_v2.pptx`를 만든다. 이후 수정도 새 버전에서 시작한다.
- 원본 8~17장은 본문에서 빼고 appendix 첫 상세 구역으로 이동한다.
- 원본 22, 25, 28, 31장의 역할을 맡는 새 본문 비교 페이지는 A/B 구조와 여섯 QA 평가표를 같은 페이지에 둔다. 미실측 표시는 유지하며 예산과 지역 가정 계산을 실측과 구별한다. 이전 리뷰 R-07의 반복 QA 표 분리 제안보다 이 사용자 지시를 우선한다.
- 본문에서 대체한 원래 페이지와 상세 계약은 appendix에 보존한다. 기존 32장의 모든 텍스트, 개체, 발표자 노트와 media를 보존 대상으로 검증한다.
- 도메인 용어는 소개에서 설명하고 필요성에 비용과 PC 자원 원인을 추가한다. 필요성에서 QA나 DP를 직접 열거하지 않는다.
- DP 제목은 `(주요 품질속성)을 위한 (기능) 설계` 형식을 쓴다. 각 배경에서 구조 선택 질문과 양쪽 비용으로 연결한다.
- 완료된 작업 단위를 검증하고 범위를 지정하여 commit/push한다. 다른 세션의 변경은 포함하지 않는다.

## 참고 발표자료의 적용

[presentation_example1](../presentation_example1/)의 PNG 파일을 제목 번호순으로 확인했다. 1~11번의 배경, 도메인 소개, 필요성, 요구사항, QA, driver, context와 설계 Overview 흐름을 따른다. 이해를 돕는 간단한 전체 흐름은 소개에서 먼저 제시한다.

12~24번의 DP 배경 다음에 구조와 QA를 함께 보여주는 비교 방식을 적용한다. 25번의 설계 적용 범위 확인, 31번의 향후 확인 사항과 35번의 appendix 구분도 반영한다. 참고 자료의 채택 표시, 최종 설계, 구현 결과와 측정 결과는 VIA의 현재 사실로 전용하지 않는다.

## 본문 구성

| 순서 | 내용 | 처리 |
| --- | --- | --- |
| 1~6 | 관련 동향 → 필요성 → VIA 역할 → 도메인과 전체 흐름 → 대표 시나리오 → 업무 위임 책임 | 기존 배경/역할/시나리오/책임 그림 유지. 필요성 보완, 용어와 시나리오의 시작 상태 설명 추가 |
| 7~11 | 요구사항의 근거 → 기능/제약 → 여섯 QA → 두 시간 지표의 경계 | 고정 요구와 QA 유지. P21과 외부 업무 시간을 쉬운 말로 설명 |
| 12~14 | 요구/품질/설계 질문 연결 → 설계 Overview → 겹쳐 도착하는 사건 | 기존 직접 영향 범위를 유지. 앞서 위임한 견적 업무라는 시작 상태를 명시 |
| 15~22 | 41 → 44 → 45 → 42, 각각 배경과 비교 | 배경에 선택 질문 추가. 비교 그림과 여섯 QA를 같은 페이지에 배치 |
| 23~24 | 적용 범위와 공통 계약 → 선택 전 확인할 사항 | 구조별 조건과 비용을 정리. 미선정/미실측 상태 유지 |
| 25 이후 | appendix | 원본 8~17장 우선 배치. 대체한 본문과 DP 상세 및 계산 근거도 보존 |

네 비교의 큰 그림은 모델/코드의 해석 제어, 중앙 후속 실행/조건 활성화, 요청별 과거 구성/공통 생산, 공동 상태 확정/독립 상태 접수의 실제 차이를 보여준다. 모듈 수만으로 우열을 설명하지 않는다. 강한 A의 비동기 실행, cache, 부분 갱신과 모듈화를 유지하고 B의 추가 상태, 표현 범위, 미사용 생산과 접수 비용을 함께 표시한다.

최종 페이지별 위치와 원본 대응은 새 버전의 manifest에 기록한다. 현재 파일과 다른 세션의 Architecture 작업은 이 편집의 입력으로 덮어쓰지 않는다.

## 반영 결과 — 2026-10-12

[VIA-architecture-presentation_v2.pptx](../VIA-architecture-presentation_v2.pptx)에 위 구성을 반영했다. 본문은 1~24장, appendix 안내는 25장, 원본 32장 보존은 26~57장이다. 원본 8~17장은 26~35장에 먼저 배치했고 본문 비교+QA는 16/18/20/22장이다. 원래 비교와 상세 QA도 삭제하지 않았다.

본문 그림을 독립 리뷰어가 재확인하면서 Component 경계, 의미 제안 반환과 채택, 응답 후보 준비 및 상태 공동 확정 경로를 보완했다. [현재 구성과 편집 안내](./README.md), [위치/보존 manifest](./manifest-v2.json), [검증 기록](./v2-validation.md)을 함께 유지한다.
