# v13 필요성 5안 통합 검수

2026-10-15. 사용자 요청에 따라 v11의 필요성 1장을 v12의 다섯 안으로 교체. 총 37장 중 2~6장에 모두 수록. 본문 28장, QA Appendix 29~37장.

## 보존 및 변경 범위

- v11의 나머지 32장: 페이지 번호만 갱신. 나머지 본문 XML과 도형 배치 동일, 노트 및 슬라이드 관계 파일 bytes 동일.
- v12의 5안: 안 이름과 전체 페이지 번호만 갱신. 본문과 그림 및 노트 보존.
- 기존 미디어, GIF, native 차트와 workbook, master/layout/theme bytes 보존.
- Section의 슬라이드 목록과 문서의 장수 정보를 37장에 맞춰 갱신.
- QA 문구, 목표 및 수치 변경 없음. Architecture 변경이나 측정 실행 없음.

## 확인

Artifact Tool로 페이지 번호 편집 후 원본 native package에 해당 텍스트만 반영. 37장 전체 렌더링 완료, 추가 5장 개별 확인 및 전체 흐름 점검. 추가 페이지의 본문 영역은 원본 v12 미리보기와 픽셀 동일. 비교에서 페이지 번호가 있는 상단 105px 제외.

Package, geometry, native 표와 차트, Calibri·정수 pt·ko-KR 검사 통과. 기존 native 표 42개와 차트 1개 유지. 자동 검사 결과는 구조/서식 검사이며 실제 PowerPoint 렌더링과 GIF 재생 검증을 뜻하지 않음.

최종 SHA-256: `958625ad35b2c2e978d8d498f8a3732d86717182d5c861f9b8d6d961faee3b0e`.

## 재현

[페이지 번호 작성기](../../../scripts/presentations/integrate_necessity_v13.mjs), [원본 보존 패키저](../../../scripts/presentations/package_necessity_v13.py), [검증 및 렌더링](../../../scripts/presentations/finalize_necessity_v13.mjs) 사용. 두 입력 파일의 SHA-256 고정.

bundled `node_modules`를 새 private build에 연결하고 mjs 사본 배치. `VIA_PRESENTATION_SKILL_DIR`, `VIA_RUNTIME_PYTHON`, `RUNTIME_NODE_MODULES`는 bundled 경로 사용.

1. `package_necessity_v13.py prepare REPO BUILD`
2. bundled Node로 `integrate_necessity_v13.mjs REPO BUILD`
3. `package_necessity_v13.py package REPO BUILD`
4. bundled Node로 `finalize_necessity_v13.mjs BUILD`

[슬라이드 대응과 보존 검증](./manifest-v13.json), [현재 발표 순서](./README.md) 참조. 원본 v11과 별도 비교본 v12는 그대로 유지.
