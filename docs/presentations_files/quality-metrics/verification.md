# 제작 및 독립 검토 기록

2026-10-06의 QA metric 부록 제작 확인이다. 실제 VIA 구현, 후보 측정이나 DP 선택의 결과는 아니다.

## 내용 확인

- 기존 10개 QA의 ID, 순위, 명칭, 설명과 단일 목표를 source JSON과 대조했다.
- 70개 구간의 정확한 경계, 유효 측정값의 중복 및 누락 여부와 단조성을 검사했다.
- 반올림 전 값과 경계 예시를 확인했다. 정확성 1,785/1,880과 1,786/1,880, 평균 개입 0.6004와 0.6, 변경 요소 17/6과 16/6, 메모리 16GB와 그보다 1byte 큰 값을 구별한다.
- 엄격 계약의 0~5점은 목표 미달이다. V-03의 미지원 수, V-09의 미확인 수와 V-10의 사건 수를 원래 단일 지표와 연결했다.
- 출처의 사실과 VIA의 목표 선택 및 작성자 구간 규칙을 구분했다. 상향 참조의 실현 가능성은 실증하지 않았다.
- 가운데 점이 없고 링크된 로컬 파일이 존재하는지 확인했다.
- 기존 QA 요약 자료의 consistency 검사도 통과했다.

## 편집과 화면 확인

- PPTX 10장에 native table 30개가 있고 채점표 70개 행이 JSON 및 Markdown과 일치한다.
- 설명과 계산은 편집 가능한 text 및 table이다. 발표자 노트에 해당 QA의 출처 링크, 상세 절차와 공통 시험 조건을 수록했다.
- package integrity, 16:9 geometry, 표와 font policy 및 artifact-tool 재가져오기 검사가 통과했다.
- 최종 PPTX를 재가져와 PNG 10개를 렌더링하고 각각 글자 잘림, 표의 경계 및 줄바꿈과 페이지 배치를 확인했다.
- Microsoft PowerPoint 또는 Google Slides 앱에서 직접 편집하고 저장한 결과는 확인하지 않았다. 다른 글꼴 환경의 native rendering도 입증하지 않는다.

## 독립 senior SW architect 리뷰

목표와 측정 설계의 기존 독립 리뷰를 수행했던 별도 agent에게 부록 계획과 완성 문서를 두 차례 검토하도록 했다. 실제 심사위원 평가나 VIA 성능 검증은 아니다.

계획 리뷰의 세 보완점을 반영했다.

1. V-05의 4초와 V-06의 12GB는 전체 지표의 공학적 상향 참조이며 최저 필요량이나 달성 가능한 실측값이 아님을 명시했다.
2. 각 표의 목표 충족 열과 색으로 개선형과 엄격 계약의 통과 기준 차이를 표시했다.
3. 원값 채점, 시험 변동 및 경계 불확실성 보고와 점수 간 단순 우열 해석 금지를 기록했다.

완성 문서 리뷰에서 한 건의 P2가 발견되어 수정했다. 공통 UNMEASURED 규칙이 V-01과 V-09의 확인된 실패까지 보류로 바꿀 여지가 있었다. 유효한 정확성 시험의 timeout 및 미전달은 실패이고, 유효한 분석에서 로그 유실, 오답과 판단 불가 및 시간 내 미제출도 실패로 남도록 구분했다. 분석 세션 자체의 미실시 또는 판정 기록 소실과 전체 registry 불확인은 평가 보류이다. V-10에서 관측 누락이 있어도 이미 알려진 위반은 목표 미달로 유지한다.

수정 원본과 JSON의 close-out 검토 결과, **이번 문서 및 채점 설계 범위에서 미해결 P1/P2는 없다**는 확인을 받았다. 모델 배포 가능성, 목표 달성, fixture 동결과 실제 측정 및 PowerPoint native 실행은 이 확인의 범위에 포함되지 않는다.
