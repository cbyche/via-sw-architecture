# DP1부터 DP4 통합 발표자료 검토 결과

2026-10-19

DP1 v3, DP2 v2, DP3, DP4의 최신 발표자료를 **각 4장씩 총 16장**으로 통합했다. 제목, 단계 표시, 페이지 번호, QA 표기와 범례를 통일했다. 구조도는 편집 가능한 도형 1,473개, 표는 PowerPoint 표 16개로 유지했다.

기존 **R01~R16 체크리스트 중 14개 충족, 2개 범위 한정 충족**이다. R07과 R09는 DP3의 미적용 복구 대안과 별도 실험의 해석 범위 때문에 한정했다. 최종 검토에서 남은 P1/P2 지적은 없으며, 패키지·레이아웃 오류와 경고는 0건이다.

## 레퍼런스에서 이어받은 원칙

- 비교와 선택 장은 대안 순서, 구조도, 장단점, QA 행을 유지한다. 선택한 열 전체에 파란 외곽선과 빨간 체크를 표시한다.
- 선택안 내부의 보완 경로, 단점 아래 보완 문구, QA 전후 값을 파란색으로 연결한다. 적용하지 않은 대안은 그 상태를 함께 표시한다.
- 보완에 따른 시간·비용·메모리 증가와 남은 오류를 함께 제시한다. 다른 실험의 숫자를 하나의 전후 변화로 연결하지 않는다.
- 배경은 실제 문제상황과 설계 질문을 도식으로 제시한다. 비교 그림은 Component 경계, 내부 처리 또는 Module, 저장 상태와 실행 의존성이 다르게 보이도록 한다.
- 레퍼런스의 수치나 점수를 VIA 수치로 옮기지 않는다. 상세 메커니즘과 해석 범위는 각 DP의 네 번째 장에 둔다.

## 통일한 스타일과 용어

### 시각 규격

- 1920×1080의 16:9 화면, Apple SD Gothic Neo 글꼴, 공통 제목과 단계 표시를 사용했다.
- 연녹색 설계안 제목, 옅은 노란색 SW 영역, 파란 선택·보완 표시, 빨간 단점·비용 표시를 유지했다.
- DP1의 비교·선택 본문 전체를 10px 위로 이동해 다른 DP의 표 시작점과 맞췄다. 개별 구조의 상대 위치는 유지했다.
- QA 행 이름을 18px로 맞추고 페이지 번호를 1/16~16/16으로 연결했다. 상세 참조는 본문과 발표자 노트 모두 4·8·12·16쪽으로 수정했다.
- DP1의 반올림된 비용을 근거의 원정밀도로 복원했다. 비교표는 $0.0674956, $0.0699160, $0.1630788이며, 별도 첫 안내 보완은 $0.0146552→$0.0157364다.

## 검토 결과와 확인 범위

1. 최신 원본의 내용·도형·표·발표자 노트를 통합본과 대조했다. 허용한 표기 변경 외 숫자, 분모, 한계와 선택 상태가 보존됐고, 비교/선택 표의 행·열 규격도 유지됐다.
2. 시각·레퍼런스 검토자와 사실·용어 검토자가 16장 통합본을 독립 검토했다. 페이지 통합 후 남아 있던 로컬 “4장” 참조를 P2로 지적해 실제 4·8·12·16쪽으로 수정했다. 수정 범위 재검토 후 남은 P1/P2는 없었다.
3. 도형·표 보존 대조, 패키지 무결성, 레이아웃, 글꼴 표기와 재가져오기를 확인했다. 표 합계 산술 검사는 해당 합계 행이 없어 산술 검증 대상으로 삼지 않았으며, 수치 보존은 별도 원본 대조로 확인했다.
4. Microsoft PowerPoint 앱 자체의 렌더링과 글꼴 대체는 확인하지 않았다. 이번 작업은 기존 발표자료의 통합과 검토이며 새로운 구현, 모델 호출 또는 성능 측정은 수행하지 않았다.
