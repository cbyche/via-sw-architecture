# 발표 구성: DP1~4 기존 자료와 DP5 추가

기존 발표의 문제, 기본 구조, QA 손익, 평가, 선택과 보완 순서를 유지한다. DP5는 평가를 아직 수행하지 않았으므로 해당 자리에 검증 가설과 선택 조건을 둔다. 실측 숫자나 승자를 새로 만들지 않는다.

## 앞부분 1~24장

1장은 DP5를 포함한 전체 목차로 확장한다. 2~3장은 기존 장면·QA 계약임을 제목에 명시한다. 4~24장의 DP1~4 본문, 관측값과 조건부 권고는 유지한다.

| 구간 | 기존 DP의 구성 |
| --- | --- |
| 4~8 | DP1 현재 요청의 근거 공급: A/B 구조, C 사전 생산, 관측, 공통 첫 응답 보완, 조건부 A |
| 9~12 | DP2 의미 판단 실행: A/B 구조, 자원 조건별 관측, B 권고와 B1 보완 |
| 13~18 | DP3 화면·발화 지칭: A/B 구조, 측정 세대별 결과, 보완과 조건부 A |
| 19~24 | DP4 업무 인계: A/B 구조, C 수신자 읽기, 관측, 조건부 C와 별도 보완 |

## DP5 25~34장

| 장 | 내용 | 발표할 판단 |
| --- | --- | --- |

| 26 | R 조사, P 작성, Q 수정과 사용자 피드백 | 최신 수정자와 사용자가 지칭한 작성자는 다를 수 있음 |

| 29 | 사건 처리, 검색, LLM 해석, 채택 | 검색 방식과 LLM 호출 횟수가 이 비교의 정의는 아님 |

| 34 | 조건부 판단과 반증 | 미선택. 공통 사실과 A 재사용으로 차이가 없으면 DP1/4 상세 설계로 통합 |

## 기존 결과 부록 35~40장

기존 25~30장을 이어 둔다. DP1~4 권고 표의 제목·주석으로 기존 결과임을 명시하고, DP5가 미선택이라는 점을 연결한다. 표에 새 실측 행이나 점수를 만들지 않는다. 40장 source 목록은 DP1~4의 기존 실험 provenance이고 DP5 근거는 25~34장 notes와 설계 원문에서 연결한다.

## 자료 해석 주의

- 다섯 DP는 완전히 독립된 성능 개선 다섯 개가 아니다. DP5는 기존 DP1/4의 생산 축을 좁혀 합친 비교다.
- QA01/03에서 같은 대기를 줄이는 효과와 QA02/07의 같은 대상 오류를 독립 이익으로 합산하지 않는다.
- DP5의 QA07은 요청 의미 해석 정확도다. 기존 결과를 새 QA07 결과로 이름만 바꾸지 않는다.
- 상세 도메인 판단과 수행은 Downstream Agent가 맡는다. 위임 관계 메모리의 역할을 모든 자료의 요약·정리로 확대하지 않는다.
