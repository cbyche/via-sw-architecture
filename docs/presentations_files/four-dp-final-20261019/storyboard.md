2026-10-19 / 현재 30장 발표자료

장 번호와 제목은 [30장 렌더 목록](render-list.md)에 맞춘다. 수치·분모·실패 해석의 정본은 [17 발표용 결과](../../architecture/12-decisions/decision-packages/seven-problem-review/17-presentation-results.md)다. 이 문서는 발표의 흐름과 핵심 메시지를 정리하며 수치 표를 중복 관리하지 않는다. 현재 권고는 작성 사례와 모델·출력 계약에 한정된 설계 판단이며 accepted ADR이나 참조 Architecture의 사용자 채택 상태를 바꾸지 않는다.

## 판단과 표현 원칙

- 구조의 **입력 → 처리 → 유지 상태 → 채택/출력**을 먼저 설명하고, 기대한 효과와 실제 관측을 구별한다. 구조 그림의 흐름 번호는 정수로 표시한다.
- QA01 → QA02 → QA03 → QA04 → QA05 → QA06 순서를 유지한다. 구조적 동점, 관측상 같은 값, 우열 미확정, 미관측, 비적용을 구별한다. 공통 함수를 쓴다는 이유만으로 실제 입력 차이까지 동점으로 처리하지 않는다.
- host 종료는 사용자 조건의 완전한 의미 충족과 다르다. QA02 지칭 집합, N-R 관계 진단, N-H 인계 구조 계약, literal/동등표현/실제 본문 대조를 합치지 않는다.
- 기본안을 먼저 비교하고, 선택 뒤 보완의 효과와 비용을 별도로 제시한다. 필수 구현 누락의 수정은 tactic 성과로 세지 않는다. A2와 A3, C1과 C2를 실행하지 않은 조합으로 합치지 않는다.
- 같은 고정 사례·분모와 실패를 보존한다. 조건부 성공 평균은 전체 속도 우위가 아니며, 같은 완료 목표의 별도 비교를 병기한다. 다른 출력 계약의 성공 행을 골라 한 기본안 결과로 합치지 않는다.
- 실제 모델 실행, 실제 응답 재생, native 자원 검사를 나눈다. 재생의 API0·시간·메모리를 새 모델 비용·정확도·지연 개선으로 표시하지 않는다.
- 표와 구조도는 편집 가능한 native 개체로 유지한다. 사용자 참고 이미지의 흰 바탕, 녹색 방안 머리글, 크림색 처리 블록, 검정 흐름선, 파란 선택/보완 표시를 따른다. 참고 과제의 숫자와 선택은 VIA의 증거가 아니다.
- COMMON-28과 대응이 승인되지 않은 새 우세 점수를 만들지 않는다. 결론에 영향을 주는 누락·오류·전제는 본문에 남기고 세부 원시 출처는 발표자 노트로 연결한다.

## 여섯 QA의 읽는 방법

| QA | 이번 관측 | 해석의 경계 |
| --- | --- | --- |
| QA01 첫 응답 지연시간 | 실제 채택 내용의 출력 callback proxy | 일반 접수 안내는 제외한다. callback 통과가 모든 문장의 의미 정확성을 보장하지 않는다. |
| QA02 지칭 집합 정확도 | 처음 채택한 대상 집합·revision | DP1/DP3 적용. N-R/N-H나 상세 본문 점수로 대체하지 않는다. |
| QA03 VIA 처리시간 | 실제 host 종료까지의 VIA 귀속 시간 | DP4의 목표별 receiver HTTP 구간 공제와 전체 wall을 함께 보고한다. 미완료는 고정 분모에 남긴다. |
| QA04 변경 모듈 수 | 같은 네 실제 변경 과제의 Rust 모듈 수 평균 | 새 판본에서 재측정하지 않은 경우 이전 값을 새 측정처럼 옮기지 않는다. 유지보수 인월이 아니다. |
| QA05 전체 사용 비용 | 준비·실패·복구·수신자까지의 모델 사용량 환산 | 기본 표는 각 안12episode 합계다. 사용량 미확정은 보수적 예약으로 따로 남긴다. 청구서 금액이 아니다. |
| QA06 로컬 메모리 | 지정 로컬 프로세스의 최고 동시 RSS | 직렬화 상태·owned 할당과 구별한다. UI·cloud 가중치·전체 제품 메모리는 범위 밖이다. |

## 사전 예상과 실측의 구분

공개 사건의 선생산은 요청 가공을 줄일 수 있지만 쓰이지 않으면 준비 비용이다. 유지 문맥은 재사용을 줄 수 있지만 첫 입력을 늘릴 수도 있다. 병행은 독립 대기를 겹칠 수 있지만 모델의 좌표/관계 정확성을 보장하지 않는다. 명시적 후보 생산이나 인계 구조 계약의 성공도 실제 본문의 조건 보존을 보장하지 않는다.
