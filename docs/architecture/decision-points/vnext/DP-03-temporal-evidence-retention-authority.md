# DP-03 — Temporal Evidence Retention Authority

**Status:** ACTIVE — NO ALTERNATIVE SELECTED

**Question:** Who remains authoritative for historical interaction evidence required to ground temporal references after source/current state changes?

- **A — VIA-owned materialized historical evidence.**
- **B — Source-owned versioned/pinnable history plus VIA time/reference broker.**

Source memory, retention, indexing, pinning, and retrieval costs remain inside the evaluation boundary.

**Structural discriminator:** persistent historical-evidence ownership, version/pinning authority, retrieval dependency direction, and availability boundary after a source mutates.

**Primary QAs:** QA-01, QA-02, QA-05, QA-07. **Dependency:** DP-00. All twelve QA-v1 attributes are evaluated.

**Excluded mechanisms:** retention duration, cache size, index algorithm, timestamp tolerance, and storage vendor.
