# 공통 QA v3의 층별 수치와 조건부 판단

2026-10-22 / `COMMON-QA-SYN-3.0` / **SYNTHETIC_AUTHORED_NOT_MEASURED**

Text 이력, Voice/Screen, Voice Delivery의 세 층에서 같은 QA 의미를 사용한다. 비교 가능한 구성끼리만 수치를 읽는다. 9개 구성의 공통 QA01~07은 63개 값이고, DP44의 첫 음성 지연은 별도 종료점 2개다. 합친 평균이나 전체 제품 점수는 만들지 않는다. 실제 모델 호출과 제품 실행은 0회다.

[계약](01-common-contract.md), [구성 및 시나리오](02-configurations-and-scenarios.md), [JSON 원값](../../../../presentations_files/qa-common-synthetic-v3-20261022/summary.json), [계산 원장](../../../../presentations_files/qa-common-synthetic-v3-20261022/normalized-data.json), [이관 및 검토](04-migration-and-review.md)를 함께 읽는다. 아래 값은 표시를 위해 반올림했으며 원값은 JSON에 남는다.

## 1. Text 이력: DP2와 DP5

각 구성에 120에피소드, 240입력, 250표현과 180목표를 적용한다. T-BASE 한 벌을 DP2 A와 DP5 A에서 공유한다. 비용은 요청 전 관계 생산과 종료 후 갱신을 포함한 활동 묶음이다.

| 구성 | QA01 화면 초 | QA02 일치/표현 | QA03 초 | QA04 모듈/과제 | QA05 VIA USD | QA06 MB | QA07 일치/입력 |
| --- | ---: | --- | ---: | ---: | ---: | ---: | --- |
| T-BASE | 2.457195 | 238/250 (95.20%) | 6.649685 | 1.833333 | 2.451601 | 278.788 | 224/240 (93.33%) |
| T-EXEC | 2.131650 | 234/250 (93.60%) | 5.804266 | 1.833333 | 2.573512 | 306.080 | 213/240 (88.75%) |
| T-REL | 1.988448 | 243/250 (97.20%) | 5.874581 | 2.000000 | 3.355791 | 329.680 | 217/240 (90.42%) |

T-EXEC는 DP2만 B로, T-REL은 DP5만 B로 바꾼 구성이다. 이 층은 DP3를 실행하지 않았다. DP44는 기존 음성 준비의 실행 소유 구조가 지정되지 않아 `FIXED_UNMAPPED`다. 이 결과를 DP44 A 또는 B의 결과로 다시 명명하지 않는다. 첫 음성 지연도 작성돼 있지 않아 별도 값은 미작성이다.

## 2. Voice/Screen: DP3

각 구성에 120평가입력, 120표현과 120목표를 적용한다. 별도 준비 활동 60개는 정확도 및 시간의 대표 분모 밖이며 비용과 RAM에 포함한다. DP2, DP5와 DP44는 고정된 주변 기능이지만 그 A/B와의 대응은 지정하지 않았다.

| 구성 | QA01 화면 초 | QA02 일치/표현 | QA03 초 | QA04 모듈/과제 | QA05 VIA USD | QA06 MB | QA07 일치/입력 |
| --- | ---: | --- | ---: | ---: | ---: | ---: | --- |
| V-A | 3.466667 | 107/120 (89.17%) | 5.983333 | 1.833333 | 3.905200 | 592.000 | 102/120 (85.00%) |
| V-R1 | 5.783333 | 115/120 (95.83%) | 8.300000 | 2.000000 | 3.418800 | 1954.000 | 110/120 (91.67%) |
| V-R2 | 5.283333 | 115/120 (95.83%) | 7.800000 | 2.000000 | 3.418800 | 2374.000 | 110/120 (91.67%) |
| V-R3 | 5.323333 | 115/120 (95.83%) | 7.840000 | 2.000000 | 3.418800 | 2662.000 | 110/120 (91.67%) |

B의 실행 구성 중 R1은 필요 모델 가중치를 적재하고 회수하며, R2는 사용 가중치를 단일 worker에 유지한다. R3는 worker와 runtime 경계를 나눈다. R3의 정상 요청 정확도나 속도 이익을 추가하지 않았다. 첫 음성 지연은 이 원장에서도 미작성이다.

A에서 B로 바뀐 QA02/07의 순개선 8입력은 같은 대상 오류의 개선이다. 독립적인 두 정확성 효과로 합산하지 않는다. Voice/Screen에는 후속 정정 평가가 없고 S3의 객체 동일성도 실제 픽셀 검증이 아닌 작성 명세다. v3 통합이 이 한계를 해소하지 않는다.

## 3. Voice Delivery: DP44

각 구성에 80평가입력, 120표현과 90목표를 적용한다. 목표는 원래 보고서 목표 10개와 새 전달 목표 80개다. 원래 목표는 -6초부터 시작한 해석과 위임을 보존한다. 질문 읽기 완료를 메일 발송 완료로 세지 않는다. 별도 준비 활동 80개는 평가 입력의 분모에 추가하지 않으며 비용과 RAM에 포함한다.

| 구성 | QA01 화면 초 | QA02 일치/표현 | QA03 초 | QA04 모듈/과제 | QA05 VIA USD | QA06 MB | QA07 일치/입력 |
| --- | ---: | --- | ---: | ---: | ---: | ---: | --- |
| D-A | 0.923333 | 120/120 (100.00%) | 1.965259 | 2.333333 | 2.479873 | 561.659272 | 80/80 (100.00%) |
| D-B | 0.923333 | 120/120 (100.00%) | 2.710185 | 2.000000 | 2.224660 | 561.506936 | 80/80 (100.00%) |

**QA02와 QA07은 같은 올바른 의미를 공급하는 제어 fixture다.** 두 값은 이 비교의 동점 조건이며 모델 정확도 예측, 정확도 차별화 coverage 또는 다른 층보다 높은 성능의 증거가 아니다. QA04도 실제 Rust diff가 아닌 `concept::` 운영 모듈의 예상 변경 수다.

### QA01 화면과 별도 첫 음성 종료점

| 구성 | 입력 종료부터 첫 구체적 화면 표시 | 같은 입력 종료부터 첫 구체적 음성 출력 |
| --- | ---: | ---: |
| D-A | 0.923333초 | 1.068708초 |
| D-B | 0.923333초 | 1.275625초 |

화면 표시를 공통 QA01로 유지한다. 음성은 별도 열이며 두 값을 평균하거나 대체하지 않는다. 첫 음성은 실제 장치 출력에 대응해 작성한 가상 사건이다. 장치를 계측했다는 뜻이 아니다. Agent source 발생부터 전달까지의 별도 진단은 사용자 입력 80개의 QA01에 섞지 않는다.

### 같은 입력에서 실행이 달라지는 지점

S03-05에서 사용자는 “보고서는 6월 기준으로 다시 해줘. 메일 질문부터 들려줘”라고 말한다. 양안은 같은 정정 의미를 채택하고 보고서 판본을 바꾼다. A는 앞서 도착한 유효한 메일 질문의 음성을 준비했고 B는 발화 선택 뒤 생성한다. A는 사용하지 않을 5월 보고서 음성도 준비해 폐기 비용을 부담한다.

| 사건, 현재 발화 종료 기준 | D-A | D-B |
| --- | ---: | ---: |
| 정정 의미 채택 | 0.867초 | 0.867초 |
| 정정 수행 의도 화면 표시 | 0.947초 | 0.947초 |
| 메일 질문의 첫 음성 | 0.947초 | 1.348초 |
| 6월 결과 화면 표시 | 3.467초 | 3.467초 |
| 6월 결과의 전체 음성 준비 | 5.784초 | 6.499초 |

S05에서 B가 복귀할 때는 보존한 유효 음성을 먼저 사용하고 미생성 후반만 요청한다. 전체 재생성을 강제하지 않는다. S01과 S06은 시간 및 비용 동점이다. S03/S04에서 A의 구판 생성 비용이 발생하고 S05에서는 A가 B의 후반 재개 문맥 비용을 피한다.

QA03은 목표의 인과 그래프에서 외부 업무, 사용자 대기와 순수 재생 duration을 0으로 투영한 값이다. S08의 실제 첫 음성 이익은 50ms지만 QA03 차이는 더 크다. 투영 뒤 남는 생성 및 의미 채택의 병행/직렬 차이를 실제 wall-clock 단축량으로 바꾸지 않는다. 유형별 QA03의 단순 평균도 사용하지 않으며 90개 목표를 직접 평균한다.

### 받아들이는 부담과 가정의 민감도

D-A는 D-B보다 첫 음성이 평균 0.206917초 빠르고 QA03은 0.744926초 작다. VIA 모델 비용은 0.255213334 USD 증가하며 B 대비 약 11.47%다. 같은 순간의 RAM 최고량 차이는 0.152336 MB로 작다. 서로 다른 시점의 audio peak를 더해 RAM 차이를 키우지 않는다.

QA04는 C04에서 5/4개, C06에서 4/3개, 나머지 네 과제에서는 같은 수를 가정해 A 14/6, B 12/6이 된다. A의 준비와 보관에 공통 section/extent 인터페이스가 이미 충분하면 두 추가 변경이 없어져 A도 12/6으로 동점이 될 수 있다. 0.33모듈 차이를 구조의 필연적인 결과로 주장하지 않는다.

DP44의 QA05는 80평가, 80준비, 미사용 구판, 취소 tail과 재개 문맥을 포함한 VIA 비용이다. 수신 Agent 내부 비용은 **미모델링**이므로 수신 비용과 시스템 역할 합계는 `null`이다. 이를 0 또는 VIA 비용과 같은 전체 비용으로 표시하지 않는다. 자체 무과금 모델에 이 과금형 가상 요율의 USD 차이를 적용하지 않는다.

## 4. 각 층 안에서의 조건부 개별 권고

| DP | 권고 | 선택 이유 | 받아들이는 손실과 재검토 조건 |
| --- | --- | --- | --- |
| DP2 | B | Text에서 첫 화면 0.326초와 목표 처리 0.845초 감소 | 대상 -1.60%p, 전체 의미 -4.583%p, VIA 비용과 RAM 증가. 후속 입력이 드물거나 기존 문맥 의존이 높으면 재검토 |
| DP3 | A | Voice/Screen에서 R2보다 첫 화면과 목표 처리 1.817초 감소 | 같은 대상 오류에 의한 QA02/07 손실과 VIA 비용 증가. 정확도 우선 또는 재사용 중심 조건이면 재검토 |
| DP5 | B | Text에서 첫 화면 0.469초와 목표 처리 0.775초 감소 | 전체 의미 -2.917%p, 사전 생산 비용과 RAM 증가. 미생산 또는 무효 관계와 현재 목적 적용 오류가 많으면 재검토 |
| DP44 | A | 화면과 고정 정확도 동점 뒤 QA03에서 0.745초 감소. 별도 첫 음성도 0.207초 감소 | VIA 모델 비용 약 11.5% 증가와 예상 변경 범위. 사용 전 철회가 잦거나 유효 선행 준비가 적으면 B가 유리할 수 있음 |

기존 QA01→QA02→QA03→QA04→QA05→QA06 순서로 각 비교를 읽으며 QA07의 순위와 점수는 새로 만들지 않는다. DP44에서도 화면 QA01을 음성으로 바꾸지 않고 같은 순서에서 권고한다. 고정 정답 fixture는 실제 자격 시험 통과를 뜻하지 않는다.

각 권고는 작성한 사례와 가정에 한정한 설계 판단이다. `2B+3A+5B+44A`의 결합 성능이나 사용자 채택, accepted ADR 변경은 없다. 준비, 호출, 현재성 검사와 상태를 공유하는 결합안은 같은 입력과 profile에서 따로 작성해야 한다. A1 같은 준비 제한 tactic도 이 기본안 수치에 포함하지 않았다.

## 5. 보존과 검증의 의미

v2와 DP44 부모 자료를 보존하고 새 판본에서 원장 연결 및 집계를 확인한다. Text와 Voice/Screen의 이전 49개 원값을 유지하며 DP44 14개 공통 값과 별도 음성 2개를 추가한다. 새 검토가 확인하는 것은 입력 및 목표 연결, 계산과 표시의 일관성이다. 실제 오류 빈도와 모델 속도, 장치 성능의 검증은 아니다.

독립 검토의 발견, 수정 및 재확인과 Excel/HTML 검증의 실제 범위는 [이관 및 검토](04-migration-and-review.md)에 기록한다. 검토 상태를 표시 완료나 실측 완료와 혼동하지 않는다.
