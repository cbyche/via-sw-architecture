# DP2, DP3, DP5, DP44의 공통 QA 층별 평가

2026-10-22 / `COMMON-QA-SYN-3.0` / **SYNTHETIC_AUTHORED_NOT_MEASURED**

**같은 QA 의미를 유지하면서 Text 이력, Voice/Screen, 음성 전달의 세 평가 층을 함께 관리한다.** [v2](../qa-common-synthetic-v2-20261021/README.md)의 7개 구성에 [DP44 전달 비교](../seven-problem-review/dp44-local-voice-execution-20261021/synthetic-comparison-20261022/README.md)의 D-A와 D-B를 추가한 판본이다. 총 26개 사례군과 9개 구성을 다루며, 공통 QA01 화면 표시를 포함한 QA01~07의 대표값은 63개다. DP44의 첫 음성 2개 값은 별도 진단 열에 둔다.

세 층은 같은 모델 시간식, 원본, 준비 활동이나 목표 분모를 가진 단일 제품 시험이 아니다. 같은 층 안의 대안에 같은 입력과 정답 및 완료 조건을 적용하고, 다른 층의 절대값은 합산하거나 성능 순위로 읽지 않는다. 모든 사건과 수치는 작성한 가상 자료이며 실제 모델 실행, 장치 관측이나 제품 시험 결과가 아니다.

기존 조건을 전제로 한 개별 권고는 **DP2 B, DP3 A, DP5 B, DP44 A**다. 이 조합을 동시에 적용한 제품의 성능을 평가하거나 채택한 결과가 아니다. DP44에서는 화면 QA01과 고정 정답 fixture가 동점이고 QA03의 작성된 차이가 A 권고의 근거다. 별도 첫 음성 이익은 화면 QA01을 대체하지 않는다. QA02와 QA07의 100%는 동일한 올바른 의미를 공급한 제어 조건이므로 정확도 차별화 coverage로 세지 않는다.

DP44의 VIA 모델 비용에는 준비, 미사용 구판, 취소 후 생성과 재개가 포함된다. 수신 Agent 내부 비용은 미모델링이므로 수신 비용과 시스템 전체 비용은 `null`이며 0이 아니다. QA04의 A 2.333과 B 2.000은 예상 모듈 경계에 따른 값이고, 공통 범위 인터페이스가 이미 충분하면 A도 2.000이 되는 민감도를 함께 보존한다.

추가 일관성 검토 판본은 `COMMON-QA-SYN-3.0-REVIEW-2`다. 기존 65개 원값을 보존하면서 QA07의 집합/순서와 대소문자 판정, 부분 표시와 전체 의미 확정의 추적, 수치 표시를 통일했다. VOICE와 DELIVERY는 기반 가정만 560 MB여서 512 MB 시스템 요구를 넘는다. 이 층의 권고는 해당 합성 profile 안의 상대 비교이며 제품 요구 충족을 뜻하지 않는다.

v1, v2, DP3와 DP44의 원본 문서 및 원장을 덮어쓰지 않는다. v3는 출처를 고정한 부모 사본에서 별도 산출물을 만들며, 새 원본 판본을 받아들일 때는 새 dataset과 출력 경로를 만든다. 독립 검토와 재계산, Excel 수식 및 렌더, HTML 오프라인 동작 검증을 마쳤고 미해결 P1/P2는 없다. HTML 브라우저 시각 확인은 보안 정책으로 차단됐으며 native Windows Excel은 미수행이다. 발견과 수정, 실제 확인 범위는 [04](04-migration-and-review.md)에 기록한다.
