# 공통 QA v3 일관성과 수치 범위 재검토

2026-10-22 / `COMMON-QA-SYN-3.0-REVIEW-2` / **SYNTHETIC_AUTHORED_NOT_MEASURED**

## 1. 범위와 검토자 구분

사용자의 추가 전체 점검 요청에 따라 문서, JSON, Excel과 HTML의 의미, 집계와 범위 및 표시를 검토했다. 최초 v3 `8b2f555f8b89eaa5a6a7085ca6323cd44a1adbd7`를 기준으로 65개 대표 원값을 보존한다. 이전 [문서 검토](01-independent-document-artifact-review.md)와 [코드 검토](02-independent-code-data-review.md)는 당시 범위와 hash를 유지하며, 이번 재검토의 완료 근거로 소급 변경하지 않는다.

| 담당 | 실제 역할과 독립성 |
| --- | --- |
| `v3_data` | 원장 생성기 수정과 자체 산술/재생성 검사. 자신의 코드에 대해서는 자기검토. 주 작성자가 쓴 문서 01/03/05 및 안내는 데이터와 별도로 대조 |
| `v3_artifacts` | Excel/HTML 생성기 수정, 수식 변이와 원복, export/렌더 자체 검증 |
| `verify_handoff_commits` | 데이터 및 표시 생성기를 작성하지 않은 독립 검토. 세 판정 경로, 직렬화 원장, 저장 XLSX와 HTML 내용을 직접 대조 |
| 주 작성자 | 문서 수정, 생성기 함수를 가져오지 않는 별도 교차 검사기 확장, 저장소 검사와 변경 범위 관리. 자신이 수정한 검사기의 확인은 독립 검토와 구별 |

SEM-01 수정 중 Python의 `False == 0`, `True == 1`과 int/float 구별도 추가 확인했다. 비교 범주를 JSON의 null/boolean/number/string으로 맞추어 boolean과 number는 다르고 1과 1.0은 같게 했다. 누락, false와 null도 구별한다. 이는 현재 원값을 변경하지 않으면서 앞으로 같은 오류를 놓치지 않기 위한 검사 보완이다.

## 3. 수치와 원장 검증

독립 검토자는 생성기 결과를 그대로 승인하지 않고 직렬화된 행에서 다음을 다시 계산했다.

- 기존 v2의 49개와 최초 v3의 전체 65개 값이 정확히 유지된다.
- 9구성의 QA01/03/04 최소/최대와 분모, QA02/07 성공 수, 사례별 VIA 총비용, 사례별 동시 RAM peak 및 512 MB 상태가 범위 원장과 맞는다.
- 모든 현재 지연, duration, 사용량, 요율, 비용과 RAM은 유한하고 0 이상이다. 판정은 0/1이며 비율은 0~1이다. 각 목표의 QA03은 해당 경과시간 이하이다.
- 1,200목표의 부모 의존을 남긴 투영 경로가 원장과 맞는다. DELIVERY의 90목표를 8개 사례군 평균으로 다시 평균하지 않는다. TEXT도 원래 목표 분모를 유지한다.
- 1,360응답의 표시와 전체 의미 확정 경계가 원본에 연결된다. T-EXEC 부분 표시 70개와 VOICE의 채택/표시 구간을 보존한다.
- 준비 비용은 활동 단위 분류이며 폐기비는 그 부분집합이다. 수신 Agent와 전체 비용의 미모델링 null을 0으로 바꾸지 않는다.

작성자는 부모 고정본만 있는 별도 임시 경로에서도 재생성했고, byte 동일성과 부모 변조 거부를 확인했다. 이 재현성 검사는 자체 검사이며 독립 검토와 구분한다. 실제 모델 속도, 오류 빈도, RAM이나 가상 요율의 현실성을 검증한 결과는 아니다.

## 4. 문서와 산출물 확인

독립 검토자는 저장된 XLSX XML에서 1,360행의 부분 여부, 전체 확정 t/interval, 두 노드와 QA07 저장값을 원장과 대조했다. 저장된 HTML의 같은 경계 필드와 범위 및 판정 policy도 일치했다. 주 작성자의 별도 검사기는 10시트의 수식 오류, 65개 QA와 숫자 비용 50칸 및 미모델링 4칸, 모든 의미 문자열을 다시 읽었다.

표시 작성자는 8,122수식의 오류 및 누락 캐시, 세 층 단가 변경/원복과 문자열/순서 변이 검사를 수행했다. 10시트에서 주요 영역 PNG 22개를 생성해 확인했다. 이는 모든 행을 시각 검사했다는 뜻이 아니다. HTML은 최소 DOM 하네스에서 9구성 필터, 검색, 오류 모드, 선택 및 source/부모 노드, 부분 표시와 전체 확정, 범위와 반올림 표시를 확인했다.

Excel 의미 셀의 canonical JSON은 export 전에 생성한다. `EXACT` 수식 자체가 수동 입력한 임의 JSON을 재정규화하지는 않는다. 이 편집 범위를 문서와 산출물 설명에 명시했으며 원자료의 전체 의미 판정을 변경할 때는 생성기 경로를 사용한다.

문서 작성과 분리한 검토자는 [01 계약](../01-common-contract.md), [03 수치와 판단](../03-results-and-decisions.md), [05 범위](../05-numeric-ranges-and-interpretation.md) 및 안내의 표와 주장, 비용 phase, 분모와 512 MB 조건을 데이터와 대조했다. 현재 검증의 hash와 실제 실행 명령은 [발행 전 기록](../../../../../presentations_files/qa-common-synthetic-v3-20261022/publication-validation.json)에 남긴다. 이전 검증 보고서는 [보존 폴더](../../../../../presentations_files/qa-common-synthetic-v3-20261022/validation-history/8b2f555/README.md)에 유지한다.

## 5. 상태와 한계

**PASS_WITH_RECORDED_LIMITS.** 기록한 발견은 수정 후 재확인했으며 검토 범위 내 미해결 P1/P2는 없다. 수치의 적절성은 작성된 단위와 분모, 수학적 범위 및 가정 안의 일관성까지 확인했다. 목표와 점수에 맞추기 위해 부모 계수나 오류를 조정하지 않았다.

HTML 브라우저 시각 검증은 기존 file URL 보안 정책 차단으로 미완료이며 다른 접근으로 우회하지 않았다. Native Windows Excel은 실행하지 않았다. 실제 모델 호출, 제품 실행과 장치 관측은 모두 없다. 512 MB를 초과한 합성 profile의 상대 권고를 제품 적합 판정이나 실측 승리로 읽지 않는다.
