# DP51 음성과 화면 Interaction의 수집 및 시간 정합 구조

2026-10-23 / 구현 수준 설계 탐색 v1 / 사용자 검토용

**늦게 도착하거나 수정된 전사가 발화 당시의 선택, 포인터와 화면을 다시 참조하게 하면서 수집, 복사와 보관 자원을 유한하게 유지하는 문제**를 다룬다. DP51은 사용자가 이번 주제에 지정한 번호다. 이전 DP3/DP47의 대안, 기존 QA 점수나 선택 결과를 승계하지 않는다.

## 이번 범위의 결과

한 실행 흐름을 OS 입력부터 자료 회수까지 따라가며 다음을 구체화했다.

1. 음성 샘플 시각, 전사 수신 시각, 화면 렌더 시각, 복사 완료 시각과 선택 조회 구간을 분리한다.
2. OS callback은 작은 사건과 유한한 캡처 작업만 넘긴다. UI Automation 조회, GPU 복사 완료와 의미 분석을 callback에서 기다리지 않는다.
3. 과거 화면의 실제 소유자, 소비자의 사용권, 복사 중 자원과 회수 조건을 정의한다. 사용 중인 버퍼를 ring의 다음 항목으로 덮어쓰지 않는다.
4. 이 실행 경로에서 **독립 이미지 보관**과 **기준 이미지 및 변경분 보관**의 구조 차이가 나온다. 읽기 의존성, 복사량, 복원 작업과 회수 단위가 다르다.
5. **사건 후 캡처만 수행하는 방식**은 이미 지나간 화면과 클릭 없는 포인팅의 지원 한계가 있다. 동등한 전체 기능 대안으로 확정하지 않는다.

현재 판단은 독립 이미지 구조로 수집 및 수명 계약을 명확히 하고, 변경분 구조를 메모리 제약에 대한 경쟁 구현으로 유지하는 것이다. 첫 구조를 먼저 설명한다는 사실은 제품 승자 선택이 아니다. 프레임 수, 주기, 보관 시간, checkpoint 간격은 아직 제품 상수로 확정하지 않았다.

## 적용 기준과 경계

- [INTENT](../../../../../../INTENT.md), [저장소 규칙](../../../../../../AGENTS.md), [현재 패키지 규칙](../AGENTS.md)을 따른다. 최신 사용자 지시에 따라 이 폴더에만 작성한다.
- [대표 UC](../../../../05-representative-use-cases.md)의 UC-03/04 및 관련 실패 조건을 유지한다.
- [현재 QA 기준](../qa/README.md)을 참조한다. 보관 정확도를 새 QA02 의미로 바꾸거나 CPU 복사 비용을 QA05 모델 사용 비용으로 세지 않는다.
- [참조 구조](../../../target-architecture/architecture.md)의 Interaction Manager와 [기억 수명 계약](../../../target-architecture/memory-and-context-lifecycle.md)은 참고 자료다. 이번 스케치는 참조 구조의 승인된 변경이 아니다.
- 개발 및 기존 평가의 Mac 환경과 제품 맥락의 Galaxy Book을 구별한다. 이 문서의 구체 API binding은 Windows 설계 가정이며 최소 빌드 및 앱 지원 검증은 미수행이다.
- 다른 주제에는 입력 판본과 evidence 사용권/누락 계약만 제시한다. 여러 업무의 대화 실행, 실행 정정, 사용자 전달과 Agent 단계 실행은 각 담당 주제의 권위다.

공용 README와 manifest, 다른 DP, QA, 평가 및 ADR는 수정하지 않았다. 공용 목록에 DP51 진입점을 추가할 필요는 [검토 기록](review.md)에 남겼다.
