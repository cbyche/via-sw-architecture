# 변경 영향과 동기화

> **2026-10-23 최신 시간 계약:** QA01-VOICE-v2, QA03-COMPLETION-v1과 [측정/전달 계약 v2](../qa/timing-measurement-contract.md)를 따른다. QA01 NORMAL 평균 2초와 WAIT 별도 표시, QA03 평균 5초 및 0~6점이 합의됐다. 계약, 원장, 계산기, JSON/Excel/HTML과 해설을 새 판본으로 갱신하고 기존 결과와 PPTX는 보존한다.

## 자료별 변경 순서

| 바뀐 내용 | 먼저 수정할 정본 | 함께 확인할 자료 |
| --- | --- | --- |
| 대안의 책임, 호출, 상태와 수명 | 해당 DP 설계와 상세 계약 | SVG/draw.io/PNG, QA 인과, 적용 시나리오, 발표 구조와 노트 |
| QA 정의 또는 관측 경계 | `qa/`의 해당 정의와 변경 기록 | 시나리오 관측 단위와 정답, 평가 계약, 기존 결과 호환성, 발표 용어 |
| 목표와 0~6점 구간 | 해당 QA 문서와 목표 근거 | 구간의 중복과 공백, 양안 공통 적용, 수치표와 발표. 원값은 유지 |
| 사례, 분모 또는 완료 조건 | 해당 시나리오 원장과 판본 | 모든 비교안의 적용 범위, 평가 계약, 대표값. 이전 모집단과 단순 합산 금지 |
| 평가 원장 또는 산식 | 새 dataset과 출력 판본 | Excel, HTML, CSV, 설명, 검증과 발표의 근거 표기 |
| 발표 표현과 배치 | 새 PPTX 판본과 작성 원본 | 편집 가능한 그림, 슬라이드별 근거, 미리보기와 제작 검사 |

동기화할 자료를 한 작업에서 갱신할 수 없으면 [패키지 README](../README.md)의 미반영 상태에 원본 판본, 영향받는 DP와 페이지, 남은 작업을 적는다. 완료되지 않은 자료를 최신 기준이라고 표시하지 않는다. 변경 중인 초안, 검토를 마친 문서와 사용자가 채택한 대안은 별개다.

## 판본과 근거

`package-manifest.json`의 이관 원본과 commit은 출처다. `EDITABLE_SOURCE`인 현재 설계, QA와 그림은 같은 경로에서 편집한다. 이관 당시 byte 동일성이 후속 편집을 금지하지 않는다. `IMMUTABLE_SNAPSHOT`인 기존 PPTX와 평가 산출물은 해시로 보존을 확인한다. 이 산출물의 변경본은 새 이름으로 만들고 README의 현재 링크와 원장을 함께 갱신한다. 이전 산출물과 검증 보고서를 새 파일의 성공 증거로 재사용하지 않는다.

공통 QA v3는 Text 이력, Voice/Screen, Voice Delivery의 서로 다른 profile을 관리한다. 실제 모델 캠페인의 수치를 이 합성 평가에 붙이거나 서로 다른 profile의 이익을 더하지 않는다. COMMON-28은 QA 목표와 점수 도출의 기존 모집단이고 v3의 26개 사례군과 같은 집합이 아니다.

## 현재 미반영 상태

새 [QA08-LOCAL-MEM-v1](../qa/qa08-on-device-model-memory.md)은 사용자 지정 1 GB 미만 목표와 DP 공통 계측 설계다. v3/v4, Excel/HTML과 발표 v10에는 새 QA08을 반영하지 않았다. 적용 대상은 추가 모델을 쓰는 모든 DP이며 DP3은 구체적인 설명 예다. 후속 평가에는 추가 자원의 귀속과 동시 피크를 확인한 새 판본이 필요하다. QA06 전체 RAM에서 모델 메모리를 임의로 제외하지 않는다.

동일 입력 비교는 [공통 QA v4](../evaluation/common-qa-v4/README.md)에 새로 작성했다. 문서, JSON, Excel과 HTML은 v4 원장으로 동기화했다. v3의 bytes와 발표 v10, 설계 그림은 보존한다. v10의 네 DP 수치와 평가 설명에는 v4가 미반영이며 후속 발표 개정 때 같은 입력·단위·미관측 정확도·조건부 계산 표기를 함께 갱신해야 한다.

2026-10-22 이관에서는 사용자 확인 v10 PPTX와 QA v3 원장 및 산출물의 bytes를 보존했다. v10에는 DP2의 기존 PoC, DP3와 DP44의 합성 예시, DP5의 미평가 상태가 남아 있다. QA v3에는 네 DP의 조건부 개별 권고가 있다. 이 차이를 숨기지 않으며 이번 자료 정리로 발표 내용까지 재평가한 것으로 표시하지 않는다.

QA07은 [QA07-REQUEST-RESPONSE-v2](../qa/qa07-request-meaning-accuracy.md)의 요청 해석 및 응답 적합성으로 확장했다. 이전 입력 의미 90%/점수/결과는 보존하고 새 사례 단위 목표와 점수는 미정으로 둔다. 상세 사례와 응답 의무/관측창 확정 없이 평가 값을 전용하지 않는다. DP44 설계 변경이나 별도 정확성 QA 신설을 포함하지 않는다. QA06/QA08의 범위와 요구는 유지한다.
