# DP53 요청 변경에 따른 진행 중 실행 제어 구조

2026-10-23 / 사용자 지정 탐색 번호 / 구현 수준 설계 탐색 1차 검토본

**정정 후 이전 실행의 확정 권한을 먼저 회수하고, 실제 연산 종료와 외부 실행 확인을 별도로 수거한다.** 이 공통 조건을 구현한 뒤, 요청 판본마다 실행을 교체할지 진행 중 연산을 새 실행이 인수할지 비교한다. DP53 번호는 사용자 지정 작업 위치이며 대안 채택, 주요 DP 적격 판정 또는 구현 완료를 뜻하지 않는다.

## 이번 범위와 상태

- 업무 ID를 이미 정확히 알아도 발생하는 정정과 실행 제어가 중심이다. 의미 해석과 외부 Agent의 지능을 대안 차이로 사용하지 않는다.
- Rust 형태의 코드는 설계 의사코드다. 제품 코드, Cargo 프로젝트, 실행 가능한 PoC, 새 모델 호출과 측정 자료는 만들지 않았다.
- 1차 산출물은 검토 가능한 문제 분석과 코드 수준 설계 탐색으로 완결한다. 제품 대안 선택, capability 확인과 성능 판정은 미완료이며 별도다.
- 큐 용량은 소유자와 제한 방식을 명시하지만 장비 근거 없는 숫자를 넣지 않는다. 정확한 최대 부하와 종료 deadline은 미확정이다.
- 기존 DP2/DP3/DP5/DP44, QA 의미와 점수, Reference Architecture, 평가와 ADR는 변경하지 않는다. 기존 측정값을 DP53 결과로 사용하지 않는다.
- 이번 본문은 코드와 사건표가 정본이다. 새 설계 그림과 발표자료는 아직 작성하지 않았으며 기존 그림을 DP53 도식으로 재명명하지 않았다.

상위 [AGENTS](../AGENTS.md), [INTENT](../../../../../../INTENT.md), [제품 범위](../../../../03-fixed-architecture-scope.md), [대표 UC](../../../../05-representative-use-cases.md), [현재 QA](../qa/README.md)를 따른다. 최신 사용자 지시에 따라 편집 범위는 이 폴더다.

## 다른 주제와의 연결

| 상대 주제 | DP53이 사용하는 경계 |
| --- | --- |
| DP51 음성과 화면 근거 | 불변 근거 참조, 원본 판본, 읽기 lease와 수명. 수집/정렬 알고리즘은 DP51 |
| DP52 여러 업무의 대화 실행 | 채택한 요청 변경과 정확한 대상 ID, 입력 보류의 해제. 대상 판단 알고리즘은 DP52 |
| DP54 Agent 메시지 전달 | 현재 내용 판본, 출력 허가 철회, 실제 전달 receipt. 알림 선택과 묶음은 DP54 |
| DP55 Agent 간 단계 실행 | 외부 실행/명령 correlation과 결과 판본. 사용자 지정 단계와 의존 관계 설계는 DP55 |

이는 제안 인터페이스이며 다른 세션에서 이미 채택했다고 주장하지 않는다. 사용자 지시에 따라 다른 DP 폴더와 공용 파일을 수정하지 않았다.

## 공용 연결 담당에게 남기는 항목

공용 `current/README.md`와 필요한 탐색 원장에 이 README를 DP53 진입점으로 연결할 수 있다. 링크 추가만으로 기존 네 DP 평가/발표 구성에 DP53을 포함하거나 package manifest의 보존 원본으로 등록하지 않는다. 이 공용 연결은 본 세션에서 수행하지 않는다.
