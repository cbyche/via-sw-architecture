# DP02 설계 그림

이 폴더의 SVG, draw.io와 PNG는 확인한 기존 설계 그림을 함께 이관한 것이다. 새 렌더나 성능 측정을 수행한 자료가 아니다. [설계 본문](../design.md)과 최신 구조 계약을 함께 읽는다.

그림의 데이터와 라벨은 이관 전 원본을 유지했다. 원본 Scene과 생성기 링크의 기존 출력 경로는 아직 이관되지 않았으므로 생성기를 그대로 실행해 이전 위치를 덮어쓰지 않는다. 후속 그림 수정은 출력 위치를 현재 폴더로 명시한 뒤 SVG, draw.io, PNG와 발표 파생본을 함께 갱신한다. 각 그림의 원본 경로와 SHA-256은 [설계 이관 원장](../../design-migration.json)에서 해당 파일의 출처를 확인한다.
