# v3 문서와 표시 산출물 독립 검토

2026-10-22 / **SYNTHETIC_AUTHORED_NOT_MEASURED**

문서 초안 작성과 Excel/HTML 작성에 참여하지 않은 `v3_data` 검토자가 문서와 표시 생성기 및 산출물을 검토했다. 이 검토자는 본인이 작성한 데이터 생성기와 JSON 정규화를 독립 검토 범위에서 제외했다. 해당 부분은 [별도 코드/원장 검토](02-independent-code-data-review.md)가 담당했다. 아래 기록은 주 에이전트가 검토자의 보고와 재확인 결과를 정리한 것이다.

## 범위와 결과

README와 공통 계약, 구성/시나리오, 수치/판단, 이관 기록과 산출물 안내를 검토했다. QA01 화면/음성/source의 구분, 90목표와 원래 시작 -6초, 고정 정확도 fixture, 준비/폐기 비용과 null 수신 비용, QA04 민감도와 개별 권고의 한계를 확인했다. 정량 표에 새 불일치는 없었다.

독립 검토에서 HTML의 빈 단계 의존과 반대 구성 source 혼입을 P2로 발견했다. 주 에이전트도 단계 의존 누락을 별도로 발견했다. DELIVERY 의미 배열의 정렬은 검토자가 P3 보완으로 보고했고 주 에이전트는 요청한 읽기 순서의 의미가 사라지는 영향에 따라 P2로 분류했다. 중복을 제거한 통합 목록은 [04 검토 기록](../04-migration-and-review.md)에 있다.

| 발견 | 수정 및 재확인 |
| --- | --- |
| HTML에서 없는 `deps`를 사용 | `parents`를 보존/표시하고 최종 HTML에 부모 ID가 있는지 확인 |
| source 상세의 구성 필터 누락 | `config_id`와 `case_id`로 제한하고 반대 안의 source가 빠지는지 확인 |
| DELIVERY 요청 의미의 순서 배열 정렬 | 의미 순서를 보존하고 저장된 XLSX 160행 대조. 생성 담당자는 순서만 바꾼 QA07 재계산/원복도 수행 |
| “화면 63개” 표현 | 화면 QA01을 포함한 공통 QA01~07 총 63개 값으로 정정 |

최종 원장 SHA256 `9ed86349876d8c094622d05d975bff17237749a926c26715498466a471370646`와 표시 검증 보고의 source hash가 일치함을 확인했다. 63개 공통 QA와 별도 음성 2개, 비용 숫자 수식/캐시 50개와 결측 빈칸 4개를 확인했고 XLSX 오류 셀은 0개였다. DP44 요약과 비용 PNG도 확인했다.

주 에이전트가 작성한 [교차 검사기](../../../../../../../../scripts/presentations/check_common_qa_delivery_v3.py)를 추가로 읽고 실행했다. QA 셀의 완전한 구성 집합과 저장된 비용표 50개 캐시를 직접 검사하도록 보강 제안을 반영한 뒤 PASS를 재확인했다.

**최종 상태: 검토 범위 내 미해결 P1/P2 없음.** 실제 브라우저 화면이나 native Windows Excel 검증은 이 독립 확인에 포함하지 않았다. 오프라인 DOM 하네스와 생성 엔진의 렌더를 실제 브라우저 또는 Excel 실행으로 표현하지 않는다. 실제 모델이나 제품 성능도 검증하지 않았다.
