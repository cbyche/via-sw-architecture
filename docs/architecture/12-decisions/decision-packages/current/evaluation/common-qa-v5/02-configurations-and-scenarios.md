## 선행 조건과 변경 이유

U19의 v4 생성 -2초와 사용자 발화 시작 -3초는 중단 순서에 맞지 않았다. v5는 양안 모두 생성 -4초, 발화에 의한 중단 -3초로 수정한다. 그 전에 실제 재생한 prefix를 재개 구간에서 뺀다. U20은 잔여12초 buffer를 공통 초기 상태로 사용한다. 관측창 이전에 처리한 R0 등은 초기 상태이며 새 Agent 사건으로 만들지 않는다. 관측창 안 사건의 source 시각 누락은 제외가 아니라 UNOBSERVABLE이다.

U08/16/24는 최초 목표 -6초부터 계산한다. 정정으로 시작을 재설정하지 않는다. 배경 업무는 이번 관측창에 새 결과를 제공하지 않는 조건이다. Agent 결과는 해당 요청 접수 후 공통8초 업무가 끝나는 인과 사건이라 절대 도착 시각은 VIA 준비에 따라 달라진다. 사용자 입력 일정과 외부 업무 길이를 후보 결과에 맞춰 바꾸지 않는다.

7구성은 BASE(A/A/A/A), DP2-B, DP3-B-R1/R2/R3, DP5-B, DP44-B다. 한 DP만 바꾸며 네 A행은 같은 BASE의 재표시다.
