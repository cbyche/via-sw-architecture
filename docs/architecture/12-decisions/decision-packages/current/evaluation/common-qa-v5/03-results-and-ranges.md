## 수치의 해석과 한계

DP2는 실행 슬롯과 의존 관계, DP3는 CPU 후보 생산·적재·회수, DP5는 사전 관계 생산과 재사용, DP44는 선행 음성 준비와 선택 후 생성의 차이를 계산한다. 원하는 차이나 점수를 만들기 위해 속도·사례 비중을 조정하지 않았다. QA01/03의 공통 병목은 그대로 둔다.

QA01 2초는 4초 참조 대비50% 단축이라는 사용자 합의 목표이며 연구의 달성 성과가 아니다. QA03은 Windows Long wait 상단을 채택한 VIA 처리 예산5초다. 원값 평균에 합의한1초 우수선과 균등 구간을 적용했다. [QA01 근거](../../qa/research-notes/qa01-voice-target-rationale.md), [QA03 근거](../../qa/research-notes/qa03-completion-target-rationale.md).

QA08은 추가 로컬 시각 모델 runtime, weights, workspace, load temporary, IPC, 보존 상태의 최고 동시 합이다. v4가 별도 명시하지 않은 모델 전용 프레임/추적 상태32MB를 공개 가정으로 추가해 QA06에도 포함했다. 입력/출력 tensor와 추론 임시는 workspace, 전달 복사본은 IPC에 포함한다. 기본 UI/ASR은 모든 구성 공통이고 의미·음성 모델은 원격이라는 범위에서만 비추가 구성의0MB가 성립한다. CPU 외 전용 가속기 메모리는0이다.

QA08 <1000MB는 요구이며 여기의 추정은 제품 합격 판정이 아니다. 최대 지원 부하·연속운영·5회 실행은 미수행이다. QA06 기반560MB는 기존512MB보다 크며 요구를 낮추지 않았다. QA05의 과거 COMMON-28 $2.55 목표는 이24사례 합계와 직접 비교하지 않는다. QA02/07/08에 미관측을0점으로 넣지 않는다. 실제 WAV·화면 자산과 실행 adapter 및 채택 출력은 미작성이다.
