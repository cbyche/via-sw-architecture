## 이 가정에서 보이는 차이

- DP2 B는 여유 의미 슬롯이 있는 독립 입력에서 먼저 처리하지만 포화와 필수 결과 의존은 기다린다. 추가 실행 상태와 envelope 비용이 있으며 모듈 수 이점은 만들지 않았다.
- DP3 B의 로컬 후보 생산은 클라우드 입력을 줄이지만 이 CPU 가정의 UI/SAM 처리와 적재 비용이 크다. R1은 가중치 회수, R2는 상주, R3는 별도 runtime이다. R3에 자동 병렬 속도 이득을 주지 않는다.
- DP5 B는 준비된 미확정 관계를 재사용하는 입력에서 단축되지만 갱신과 미사용 관계 생산 비용도 낸다. 이미 확정한 사실은 A도 재사용한다. 정확도 이득은 미확인이다.
- DP44의 화면 QA01은 같다. B는 선택한 발화만 생성하여 불필요한 준비를 줄이지만 다음 발화 선택 후의 생성 대기가 늘 수 있다. 유효한 기존 audio는 양안 모두 재사용한다.

어느 구성도 실제 제품 적합성이나 최종 선택을 뜻하지 않는다. 서로 다른 B의 감소량을 합쳐 결합 성능으로 주장하지 않는다.

## 범위의 적절성과 남은 한계

공통 기반 RAM은 560 MB라 기존 512 MB 요구를 이미 48 MB 초과한다. 요구를 맞추려고 값을 낮추거나 기존 요구를 변경하지 않았다. 모든 구성의 제품 RAM 적합성은 미입증이며, 실장 계측과 메모리 설계 수정이 필요하다. DP3의 과거 비교용 RAM cap 예외도 일반 요구 삭제가 아니다.

기존 QA05의 $2.55는 COMMON-28 묶음의 도출값이다. 새 24사례 합계와 직접 합격/불합격 비교하지 않는다. v4의 단가, 토큰 예산, 클라우드 속도, CPU 처리 시간과 RAM은 공개된 작성 가정이며 실제 견적·측정 또는 정답 출력을 근거로 교정되지 않았다. 여기서는 산식과 누락·중복을 검증했으며 숫자가 실제 하드웨어에 맞는지는 검증하지 않았다.

QA02 33표현과 QA07 24입력의 평가자 정답은 준비했지만 후보 출력은 0개다. 최초 의미 채택 증거를 수집한 뒤 별도 판본에서 판정해야 한다. 오류 사례는 제외하지 않고 원래 분모에 보존하며, timeout과 미채택 처리는 실행 전에 동결한다. 현재 QA07 목표/점수의 별도 제안과 이 24입력 묶음도 자동 호환하지 않는다.
