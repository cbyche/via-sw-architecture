# 공통 입력과 구성

`COMMON-QA-MODEL-4.0` / 분석 모델 / [시작](README.md) / [계약](01-common-contract.md)

7개 구성 모두 아래 24개 입력과 동일한 초기 원본, 사건 시각, 목표 및 출력 의무를 사용한다. A/A/A/A를 기준으로 한 DP만 바꾼다. 각 입력은 한 번 계산하며 독립 통계 반복이나 실사용 빈도 표집이 아니다. `source_family`는 v3의 관련 사례를 추적하는 표식이며 같은 시험이나 같은 원시 데이터라는 뜻이 아니다.

| --- | --- | --- | --- | --- |
| BASE | A | A | A | A |
| DP2-B | B | A | A | A |
| DP3-B-R1 | A | B-R1 | A | A |

## 고정 시간과 완료 조건

모든 현재 입력 종료는 0초다. 선행 화면 처리는 -12초, 관계 원본 도착은 -8초, 대기 응답은 -2초 또는 -0.5초, 진행 중 의미 step은 -1초, 피드백 정정은 -0.2초다. 후보 응답 속도에 맞춰 다음 사용자 입력을 당기지 않는다. U08/U16/U24의 기존 목표는 -6초의 최초 2초 VIA 처리부터 계산하며 정정마다 새 목표로 초기화하지 않는다.

QA03의 공통 terminal은 요청한 결과의 UI 상태와 필요한 전체 음성 준비, 취소 정산 또는 재개 후반 준비다. 장치에서 첫 chunk가 나오는 시간은 별도 first_voice다. 사용자에게 실제 전달하는 순수 재생과 Agent 업무 duration은 QA03에서 0으로 투영하지만 순서 의존은 유지한다.
