## 독립 검토와 수정

독립 검토자는 문서/변경 manifest와 생성기/렌더러를 나누어 읽었다. 세 P2 발견을 수정했고 재검토에서 모두 충족했으며 추가 P1/P2는 없었다.

| 발견 | 수정과 확인 |
| --- | --- |
| QA02 태그가 같은 입력의 모든 지칭에 복사됨 | 33개 표현별 태그로 변경. U13의 D2/작성자, U21의 선택 집합/과거 형식/Task를 구별하고 각 원전 대상과 사실을 보존 |
| DP5-B의 미사용 관계 생성 $0.0114가 준비 분류에만 포함됨 | relation_unused를 취소/미사용 분류에 포함. 각 청구 항목을 한 번만 합산하고 모든 구성의 총액과 대조 |
| QA04 빈 registry로 0개를 인정하고 의존성 필드를 생략할 수 있음 | 0개 경로 전 전체 registry의 소스/공개 경계/상태/자산/의존성/기준 commit을 확인. 증명된 0개와 미측정을 구별 |

독립 검토는 소스 읽기다. 아래 생성/재계산과 산출물 검사는 작성 담당이 별도로 실행했다. 실제 후보의 응답을 판정한 독립 평가가 아니다.
