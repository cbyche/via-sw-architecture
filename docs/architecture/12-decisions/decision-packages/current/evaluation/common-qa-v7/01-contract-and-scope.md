# 대표값과 적용 범위

[목록](README.md) / [정의 정본](../../qa/measurement-appendix.md)

각 QA는 동일 의미의 대표값 하나로 비교하고 모집단, 실패/미관측과 근거를 함께 표시한다. 세부 유형을 다시 평균내거나 여러 QA를 가중 합산하지 않는다.

| QA | v7 대표값과 모집단 | 적용 상태 |
| --- | --- | --- |
| QA01 | 구성당 NORMAL 36사건의 첫 실질적 음성 지연 산술평균 초 | v5/v6 원값과 2초 목표/점수 유지. WAIT 6예정 중 5출력과 1철회, L/B/R을 대표 표 옆에 별도 보고 |
| QA02 | 지칭 표현/revision 33개의 최초 집합 완전 일치율 % | 실제 출력 없음. 태그 중복은 대표 분모에 더하지 않음 |
| QA03 | 전체 24목표의 필수 상태/외부 연동/최종 응답 준비를 포함한 VIA 경로 평균 초 | v5/v6 전체 완료 DAG와 5초 목표/점수 유지 |

## 시간 경계 확인

QA01은 입력/외부 사건 제공 시각부터 실제 첫 실질적 음성까지다. 모델 큐와 음성 처리도 포함한다. 사건 원장의 source_s/first_audio_s, 사전 NORMAL/WAIT, 출력 철회 기록을 그대로 보존했다. P95를 추가하지 않는다. 현재 수치는 물리적 음성 관측이 아닌 분석 가정이며, 실제 누락이 있는 실행의 성공 표본만으로 대표 평균을 확정하지 않는다.

QA03은 required_state_nodes, required_external_nodes, required_channel_nodes와 처리 DAG를 그대로 보존했다. 첫 안내로 종료하지 않는다. 외부 Agent 내부 작업/사용자 대기는 제외하되 그 시간과 겹친 VIA 작업은 삭제하지 않는다. 원장과 Excel `목표계산`/`처리단계`, HTML 입력별 전체 원장에서 확인할 수 있다. v7은 새 시간 수치를 만들거나 재채점하지 않았다.

## 변경 증거와 자원 경계

QA04는 각 구성의 동일 기준 commit에서 8개 변경을 독립 수행한다. 운영 모듈 registry는 언어, 소스, 공개 경계, 상태, 의존성과 자산 소유를 포함한다. 실제 patch, 기준 동작, 수용과 회귀 증거가 있어야 고유 수정/추가/삭제/이동 모듈 수를 산출한다. 이미 지원하는 기능의 0개도 증명이 필요하다. 하나라도 미완료면 평균/점수를 내지 않는다. 현재 registry가 비어 있는 것은 모듈 0개라는 뜻이 아니다. 기존 6과제는 Excel `변경과제`와 legacy_changes에 보존한다.

QA05 모델에는 준비와 취소/미사용 생성 비용이 포함되어 있다. 재시도는 이번 분석에 예정하지 않았으며 실측 0회라는 뜻이 아니다. 후속 청구의 실제 종료를 확인한 공급자 원장은 없다. 따라서 현재 합계는 실제 청구 총액이나 반복 평균이 아닌 분석 묶음 비용이다. 로컬 모델 전력/장비 비용이나 Agent 내부 비용을 임의로 더하지 않는다.

QA06/08은 서로 다른 시점의 개별 최고값을 합하지 않고 같은 시점의 자원 합에서 최고값을 취한다. QA08의 호스트 RAM은 QA06에도 들어가므로 두 지표나 절감 효과를 합산하지 않는다. QA06의 기존 분석값은 모두 512 MB를 넘는다. QA08이 0 또는 작더라도 전체 제품 RAM 적합성을 의미하지 않는다. 실제 RAM 관측과 제품 합격 판정은 없다.

현재 모집단과 수치는 새로운 제품 실험이나 사용자 채택의 증거가 아니다. 이전 판본과 PPTX는 변경하지 않는다.
