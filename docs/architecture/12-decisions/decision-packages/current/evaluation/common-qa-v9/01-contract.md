## 입력, 정답과 최초 사용

COMMON-28의 사용자 입력 84개 중 28개를 선정하고 56개 제외 이유를 보존한다. 단위는 `config_id × source_event_id × repeat_id`이며 업무 절/Task/모델 호출/출력 문장 수로 분모를 늘리지 않는다. 모든 대표 실행은 원문 Text로 하고 원전 voice/text는 출처로만 보존한다. 다중 업무도 같은 입력 반복에서 모두 맞아야 성공 1회다.

- **연결:** 입력 시작 상태를 기준으로 NEW 또는 EXISTING과 기존 업무 ID가 모두 맞아야 한다. 업무 alias와 내부 Task ID 정렬은 사전 확인한 adapter/평가자 규칙으로 하고 정답 추론이나 보정은 금지한다.
- **순서:** 사용자 지정 선후 관계를 추이 폐쇄로 비교한다. 동등한 추이 관계는 허용하고, 순환/누락/반전/불필요한 추가 관계는 실패다. 빈 집합도 정답이며 실제 자원 스케줄의 순차 실행은 의미상 선행조건과 다르다.
- **최초 사용:** 명시 commit 전에 위임/상태 변경에 사용했으면 그 시점이다. 부분 채택 이력도 모두 연결하고 실제로 사용한 최초 오류는 후속 정정으로 지우지 않는다. 정정 입력은 자기 최초 판단을 따로 채점한다.
- **제외:** 세부 업무 조건, Agent 내부 계획/도구 순서/실행 성공, 응답 문장과 실제 음성 전달은 점수에 넣지 않는다. 원문 보존/권한/전달 등 기능 의무는 유지한다.

S17-U03은 TS17 검색이 진행 중이고 결과가 없다는 파생 문맥이다. 원전의 새 검색 ingress 일정이나 기존 시간/비용 수치를 가져오지 않는다. S17-U05의 직접 문단 설명, S22-U04/U05의 실제 취소 가능성, S28-U03의 Agent 미접속은 업무 관계 오류로 세지 않는다. S24-U03의 “표 먼저”는 표시 형식이다.

## 관측과 집계

구성당 계획 N은 140이다. 실행 fixture와 조건을 동결하기 전 확정 N은 미산출이다. 최종 전체 일치 정확도는 성공 S/140이며 미판정이 남거나 공통 무효/중복 실행이 있으면 확정 대표값과 점수를 내지 않는다. 공통 원본 결함은 같은 입력의 모든 후보에 공통 적용하며 원 기록을 보존하고 수정 판본에서 재평가한다. 무효 행을 빼서 작은 N으로 계산하지 않는다.

입력 제공부터 60초 안의 최초 채택/사용을 관측한다. 완전한 관측에서 판단이 없으면 FAIL, 필요한 입력/채택 증거가 없으면 UNKNOWN이다. 사용자 답변이나 Agent 완료를 기다리지 않으며 이전 v3의 응답 3단계/300+10초 조건을 승계하지 않는다.

Excel은 다음 근거를 가진 **평가자 판정 입력·집계표**다. 자유 문장을 자동 해석하거나 그래프를 정규화하는 runner가 아니다.

1. 원장에 입력/context hash, 최초 사용 시각/trace, 정규화 구조와 평가자 검토, 최초 부분 채택 및 실패 이력을 기록한다. 정규화 결과는 두 독립 평가자가 원문/trace와 대조하고 불일치를 해결한다.
2. Excel의 순서/연결 PASS/FAIL 두 칸은 위 검토가 끝난 모든 요청 절의 결과다. 두 평가자 참조, 원시 증거와 정규화/불일치 검토 참조 및 입력 제공/최초 사용 근거가 필요하다. 시각은 제공 후 초이며 0~60초의 숫자여야 한다.
3. 무판단 실패는 입력 제공과 60초 완전관측 근거, 실행 키를 요구한다. 이전 입증 오류 참조는 검토가 끝난 실제 사용 오류만 기록한다. 원시 실패 이력은 삭제하지 않는다.
4. fixture 완비와 실행 동결은 해시/초기화/모델 판본/adapter 검증 후에만 기록한다. 현재 모든 fixture와 후보 payload는 미준비이고 980행은 UNKNOWN이다. 노란 칸만 채워서 실행 완료로 간주하지 않는다.

실행 키는 구성 내 중복을 차단한다. 같은 실제 실행을 다른 비교에서 참조해도 독립 관측으로 합산하지 않는다. 네 A행은 같은 BASE다. QA02와 같은 원인에 따른 오류는 공통 cause ID로 연결한다.

## 부록과 해석 한계

순서 있음은 S17-U02/U03의 **2입력/10반복**, 없음은 **26입력/130반복**이다. 전체 정확도만으로 복잡한 다단계 순서가 검증됐다고 설명하지 않는다. S17-U01 명시적 독립 요청의 5반복도 부록에 별도로 보이되 없음 그룹과 중복 합산하지 않는다. 각 유형의 S/F/U와 미산출 상태를 함께 표시한다.

DP2의 해석과 DP5의 이전 업무 관계 복원은 관련 가능성이 있다. DP3는 대상 식별 오류가 업무 연결에 전파되는 경로가 있을 때만 관계가 있으며 Text 시험만으로 화면 grounding 이득을 주장하지 않는다. DP44는 최초 순서/연결 판단 자체를 바꿀 때만 관련된다. 음성 큐 취소/재개 개선만으로 새 QA07 차별화 coverage를 주장하지 않는다. 7구성의 평가 슬롯 존재는 차별화 증거가 아니다.

목표는 TaskBench GPT-4 **2작업 graph accuracy 84.53%**를 정수 상향한 제안이다. 전체 graph accuracy **67.25%**, SMCalFlow **73.751%**와 구별한다. 외부 시험은 VIA의 이 140회와 다르며 숫자 차이는 VIA 개선 성적이나 동일 조건 기준 성능이 아니다. 근거는 [고정 조사](definition-snapshots/qa07-meaning-research.md.txt)에 보존한다. reference harness는 별도 미실행 계획이며 외부 숫자로 그 결과를 채우지 않는다.

QA07 이외의 QA는 v8의 값/미관측 상태를 보존한다. 다른 QA의 기존 24입력 계산과 새 28입력 평가를 같은 실험에서 얻은 값으로 설명하지 않는다. 모델 실행, 성능 재측정과 기존 결과 재채점 및 PPTX 변경은 없다.
