# v9 검토와 검증

2026-10-23. 새 QA07 범위의 적용 매핑과 관측 전 평가표를 검증했다. 실제 제품/모델 실행은 없다.

이전 v8의 검토 통과를 새 범위의 검증으로 전용하지 않았다.

## 독립 검토와 수정

`verify_handoff_commits`, `v3_data`, `v3_artifacts`가 새 v4 계약, 입력 선정/제외, 문서/원장/snapshot과 생성 소스를 읽기 전용으로 검토했다. 중복 제거한 P2 두 건을 수정했고 재검토에서 수정 충족 및 추가 P1/P2 없음으로 확인했다. 리뷰어가 제품/모델이나 산출물 생성기를 실행한 것은 아니다.

| 발견 사항 | 수정과 회귀 확인 |
| --- | --- |
| 순서 또는 연결 한 항목이 FAIL이고 다른 항목이 UNKNOWN이면 입증 실패를 놓침 | 공통 근거 확인과 항목 판정을 분리. FAIL/UNKNOWN 양방향 모두 FAIL 보존을 Artifact Tool 수식으로 확인 |
| 60초 무판단 입증 뒤 61초 최초 사용을 기록하면 실패가 사라짐 | 완전관측 무판단 근거가 있고 첫 사용이 없거나 60초 이후면 FAIL. 뒤늦은 채택을 추가하는 수식 검사로 확인 |

## 수행한 검사

- [계약/재현 검사](artifacts/validation.json): 원전 사용자 입력 84개를 선정28/제외56으로 빠짐없이 분할, 순서 있음2/없음26, S17-U03 파생 문맥, Text 입력, 980 UNKNOWN과 실제0을 확인했다. QA07 이외 원값과 v8 전체 파일 바이트 보존, 생성 재현이 통과했다.
- [Excel 검사](artifacts/artifact-validation.json): 최종20시트. 부모18시트의 181,571셀과 관련 값/수식/서식/validation을 허용한 QA07 연결/안내 변경 외 보존했다. 980기록은 UNKNOWN, 근거 입력은 비어 있고 임시 검사 값은 제거했다. 선정/제외 입력과 2/26 유형·독립 요청 부분집합이 원장과 일치한다.
- 수식 변경 검사: 140/140 성공→100%·6점, 119/140 성공→85%·1점, 근거 누락/같은 평가자/중복 실행/공통 무효, 한 항목의 입증 오류와 늦은 판단을 확인했다. 임시 데이터는 실제 관측이 아니며 최종 파일에 남기지 않았다.
- [HTML 검사](artifacts/html-validation.json): embedded JSON과 원장 일치, 기존144개 입력 비교 handler, 새28개 QA07 선택 handler, 제외56개와 로컬 링크가 통과했다.
- Artifact Tool PNG에서 전체 비교, 새 QA07 요약/근거/기록, 입력/선후 관계/유형 부록과 제외표를 확인했다.
- 현재 패키지, active Markdown 링크/용어, v7/v8/v9 보존·재현 검사와 diff 공백 검사를 통과했다. 기존 발표 v10의 최신 평가 미반영 상태는 알려진 동기화 잔여 사항이다.

## 확인 한계

native Excel과 실제 브라우저 레이아웃 검사는 수행하지 않았다. HTML은 최소 DOM에서 코드와 문자열/링크를 검사했다. 이 파일은 평가자 판정 입력/집계표이며 후보 adapter, 실제 모델 호출, 최초 채택 계측과 실행 fixture를 구현/검증한 runner가 아니다. 제품 성능, 실제 85% 달성, DP 간 정확도 개선과 대안 선택을 입증하지 않는다. 실제 실행은 0회이며 목표/점수/모집단 제안의 사용자 채택은 미확정이다.
