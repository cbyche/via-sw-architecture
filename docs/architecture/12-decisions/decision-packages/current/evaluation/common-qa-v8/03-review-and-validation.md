# v8 검토와 검증

2026-10-23. 이전 확장 범위 QA07 v3의 32사례/5회 평가표 검증 기록이다. 이후 사용자가 QA07을 업무 순서 및 연결 정확도로 재확정했으므로 이 판본을 새 범위의 평가로 사용하지 않는다. [전환 기록](../qa07-scope-transition-20261023.md)을 따른다.

목표와 평가 절차는 작성자 제안이며 실제 실행 결과는 없다. v7의 QA04 및 대표값/부록 검토는 [그 판본의 기록](../common-qa-v7/04-review-and-validation.md)을 따른다. 새 QA07에 과거 검토 결과를 자동 승계하지 않는다.

## 독립 검토

검토자 `verify_handoff_commits`, `v3_data`, `v3_artifacts`가 계약/JSON과 생성 소스를 독립 검토했다. 중복 제거한 P2 두 건을 수정하고 재검토에서 추가 P1/P2가 없음을 확인했다.

| 발견 사항 | 수정 및 확인 |
| --- | --- |
| 유형별 비율이 전체의 유효 분모 조건을 누락 | 전체 확정 N을 요구하도록 수정. 중복 실행 두 행이 모두 FAIL이어도 유형별 비율이 미산출인지 임시 수식 입력으로 확인 |
| 이전 24입력의 1회/고정 시각 정책이 전역 정책처럼 노출 | 기존 분석 전용 정책으로 한정하고 QA07 v3의 5회/인과 트리거 정책을 분리 |

## 수행한 검사와 한계

- 정적 계약/재현 검사 PASS: 32사례, 구성당 계획 160회, 총 1,120개 UNKNOWN, 실제 실행 0회, 부모 v7 바이트 보존, 18개 판정/분모/점수 경계 검사.
- Excel 검사 PASS: 18시트, 부모 109,715셀의 값/수식/관련 서식과 validation 보존. 새 3,360개 단계 슬롯과 1,120개 반복 기록에 관측 입력이 없으며 임시 수식 검사용 값을 제거했다.
- HTML 검사 PASS: 원장 일치, 기존 144개 입력 비교, 새 32개 사례 선택과 로컬 링크. 최소 DOM에서 handler를 실행한 검사이며 실제 브라우저 레이아웃 검증은 아니다.
- Artifact Tool 렌더에서 전체 비교와 QA07 요약을 확인했다. native Excel 실행은 하지 않았다. 검증은 계산표/판정 소프트웨어 검증이며 제품/모델 성능 검증이 아니다.

상세 기계 기록은 [계약 검사](artifacts/validation.json), [Excel 검사](artifacts/artifact-validation.json), [HTML 검사](artifacts/html-validation.json)에 있다.
