# DP3의 이전 설계 자료

이 폴더는 현재 설계의 변경 이유를 확인하기 위한 보존 자료다. 현재 네 대안과 배치는 [CPU runtime 설계](../cpu-runtime-architecture.md), 현재 그림과 책임은 [발표 구조 계약](../presentation-architecture-contract.md)을 따른다.

| 자료 | 보존하는 범위 |
| --- | --- |
| [cpu-small-synthetic-budget.md](cpu-small-synthetic-budget.md) | 이전 작은 CPU 가상 예산. 현재 실행 RAM, 속도 또는 정확도 값이 아님 |
| `diagrams/comparison.*` | 초기 cloud 생산기 비교 |
| `diagrams/local-comparison.*` | caption을 포함하던 이전 local 판본 |
| `diagrams/runtime-residency.*` | v8 이전 CPU 실행 표현 |
| `diagrams/dp3-v7-*` | 호출과 반환 및 후보 확장 표현을 보정하기 전 v7 그림과 Scene |

원본 그림과 수치 및 과거 문구를 그대로 보존한다. 이력의 모델 배치나 당시 권고가 현재 대안의 제약은 아니다. 원래 생성기는 이전 경로에 남겨 두었으며 이관 과정에서 실행하지 않았다.
