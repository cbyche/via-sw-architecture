# QA08 목표 출처: Galaxy Book 기본 탑재 서비스의 메모리 상한

2026-10-22 / `SR-PC-LOCAL-MODEL-MEM-01` / 사용자 지정 프로젝트 요구사항 / 미측정

| 항목 | 기록 |
| --- | --- |
| 요구사항 | 온디바이스(로컬) 모델 추가 메모리 최소화 |
| 사용자 정의 | 시스템은 PC에서 동작하는 온디바이스 모델의 메모리 사용량을 최소화해야 한다. |
| 사용자 지정 지표 | **메모리 사용량 < 1 GB** |
| 사용자 지정 목표 근거 | **삼성 Galaxy Book 기본 탑재 서비스의 메모리 상한 제약** |
| 직접 출처 | 2026-10-22 사용자가 QA08 신설을 요청하며 이름, 정의, 지표와 목표 근거를 직접 지정 |
| 측정 설계 위임 | DP3뿐 아니라 다른 DP에 로컬 모델이 추가되는 경우에도 적용할 수 있는 일반적인 측정 조건을 작성하도록 요청 |
| 근거의 종류 | 제품 통합을 위한 프로젝트 제약. 논문, 모델 크기나 시판 PC RAM 용량에서 역산한 수치가 아님 |
| 확인 범위 | 사용자 지정 요구를 기록함. 삼성 내부 정책 원본이나 별도 승인 문서를 확인한 것으로 확대하지 않음 |
| 단위 해석 | GB를 십진 단위로 명시: 1 GB = 1,000,000,000바이트. 1 GiB가 아니며 정확히 1 GB는 미충족 |

사용자 지정 이름과 정의 및 상한은 [QA08 상세](qa08-on-device-model-memory.md)의 요구사항으로 사용한다. 추가 모델 실행 경로의 동시 메모리 최고량, 가속기 포함과 공유 중복 제거, 5회 반복 및 중간 점수 구간은 이 요구를 측정 가능하게 만든 작성자 제안이다. 실제 장치 계측을 검증했다는 뜻은 아니다.

이 요구로 기존 QA06의 전체 RAM 512 MB를 변경하거나 512 MB와 1 GB를 합친 예산을 신설하지 않는다. 새 QA08의 비교 우선순위는 별도 합의 대상이다.
