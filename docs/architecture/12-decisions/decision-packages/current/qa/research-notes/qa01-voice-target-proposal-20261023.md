# QA01 음성 첫 응답 목표와 점수 제안

## 1. 제안과 기존 1초에 대한 판단

**대표 음성 사건 집합의 평균 첫 실질적 음성 시작 지연 L을 2.0초 이하로 제안한다. 1.0초 이하는 6점의 우수 수준으로 남긴다.** 사용자 발화와 이전 응답 때문에 기다린 시간도 L에 포함한다. 차례 대기를 뺀 보조 지표 E의 목표로 바꾸지 않는다.

1초는 음성 응답에 부적절한 수치가 아니다. 음성 대화 연구에도 이를 좋은 수준으로 볼 근거가 있다. 다만 이번 QA01은 순서대로 질문하고 답하는 대화뿐 아니라 사용자가 말하는 중의 Agent 통지와 이전 응답 대기를 포함한다. 이 혼합 모집단의 평균 1초를 보편적인 합격선으로 뒷받침하는 자료는 이번 조사에서 확인하지 못했다. 그래서 기존 1초를 그대로 최소 충족선으로 승계하는 안은 권고하지 않는다.

2초도 문헌이 직접 제시한 VIA의 한도가 아니다. 아래의 1초 선호 근거, 1.5초 음성 조건과 4초 부근의 경험 저하를 참조하여, **음성 응답을 낮은 한 자릿수 초 이내에 시작하도록 관리하되 1초를 개선 목표로 남기는 제품 판단**이다. 모델 호출별 시간을 더해서 만든 숫자나 후보가 통과하도록 역산한 숫자가 아니다. 1.5초와 4초 사이의 어떤 값이 최적인지 해당 실험만으로 결정할 수 없다. 2초를 선택하는 정확한 부분은 작성자의 제안이며 사용자 합의가 필요하다.

## 2. 확인한 원자료와 적용 한계

출처 확인일은 2026-10-23이다. 아래 원자료는 음성 응답 지연을 다루지만 VIA PC 제품이나 현재 공통 평가의 실측은 아니다.

| 원자료와 위치 | 확인한 사실 | VIA 적용과 한계 |
| --- | --- | --- |
| [Shiwa 외, 2009, How Quickly Should a Communication Robot Respond?](https://link.springer.com/article/10.1007/s12369-009-0012-8), 출판사 초록 | 첫 실험에서 로봇 응답시간에 대한 선호가 1초에서 가장 높았다고 보고 | 1초를 우수 수준으로 남기는 근거. 유료 본문은 이번 조사에서 확보하지 않았으므로 초록 이상의 표본/통계나 VIA 평균 목표를 단정하지 않음 |
| [Maslych 외, CUI 2025](https://arxiv.org/html/2507.22352v1), §3.1.1, §3.4~3.6, §5.3 | 54명의 VR 음성 Agent 실험. 1.5/4.0/6.5초 조건을 비교하고 4초 부근 및 더 긴 지연에서 경험 저하를 보고. 저자는 4초 미만을 지향하도록 권고 | 낮은 지연을 목표로 잡는 주된 음성 근거. 실제 마지막 발화 sample 대신 마이크 버튼 종료부터 음성 시작까지 측정. 1.5초는 해당 시스템의 빠른 조건이며 보편적 허용선이나 VIA의 달성 보장이 아님 |
| [Peng 외, CHI EA 2020](https://zhenhuipeng.com/docs/chi2020lbw_Xiaowei.pdf), 초록과 본문 | 94명 대상 서비스 로봇 영상 연구에서 4초까지의 지연을 수용했으며 8초에서 만족도가 낮아졌다고 보고 | 1초를 넘으면 반드시 실패한다는 해석에 대한 반례. 영상 관찰과 실제 PC 대화는 다르며 이 결과로 VIA 목표를 4초/8초로 완화하지 않음 |

세 연구는 정확히 같은 경계, 상호작용과 실험 방식이 아니다. 숫자를 평균내거나 1초, 1.5초, 4초를 하나의 연속적인 사용자 만족 곡선으로 만들지 않는다. 2025년 연구의 filler는 지연 완화 수단으로 다뤄졌으며 VIA QA01에서는 여전히 종료점으로 인정하지 않는다. 연구 참가자의 선호와 VIA의 산술평균 채점은 별개의 판단이다.

기존 화면 QA01의 Microsoft/Nielsen 1초는 [이전 조사](qa01-latency-research.md)의 근거로 남긴다. 새 음성 지표의 주된 근거는 위 음성 연구로 바꾼다. 사람 간 대화의 짧은 turn gap이나 특정 모델의 첫 토큰 시간을 전체 VIA 음성 응답 목표로 대체하지 않는다.

## 3. 차례 대기를 포함한 2초 목표의 적용 조건

**이 목표는 사전에 고정한 대표 사용 구성의 평균 요구다. 모든 음성 사건마다 2초를 보장하는 요구가 아니다.** 무제한 사용자 발화나 무제한 이전 응답이 허용된 모든 상황에 단일 상한을 보장할 수 없다. 이는 1초를 2초로 바꿔도 해결되지 않는다.

목표를 채택할 때 다음 항목을 공통 평가 계약에 고정해야 한다.

1. 즉시 응답 가능한 입력, 추가 사용자 발화 중인 입력/통지, 앞 응답 중인 통지의 수와 비중, 차례 정책 및 음성 의무를 기록한다. 수량은 기존 24입력이나 이전 109음성에서 자동 가져오지 않는다.
2. 사전에 정한 발화 일정과 차례 의무만으로 발생하는 최소 지연을 확인한다. 그 평균부터 2초를 초과한다면 해당 구성의 목표가 충돌하는 것이므로 채택 전에 요구와 대표성부터 검토한다. 후보 결과에 맞춰 대기 사건을 빼거나 비중을 줄이지 않는다.
3. 실제 평가에서는 L, 차례 대기 B, 나머지 E와 사건 종류별 평균, 분포 및 미출력을 함께 보고한다. L이 2초를 넘으면 제안 점수는 0점이다. 대기 때문에 초과했다는 진단을 붙일 수 있지만 E로 대신 채점하거나 목표를 후보별 B만큼 늘리지 않는다.
4. 보조 지표나 4초 초과 사건 비율은 원인 설명에 사용한다. 아직 합의되지 않은 별도 합격선이나 가산 점수로 사용하지 않는다.

예를 들어, 의무 대기만 5초인 사건 하나는 평균 목표 때문에 실패 사건으로 제거되지 않는다. 반대로 대기가 전혀 없는 대표 입력도 매번 2초까지 기다려도 좋다는 뜻은 아니다. 1초 이하의 응답을 높은 점수로 구별한다. 평가에 실제 사용 비중 자료가 없다면 대표성 가정을 명시하며 현재 구성의 목표를 제품 전체 SLA로 확대하지 않는다.

## 4. 0~6점 제안

기존 목록의 의미를 유지하여 **0점은 수치 목표 미달, 1점 이상은 수치 목표 충족, 6점은 우수 수준**으로 둔다. 1초부터 2초까지 다섯 구간을 균등하게 나누면 간격은 `(2.0−1.0)/5 = 0.2초`다.

| 점수 | 원형 | 평균 L / 초 |
| --- | --- | --- |
| 0 | ○○○ | `L > 2.00` |
| 1 | ◐○○ | `1.80 < L ≤ 2.00` |
| 2 | ●○○ | `1.60 < L ≤ 1.80` |
| 3 | ●◐○ | `1.40 < L ≤ 1.60` |
| 4 | ●●○ | `1.20 < L ≤ 1.40` |
| 5 | ●●◐ | `1.00 < L ≤ 1.20` |
| 6 | ●●● | `0 ≤ L ≤ 1.00` |

**0.2초 간격은 비교 결과를 표시하는 설계 규칙이며 사용자가 0.2초마다 한 단계씩 다르게 느낀다는 실험 결과가 아니다.** 1초 이하를 모두 6점으로 묶어 0.2초를 음성 응답의 최적값으로 가정하지 않는다. 0.4초와 0.9초의 차이는 원값으로 남기며 점수를 더 주기 위해 구간을 좁히지 않는다. 일부 로봇 연구에서 1초가 선호됐다는 이유로 0.4초 응답을 인위적으로 늦추라는 요구도 아니다.

반올림 전 유효 평균을 채점한다. 2초는 1점, 1.8초는 2점, 1초는 6점이다. 음수는 계측 오류이며 미출력/미관측/불완전 모집단은 0점으로 바꾸지 않는다. 오답의 실제 시간은 보존하되 오류를 별도 보고한다. 높은 시간점수가 기능과 정확성 충족을 대신하지 않는다. 분석 모델의 제안 점수와 제품 관측 점수도 구별한다.

## 5. 채택과 후속 작업

현재 확정된 것은 `QA01-VOICE-v1`의 정의와 측정방법이다. 이 문서는 그에 맞는 수치와 구간의 검토 제안이며 평가 계산기에 적용하는 승인이 아니다. 정의 명세의 목표/점수 승인 대기 상태를 유지한다. 사용자 채택 후 공통 모집단 적용 조건과 함께 새 점수 판본을 전달하고, 기존 평가와 구간은 보존한다. 현재 DP 값이나 예상 순위를 기준으로 경계를 조정하지 않았다.
