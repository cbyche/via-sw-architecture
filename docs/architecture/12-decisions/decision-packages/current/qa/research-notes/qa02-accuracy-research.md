## 1. 조사 질문과 수정 결론

사용자가 요구한 것은 말과 화면 및 과거 맥락으로 **지칭 대상 집합을 정확하게 찾는 능력**이다. 표시된 표적을 마우스로 누르는 운동 과제는 이 의미 해석 과제와 다르다. 마우스 오류 1.3%에서 성공률 98.7%를 계산하고 99%로 올렸던 목표 근거는 철회한다. 인용한 수치가 맞더라도 과제가 다르면 목표의 근거로 삼을 수 없다.

현재 제안은 **지칭 대상 집합 일치율 93% 이상**이다. 음성비서의 화면 및 대화 지칭을 집합 완전 일치로 평가한 ReALM을 참조한다. 이는 유사 기술의 공개 성능을 기준으로 채택한 제품 개발 목표이며 사용자가 감내하는 오류율이나 VIA의 달성 실적이 아니다. [이전 조사 문서](../../../../../../archive/qa-targets-before-task-aligned-revision-20261014/research-notes/qa02-accuracy-research.md)와 [이전 QA02](../../../../../../archive/qa-targets-before-task-aligned-revision-20261014/qa02-referent-accuracy.md)는 수정 이력으로 보존한다.

## 2. 주요 근거: ReALM의 지칭 대상 집합 평가

[ReALM: Reference Resolution As Language Modeling, SIGDIAL 2024 정식 출판본](https://aclanthology.org/2024.sigdial-1.5.pdf)의 §3은 예측 대상 집합과 정답 집합의 완전 일치를 판정한다. 대상 순서는 무관하다. Table 2의 시험 규모는 화면 약 1,900건과 대화 약 1,200건이다. Table 3은 다음 결과를 보고한다.

| 모델 | 화면 지칭 집합 일치율 | 대화 지칭 집합 일치율 |
| --- | ---: | ---: |
| MARRS 재구현 | 83.5% | 92.1% |
| GPT-3.5 | 74.1% | 84.1% |
| GPT-4 | 90.1% | 97.0% |
| ReALM-80M | 88.9% | 96.7% |
| ReALM-250M | 90.6% | 97.8% |
| ReALM-1B | 91.4% | 97.9% |
| ReALM-3B | **93.0%** | **97.9%** |

분모는 질의와 후보 목록 및 정답 집합을 가진 시험 사례다. 객체별 정답을 평균한 F1이나 Top-1 정확도가 아니다. MARRS는 재구현 결과이므로 기존 MARRS 논문과 동일한 실험으로 합치지 않는다.

### 같은 채점 방식과 다른 평가 범위

| 확인 위치 | 논문의 조건 | VIA와의 차이 |
| --- | --- | --- |
| §3와 §5.3.2 | upstream에서 대상과 유형 및 화면 위치 등을 제공 | VIA는 원본 획득과 조회 실패를 포함하며 정답 후보를 입력에 미리 제공하지 않음 |
| §4.1 | 이전 대화에서 제시한 항목의 지칭 | DP45의 과거 이력 검색과 실제 전달 버전 확인 전체를 평가한 것이 아님 |
| §4.3와 §7 | 화면의 전화번호와 주소 등 텍스트 중심 | 그래프와 이미지 및 일반 PC UI까지 검증한 결과가 아님 |
| §4.2와 Table 5 | 일부 정답은 모호한 표현에 가능한 후보 전체 | VIA의 정량 모집단은 근거로 의도 집합을 정할 수 있는 사례이며 모호한 사례는 별도 검증 |
| §3의 입력과 출력 | 질의에서 후보 ID 집합을 선택 | pointer 시점과 화면 변화 및 필요한 범위와 revision 판정을 같은 조건으로 검증하지 않음 |

**지표 형식과 지칭 해석 문제는 대응하지만 동일한 시험은 아니다.** 공개 결과를 VIA의 예상 성능이나 재현 결과로 표현하지 않는다.

### 평가 단위의 추가 확인

ReALM은 **질의별 관련 대상 ID 집합**을 평가한다. VIA는 **지칭 표현별 대상 집합과 revision**을 평가한다. “이 표를 저 표와 비교”에서 두 표현의 대상을 서로 바꾸면 VIA의 각 판정은 실패지만 질의 전체 합집합 `{A,B}`는 바뀌지 않을 수 있다. 집합 완전 일치라는 판정 원리는 같지만 분모 단위와 역할 연결의 평가 범위는 다르다. ReALM의 93%를 그 차이까지 검증한 결과라고 설명하지 않는다.

## 3. 목표값 선택의 판단

선택 규칙은 **유사 음성비서 지칭 기술의 공개 성능 수준을 VIA의 지칭 기능에서도 확보한다**는 것이다. 선정한 연구의 전용 모델이 보고한 가장 높은 화면 값 93.0%를 공통 최소 목표로 채택한다. ReALM-3B를 VIA 모델로 선정하거나 파라미터 수로 다른 모델의 능력을 추정하는 결정은 아니다.

| 후보값 | 채택 여부와 이유 |
| --- | --- |
| 90% | 미채택. GPT-4의 화면 값 90.1%를 낮춰 반올림하는 추가 정책이 필요함 |
| **93%** | **채택 제안. 선정한 유사 과제 연구의 전용 모델이 보고한 화면 집합 일치 수준을 참조** |
| 95% | 미채택. 해당 화면 결과에 직접 없는 상향 수치이며 별도 근거가 필요함 |
| 97.9% | 미채택. 대화 수치를 화면에 그대로 적용하면 과제별 차이를 무시함 |
| 99% | 이전 마우스 기반 논리를 철회. 이번 연구가 화면 집합 정확도 99%를 뒷받침하지 않음 |

93%는 자료에서 유일하게 결정되는 자연적 경계가 아니다. 관련 연구를 선정하고 그 성능 수준을 최소 도달 목표로 선택한 제품 판단이다. 더 넓은 원본 취득과 시점 및 정정 처리까지 포함해 이 수준을 유지할 수 있는지는 자체 PoC로 확인한다. DP47과 DP45는 각각 목표를 만족해야 하며 두 결과를 합쳐 부족한 영역을 숨기지 않는다.

## 5. Downstream 복구율 논리를 사용하지 않은 이유

`VIA 성공 90% + VIA 실패 10% × downstream 복구 90% = 전체 99%`는 후자의 90%가 **VIA가 잘못 해석한 요청을 받은 조건에서 의도를 복구한 성공률**일 때 성립한다. 일반 PC Agent benchmark의 업무 성공률은 이 조건부 복구율이 아니다. 그 값을 그대로 대입하지 않는다.

잘못 전달된 대상이 명확한 지시처럼 보이면 downstream이 그 대상을 충실히 처리할 수도 있다. 임의의 복구 가정으로 VIA 정확도 목표를 완화하지 않는다.

## 6. 집합 판정 예시와 통계적 해석

“이 두 개”의 정답이 `{표 A, 그래프 D}`이면 다음과 같이 판단한다.

| 채택 집합 | 사건 판정 | 이유 |
| --- | ---: | --- |
| `{표 A, 그래프 D}` | 1 | 전체 일치 |
| `{표 A}` | 0 | 대상 누락 |
| `{표 A, 그래프 C}` | 0 | 다른 대상 |
| `{표 A, 그래프 C, 그래프 D}` | 0 | 불필요한 대상 추가 |

원본과 범위 및 필요한 버전의 정답 규칙은 현재 명세를 따른다. 실제 공통 평가는 지칭 44개 × 5회 = 220판정이며 성공 205개 이상이 93% 목표를 충족한다. 아래 100판정은 퍼센트 이해를 위한 가상 예시다. `QA-C02-score-v3`에서 가상 100판정 중 93개 성공은 93%와 1점이고 99개 성공은 99%와 5점이다. 100개 성공은 6점이다. 93~94개는 1점이고 95개는 2점 및 96~97개는 3점과 98개는 4점이다. 점수 구간은 표현 규칙이며 논문이 정한 사용성 경계가 아니다. 이전 99% 기준의 1점 예시를 현재 점수로 재사용하지 않는다.

[NIST TN 2045](https://www.nist.gov/publications/confirming-performance-threshold-binary-experimental-response)는 목표 성능과 통계적 확인을 구별하는 자료이고 [NIST 이항비율 신뢰구간](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)은 이진 결과의 불확실성 계산 자료다. 독립 시행 100건이 모두 성공해도 단측 95% 신뢰하한은 `0.05^(1/100)`인 약 97.05%다. 현재 20개 fixture를 5회 반복한 설계는 독립 사용자 상황 100개가 아니므로 이 계산을 제품 성능 보장에 그대로 적용하지 않는다.

## 7. 발표자 노트와 심사 답변

| 질문 | 답변 |
| --- | --- |
| 왜 93%인가 | 같은 지칭 해석 문제를 집합 일치로 평가한 공개 기술 수준을 제품 목표로 채택했다. 다른 과제의 수치를 환산하지 않았다. |
| 사용자 만족이 93%에서 보장되는가 | 그런 연구 결과로 제시하지 않는다. 유사 기술을 기준으로 삼은 개발 목표이며 사용자 만족 임계값은 아니다. |
| 연구보다 VIA의 평가 범위가 넓지 않은가 | 그렇다. 원본 취득과 시점 및 정정 처리를 포함해 목표 수준을 확보하는지 자체 시험으로 확인한다. |
| DP45의 과거 이력도 같은 연구에서 검증됐는가 | 대화 지칭이라는 공통점이 있지만 전체 이력 검색과 실제 전달 버전 복원은 별도 VIA 책임이다. |
| 100회 중 93회 성공하면 제품 전체도 93%인가 | 해당 대표 시험에서 목표를 만족한 것이다. 독립 사례와 별도 수용 계획 없이 모집단으로 일반화하지 않는다. |

정량 분모의 식별 가능한 사례와 확인이 필요한 사례는 실행 전에 나눈다. 실패 후 어려운 사례를 모호하다고 제외하지 않는다. 두 DP의 난이도 차이를 무시해 `47A`와 `45B`의 원점수를 직접 대조하지 않는다. DP47 양안은 원본 재조회와 부분 정정이 가능하므로 지표를 공통 적용할 수 있다는 사실만으로 A/B 차이를 주장하지 않는다.

후속 증거는 지칭 단위별 oracle과 원본 revision 및 채택 집합, 최초 오답과 수정 이력, 두 검토자의 판정 근거다. 이번 조사에서는 구현이나 모델 실행 및 정확도 측정을 수행하지 않았다.
