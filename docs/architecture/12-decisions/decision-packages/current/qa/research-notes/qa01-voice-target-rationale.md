# QA01 음성 첫 응답 목표와 점수 근거

2026-10-23 / 사용자 합의 / [정의와 점수 정본](../qa01-first-response-latency.md)

## 1. 4초 참조에서 50% 단축한 2초 목표

[Maslych 외, Mitigating Response Delays in Free-Form Conversations with LLM-powered Intelligent Virtual Agents, CUI 2025](https://arxiv.org/html/2507.22352v1)의 §3.1.1, §3.4~3.6, §5.3을 근거 자료로 사용한다. 2026-10-23 확인했다.

| 항목 | 원자료에서 확인한 내용 |
| --- | --- |
| 참가자와 상황 | 54명, VR의 LLM 음성 Agent와 과제 기반 대화 |
| 응답 지연 조건 | 1.5초, 4.0초, 6.5초 |
| 관측 경계 | 마이크 입력을 버튼으로 종료한 뒤 생성 응답의 음성이 시작될 때까지 |
| 연구 결과와 권고 | 지연 증가에 따른 사용자 경험 저하를 보고하고 4초 미만을 지향하도록 권고 |
| VIA의 개발 목표 | **참조값 4초 대비 지연시간 50% 단축** |
| 목표 산식 | **4.0 × (1−0.50) = 2.0초** |
| 적용 | 차례 대기가 없는 일반 상황의 첫 실질적 음성 시작 지연 평균 |

연구의 4초 조건을 참조값으로 사용하고 50% 단축은 VIA의 사용자 합의 목표로 정했다. 연구의 실제 비교 결과가 50% 개선이었다고 쓰지 않는다. VIA의 발화 종료점과 실질적 음성 판정은 합의된 측정 계약을 따른다. Filler나 인사만 먼저 낸 것은 응답으로 세지 않는다.

## 2. 일반 상황 별점과 대기 상황의 별도 표시

사용자 발화나 앞 응답 때문에 차례를 기다리지 않는 NORMAL의 평균에 2초 목표와 별점을 적용한다. 사용자 발화/앞 응답 대기는 WAIT로 사전에 구분하고 해당 DP에서 총 실제 지연, 차례 대기 및 마지막 대기 종료 후 추가 지연을 별도로 제시한다. WAIT를 삭제하거나 그 보조 지표를 NORMAL로 대신 채점하지 않는다.

## 3. 우수선과 점수

[Shiwa 외, 2009](https://link.springer.com/article/10.1007/s12369-009-0012-8)의 출판사 초록은 로봇 응답시간 선호가 1초에서 가장 높았다고 보고한다. 이 결과를 참고해 1초 이하를 6점으로 둔다. 2초는 목표 충족선이며 두 경계 사이를 `(2−1)/5 = 0.2초`씩 균등 분할한다. 중간 구간은 사용자와 합의한 채점 규칙이다. 정확한 구간과 경계 처리는 정의 문서의 점수표를 따른다.

## 4. 변경 이력

[이전 목표 제안](../history/timing-before-normal-profile-20261023/qa01-voice-target-proposal-20261023.md)은 차례 대기를 포함한 혼합 평균에 2초를 제안했다. 사용자 정정에 따라 일반 상황의 별점과 대기 상황의 별도 결과로 분리하고, 2초의 도출을 4초 대비 50% 단축으로 확정했다. 이전 화면 1초 근거는 [과거 조사](qa01-latency-research.md)에 보존한다.
