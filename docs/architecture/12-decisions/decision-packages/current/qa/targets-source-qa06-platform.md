**발표 본문:** “PC 플랫폼 및 기술기획 측 시스템 요구사항: 기본 탑재 VIA의 최대 RAM 사용량 512 MB 이하.”

**발표자 노트의 출처 표기:** “과제에서 사용자가 지정한 시스템 요구사항이다. 실제 삼성 내부 정책 문서나 별도 승인 기록을 확인한 것은 아니다.” 이 과제의 요구로 사용하며 검증된 회사 공통 정책으로 확대하지 않는다.

## 2. 목표와 점수 경계의 구별

512 MB는 준수할 상한이다. 이를 구성 요소별 사용량으로 역산해 정당화하거나 다른 프로그램의 사용량을 합산해 도출하지 않는다. 목표 이내의 개선 여유를 구별하는 **RAM-v3-MB** 점수는 별도의 평가 규칙이다.

- 1점 경계: 요구 상한 **512 MB**.
- 6점 경계: 상한의 절반인 **256 MB**. 예산의 50%를 남긴 구조를 가장 높은 개선 등급으로 표현하는 선택이며 최소 구현량이나 외부 조직의 추가 요구가 아니다.
- 중간 경계: `(512 − 256) / 5 = 51.2 MB`씩 나눈다.
- 0점: 512 MB 초과. 미측정과 불완전한 관측은 점수를 부여하지 않는다.
- 원시 바이트로 판정한다. 표시 반올림으로 512 MB 초과를 합격으로 바꾸지 않는다.

실제 RAM 계측 방법과 목표 달성 및 다른 앱과의 공존 성능은 아직 검증하지 않았다. 요구사항 확정과 실측 달성을 구분한다. 새 수치가 기존 512MiB의 재사용이라는 오해를 막기 위해 단위와 출처 및 점수 버전을 모두 변경했다.
