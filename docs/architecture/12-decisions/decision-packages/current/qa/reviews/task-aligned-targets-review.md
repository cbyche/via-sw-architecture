# QA 목표와 출처 적합성 재검토

> **이관한 원전 이력:** 본문의 현재·최신·실측 전·검토 완료는 원래 날짜와 대상 범위의 기록이다. 현재 네 DP의 정본 상태와 결과는 [QA 기준 안내](../README.md) 및 [공통 QA v3](../../evaluation/common-qa-v3/README.md)에서 확인한다. 이 기록을 최신 실측 또는 현재 설계 승인으로 계승하지 않는다.


> 2026-10-14 / 사용자 지적 후 재조사와 교차 검토 / 구현과 모델 호출 및 Windows 측정 없음

## 1. 이전 리뷰에서 놓친 문제

이전 리뷰는 원문의 숫자와 계산이 맞는지 확인했지만 **그 연구의 과제가 VIA의 평가 목적과 충분히 일치하는지**를 엄격하게 판단하지 못했다. 마우스 표적 선택의 성공률을 의미 지칭 해석에 옮긴 QA02와 명령 UI 및 음성 엔진의 부분 수치에서 전체 비서의 RAM을 정한 QA06의 근거를 철회한다. 이전 리뷰 원문은 당시 판단의 이력으로 보존하며 현재 목표의 승인으로 읽지 않는다.

## 3. 독립 교차 리뷰

조사 부록 작성자는 자기 문서를 독립 검토한 것으로 세지 않는다. 루트가 작성한 상세안과 요약을 검토하는 한편 다른 작성자의 조사 부록도 교차 확인한다. 에이전트 검토이며 외부 기관이나 인간 심사위원의 승인이 아니다.

| 검토자 | 다른 작성자의 검토 범위 | 결과 |
| --- | --- | --- |
| targets_accuracy_change_research | QA04 상세 정의와 요약의 모집단 및 ARGO 출처 구분 | P2 3건: QA04 정의의 C03 누락 / QA05 요약의 추론 출력 누락 가능성 / QA06까지 목표와 점수가 완료된 것으로 읽히는 상위 요약. 수정과 재확인 완료 |
| targets_cost_memory_research | QA05 상세 견적과 목표 논리 및 활동과 발표 표 | P2 1건: 후속 관측의 30초와 120초 기준점 불명확. R20 발화 종료를 기준으로 고정하고 재확인 완료 |
| targets_latency_research | QA02와 QA06 상세 및 다른 작성자의 조사 부록과 요약 | P2 1건: ReALM 질의별 집합과 VIA 표현별 집합 및 revision의 평가 단위 차이 누락. 상세와 요약에 추가 후 재확인 완료 |

## 4. 보완과 재확인

1. QA04 정의를 “VIA가 주고받는 데이터 형식”으로 고쳐 화면 자료 변경도 포함했다. ARGO 감소율은 실적이 아닌 3개 달성 시 표시값 대비 계산이라는 점을 보완했다.
2. QA05 목표 요약의 500출력을 “추론 포함 총 청구 출력 500”으로 고쳐 상세 견적과 일치시켰다.
3. 저장소 README와 중심 계획 및 패키지와 발표 표에서 QA06의 목표와 점수 미완료를 명시했다. 여덟 개의 현재 점수표와 아홉 개의 QA 정의를 구분한다.
4. ReALM의 질의별 집합과 VIA의 지칭 표현별 집합 및 revision 차이를 추가했다. “이 표를 저 표와 비교”에서 역할을 바꾸어도 전체 합집합이 같을 수 있다는 예시를 남겼다.
5. R20의 발화 종료를 `t_last`로 고정했다. +30~40초의 완료 확인과 +40초 종료 또는 취소 및 +120초 미완료를 구분한다. 필수 처리 취소는 기능 미완료이며 늦은 청구는 추가해도 성공으로 바꾸지 않는다.

세 검토자가 각 수정 후 재확인을 수행했다. **이번 교차 검토의 문서 결함 P2 다섯 건은 수정됐고 검토 범위에서 추가 미해결 P1/P2는 보고되지 않았다.** 이는 목표의 실제 달성이나 모든 작업의 완료 판정이 아니다. 특히 **QA06의 절대 목표 미완료는 해결된 것으로 닫지 않는다.**

## 5. 정적 확인과 남은 범위

- QA 정의 9개와 현재 점수표 8개의 구간과 원형 표시 및 단조성 210개 검사
- gpt-realtime의 텍스트와 음성 및 Luna 견적 합계 $0.7067과 ARGO 계산 확인
- QA06은 목표 근거와 계측 미완료 상태이며 활성 점수표가 없음을 검사
- 전체 표 9행과 축약 표 9행의 5열 구성 및 축약 Scenario 4줄 확인
- archive 원본과 이전 commit의 바이트 일치 및 현재 문서 링크와 제목 연결 확인
- active Markdown 링크와 용어 및 기존 QA 등록부와 `git diff --check`

실제 입력 파일과 tokenizer 사용량 및 참조 API의 기능 품질을 검증하지 않았다. ARGO PR 원본 감사와 Windows 동종 제품 RAM 측정 및 후보 PoC도 수행하지 않았다. 다른 DP의 그림과 구현 및 기존 측정 결과는 이번 수정에 포함하지 않는다.
