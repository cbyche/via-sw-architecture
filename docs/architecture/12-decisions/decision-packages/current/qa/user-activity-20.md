# 이전 20요청 활동의 대체 안내

> **현재 QA 자료의 이관본 (2026-10-22):** 출처, 원값, 목표 도출과 기존 검토 내용을 유지한다. 문서 안의 이전 DP, 모집단, 검토 상태는 해당 작성 세대에 한정한다. [현재 QA 기준과 적용 범위](README.md).


> SUPERSEDED / 2026-10-14 / 기존 링크를 위한 안내

현재 평가 입력은 [COMMON-28-v1의 28개 대표 시나리오](../scenarios/common-28-v1/common-scenarios.md)다. QA별로 별도 활동을 만들지 않고 같은 입력에서 응답과 목표 및 지칭과 음성 관측을 추출한다.

이전 COST-20-v3의 요청 문장과 사건 배치 및 시간 조건은 [통합 전 원본](../../../../../archive/qa-populations-before-common-catalog-20261014/user-activity-20.md)에 그대로 보존했다. 현재 측정 조건이나 비용 목표로 사용하지 않는다.

현재 비용은 [새 공통 견적](common-model-cost-quote.md), 측정 조건은 [품질 요구사항 표](quality-requirements-table.md), 변경 경위는 [통합 기록](../scenarios/common-28-v1/common-evaluation-population-plan.md)을 읽는다.
