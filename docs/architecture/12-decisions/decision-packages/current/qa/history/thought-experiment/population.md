관련성은 결과의 승패가 아니라 해당 구조의 근거 취득, 의미 생산, 실행 연결 또는 상태 확정 경로를 쓰는지로 정한다. A/B의 ID와 가중치는 같다. 선택하지 않은 쉬운 일반 질의와 다른 기능은 전체 제품 회귀 목록에 남지만 DP 평균에는 넣지 않는다. 관련 경로 안의 쉬운 native 사례와 cache 적중, B에 불리한 새 관계도 남긴다.

QA01은 아래 사건만, QA02는 그 사건에 속한 B-ID만, QA03은 관련 사건이 들어 있는 G-ID 전체의 인과 경로를 쓴다. 같은 목표의 Agent 후속 처리나 정정이 평균에서 빠지는 일이 없도록 목표 전체를 유지한다. QA05는 기존 28개 묶음의 총액 배점 단위를 유지하고 관련 의미 호출 소계도 공개한다. QA06은 아래 S의 준비 포함 최고량, QA09는 아래 사건 중 의무 음성만 쓴다. QA07은 경합을 만드는 구조와 연결되는 대조 cell만 선택한다.
