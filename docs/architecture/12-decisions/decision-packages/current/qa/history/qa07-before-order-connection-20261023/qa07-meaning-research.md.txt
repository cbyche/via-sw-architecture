# QA07 목표 90%와 평가 절차의 근거

## 1. 제안 결론

**요청 처리 사례 전체 충족률 90% 이상**을 개발 목표로 제안한다. 한 사례에서 최초 해석, 채택 응답 구성, 실제 전달의 의무가 모두 맞아야 성공이다. 32사례를 5회씩 실행하므로 **160회 중 144회 이상 성공**해야 한다. 숫자를 미정으로 두지 않고 목표, 표본 구성, 기한, 판정과 점수까지 이번 문서에서 정했다. 사용자에게 이미 승인받은 수치 또는 실제 달성 결과로 표시하지 않는다.

## 2. 90%의 수치 참조

Park, Kang, Seo의 *An Efficient Framework for Development of Task-Oriented Dialog Systems in a Smart Home Environment*, Sensors 2018, 18(5), 1581은 한국어 목적 지향 대화 시스템의 대화 성공률을 보고한다. §6.1.2와 Table 3의 without HAS 평균은 약 **90%**, with HAS 평균은 약 **91%**다. 논문의 성공 단위는 목적을 가진 대화이며 지정한 대화 차례 한도를 넘으면 실패다. [원문 §6.1.2와 Table 3](https://pmc.ncbi.nlm.nih.gov/articles/PMC5982658/), [DOI](https://doi.org/10.3390/s18051581).

VIA에서는 이 대화 단위 90%를 **목표 수준을 선택하는 참조값**으로 사용한다. 최초 의미 파싱 한 단계만의 수치보다 현재 QA07의 대화/응답 범위에 가까운 참고다. 다만 논문이 VIA의 화면 지칭, 다중 Task, 정정 후 지연 전달까지 검증하거나 VIA의 오류 허용선을 정한 것은 아니다. 같은 숫자를 VIA의 더 엄격한 전체 충족 기준에 적용하기로 한 것은 작성자의 개발 목표 판단이다. 두 시스템의 정확도가 동등하거나 통계적으로 비교 가능하다고 주장하지 않는다.

90%는 외부 연구의 성공 수준을 최소 목표로 잡고, 관측한 모든 사례가 맞는 100%를 우수선으로 놓는 설계다. 특정 대안을 통과시키려고 결과를 보고 정한 숫자가 아니며 현재 실측 결과는 없다.

## 3. 마지막 답변만 보지 않는 이유

TD-EVAL은 대화의 최종 성공 지표가 중간 응답의 문제를 놓치는 예를 제시하고 대화 일관성, 근거 지식과의 일치, 정책 준수를 평가한다. 이를 참고하여 QA07은 최초에 잘못 채택한 해석이나 잘못된 중간 응답을 최종 정답으로 지우지 않는다. 이는 **판정 방법의 근거**이며 논문에서 90% 한도를 가져온 것이 아니다. [Acikgoz 외, TD-EVAL, SIGDIAL 2025, 도입부와 Figure 1](https://aclanthology.org/2025.sigdial-1.7/).

TreeDST/FULLTOGRAPH의 이전 90.8%는 최초 의미 파싱 참고로만 보존한다. 현재 사례 전체의 응답/전달 충족률을 설명하는 직접 근거로 사용하지 않으며 세 단계의 정확도를 독립으로 가정해 곱하지 않는다.

## 4. 사례 수와 반복 수의 출처

| 결정 | 수치 | 출처와 이유 |
| --- | --- | --- |
| 사례 유형 | 8개 | 고정 UC의 직접 답변, 복합 요청, 확인, 정정, 취소, Agent 사건, 대기/재개, 채널/문맥을 구별한 작성자 평가 구성 |
| 유형별 사례 | 4개 | 유형마다 서로 다른 의미/상태/전달 실패 경로 4개를 32사례 문서에 명시. 실제 사용 빈도 기반 비중은 아님 |
| 반복 | 5회 | 동일 입력에 대한 출력 변동 확인을 위한 작성자 공통 실행 규칙. 통계적 신뢰도에서 역산한 표본 수는 아님 |
| 전체 분모 | 160회 | 8 × 4 × 5. 기존 80입력이나 v6의 24묶음을 자동 승계하지 않음 |
| 목표 성공 수 | 144회 | 160 × 0.90 |
| 응답 기능 기한 | 60초 | 짧은 시험 응답의 무한 대기 방지. 정확도 시험 한도이며 사용자 지연 목표가 아님 |
| 사례 한도 | 300초 | 최대 4응답 × 60초 + 제어/사건 전환 여유 60초 |
| 추가 관측 | 10초 | 종료 뒤 5초에 구판 사건/큐 재검사를 유발하고 추가 5초 관찰 |

이 구성은 VIA의 주요 기능 경로를 동일 비중으로 비교하는 고정 시험이다. 160개의 서로 다른 실제 사용자 대화나 일반 사용자 전체의 정확도 보장을 뜻하지 않는다. 측정 담당이 사례나 종료 기준을 다시 발명하도록 남겨두지 않고 입력/정답/사건 트리거까지 작성했다. 실제 원음/화면 자료와 계측 adapter의 제작, 검증, 실행은 측정 구현 작업으로 구별한다.

## 5. 점수 구간

90%를 목표선, 100%를 우수선으로 둔다. 중간 구간은 `(100−90)/5 = 2%p`로 균등 분할한다. 0점은 90% 미만, 1~5점은 [90,92), [92,94), [94,96), [96,98), [98,100), 6점은 100%다. 이전 구간과 숫자가 같더라도 새로운 사례 단위와 근거를 갖는 `QA07-REQUEST-RESPONSE-score-v3`다. 구간은 연구 결과가 아니라 일관된 평가를 위한 작성자 규칙이다. 미관측 사례는 0점으로 처리하지 않는다.
