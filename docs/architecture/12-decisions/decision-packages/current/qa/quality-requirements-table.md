## 1. 대화에서 제공한 상세 표

첨부 표의 **ID / 분류 / Title / Scenario / 중요도 / 난이도** 구성을 따랐습니다. Scenario에는 **요구사항 문장 → 정량 목표 → 측정 조건 → 목표 근거**를 넣었습니다.

목표 수치는 상세 명세를 따르며 **QA06의 512 MB는 사용자 지정 시스템 요구사항이고 나머지는 검토용 제안값**입니다. 중요도 / 난이도는 **1~10점의 사전 판단**이며 **1~4점=L / 5~7점=M / 8~10점=H**로 표시합니다. 예를 들어 `H(10) / H(9)`는 중요도 10점과 난이도 9점입니다.

### 1.2 중요도와 난이도 판단 근거

**중요도는 사용자 가치와 사업 / 개발 영향을 고려한 이 과제의 QA 평가 우선도**다. 기존 QA 순서에 맞춰 핵심 여섯 개를 먼저 두고 이미 다루는 품질을 보완하는 후보는 뒤에 둔다. **난이도는 각 목표를 달성하는 데 필요한 구조적 조정의 복잡성**이며 중요도와 독립적으로 판단한다. 두 점수를 합산하지 않는다.

- **중요도 기준:** 10점은 최우선 대화 경험, 9점은 핵심 기능의 신뢰, 8점은 전체 처리와 지속 개발의 핵심, 7점은 운영 비용, 6점은 PC 자원 공존, 5점은 핵심 QA를 보완하거나 공통으로 검증할 품질이다. 이 점수는 현재 VIA 과제에 대한 판단이며 범용 공식이 아니다.
- **난이도 기준:** 10점은 여러 종류의 불확실한 근거를 함께 판정하는 문제, 9점은 여러 처리 단계와 대기를 함께 줄이는 문제, 8점은 상태 / 계약 / 동시 처리 경계를 조정하는 문제, 7점은 품질을 유지하면서 생산량과 비용을 줄이는 문제, 6점은 자원 수명이나 모듈 경계를 제한하는 문제에 부여했다. 현재 측정 범위에 대한 구현 전 판단이다. QA06은 클라우드 모델 조건에서 512 MB 상한을 적용하며 실제 구현 난이도는 검증 전이다.
- **동점 처리:** QA03 / QA04는 중요도 8점이며 사용자의 완료 경험을 먼저 다루는 기존 순서를 유지한다. 추가 후보 QA07~QA09는 모두 5점이며 기존 후보 순서를 유지한다.
- **이전 등급의 수정:** QA09는 제품 필수성을 이유로 H였으나 이번에는 평가 우선도와 행 순서를 일치시키기 위해 **M(5)**로 조정했다. **음성 전달은 여전히 필수 검증 항목**이며 낮은 평가 순위가 생략을 허용하지 않는다.

**Stakeholder 연결의 근거:** 사용자 / CTO/담당임원의 요구와 AI 코딩 병행 개발 부담은 대화에서 확인했다. 아래는 이를 QA 목적과 연결한 **요구 연계안**이며 역할별 세부 발언이 확인되지 않은 연결은 해당 역할의 관점에서 제안했다. 인용문이나 stakeholder별 합의 점수로 해석하지 않는다. 개발자가 VIA에 바라는 연동 / 협업 조건을 적으며 그 개발자의 구현 업무를 요구사항으로 바꾸지 않는다.

### 1.3 표를 해석할 때 유지할 조건

**2026-10-15 사용자 정정:** QA01/03은 산술평균이며 오답도 실제 시간을 포함한다. 실패 시간 벌점을 적용하지 않는다. 목표 1초 / 5초와 수치 배점은 유지한다.
- 여기의 **H/M/L과 괄호 안 1~10점은 중요도 / 난이도 평가**입니다. 이후 PoC 결과에 부여할 **0~6점 성능 점수와는 별개**입니다.

## 2. 발표용 축약 표

**표의 공통 조건: 대표 시나리오 S01~S28과 동일 초기 상태 및 사건 시각을 사용한다. 실행 QA의 반복은 5회이며 QA04/08은 개발 변경 과제다.** [시나리오와 관측 건수](../scenarios/common-28-v1/common-scenarios.md#2-수량과-적용-범위)에서 표의 모든 수를 추적할 수 있다.

각 Scenario는 **정의 한 줄 → 목표 한 줄 → ※ 측정 조건 한 줄 → ※ 목표 근거 한 줄**로 구성한다. QA06 목표는 사용자 지정 요구사항이며 나머지 목표와 중요도 / 난이도 점수는 검토안이다. QA별 상세 규칙은 ID의 링크에서 확인한다.

발표 표 아래에는 다음 두 문장을 공통 각주로 둔다.

- 중요도 / 난이도는 1~10점 제안값이며 1~4=L / 5~7=M / 8~10=H다. 목표 달성 성능은 PoC의 별도 0~6점으로 평가한다.
- QA01~QA06은 핵심 검토 대상이며 QA07과 QA08은 보조 지표이고 QA09는 필수 음성 검증 항목이다. 핵심 여섯 QA에 목표와 점수표를 작성했다. QA06의 512 MB는 사용자 지정 시스템 요구사항이며 Windows 계측 구현과 목표 달성은 검증 전이다. QA07~09는 이번 여섯 QA의 수치 근거 재검토 범위 밖의 기존 보조 제안이다.

측정 상세와 실패 처리, 목표 산식의 가정, 0~6점 구간, 예시와 QA–DP 관계는 각 QA 상세 명세와 [이관 전 패키지 대응표](history/source-package-overview-20261015.md#4-qadp-대응과-예상-우열)로 연결한다.
