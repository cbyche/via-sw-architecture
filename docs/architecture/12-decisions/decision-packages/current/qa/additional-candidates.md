# 보조 QA 검토

현재 QA01~QA08의 정의와 목표는 [QA 목록](README.md)을 따른다.

[QA09 음성 전달 지연](qa09-audio-delivery-lag.md)은 응답 채택 이후 말할 수 있었던 시간 중 실제 음성 시작까지의 대기를 보는 보조 검증이다. QA01의 음성 종료점 전환 여부와 함께 독립 QA 유지 필요성을 검토한다. 현재 정의나 500ms 목표를 이번 검토로 변경하지 않는다.

아래는 2026-10-14 당시의 추가 관심사 검토 이력이며 현재 네 DP의 확정 평가가 아니다.

## 2. 후보를 더 늘리지 않은 이유

| 추가로 검토한 관심사 | 가능한 지표 | 판정과 이유 |
| --- | --- | --- |
| 오래된 결과 사용 방지 | 정정 후 무효 결과가 실제 사용된 시험 비율 | 필수 기능 검증으로 유지. 44와 42의 강한 양안이 같은 현재성, 권한 검사를 요구하므로 정상 정답 구현끼리 임의 오류율 차이를 만들 수 없음 |
| 장애 후 업무 지속 | 대화 owner 중단 중 정상 반영한 Task 사건 비율 | 42의 특수 장애 사례에서는 의미 있으나 사용자에게서 드문 재시작을 주요 선정 논리로 쓰지 말라는 지시가 있었음. 다른 두 DP에 독립성 이익을 전파할 근거도 없음 |
| 정정 재처리량 | 재판단에 추가 입력한 token, media 양 | 47, 45에 관련되지만 모델 사용 비용의 원인 진단과 중복됨. 단가별 분해는 QA5에서 보존 |
| 음성 끼어들기 중단 | 사용자 발화 시작부터 기존 음성의 마지막 sample까지 | 매우 중요하지만 현행 네 DP는 같은 로컬 stop 경로를 공유함. 별도 필수 회귀로 두고 차별화 커버리지에서 제외 |
| 최대 처리량 | 응답 목표를 지키는 초당 사건 수 | 사용자 1명의 PC 업무에서는 사건 종류, 모델 비용에 따라 수가 달라져 QPS 하나의 의미가 약함. 고정 대표 profile의 QA1과 메모리로 우선 검증 |
| 업무 상태 최신성 | Agent 사건부터 Task/UI 반영까지 시간 | Task 원본까지 끝내면 44의 차이 경로 앞에서 측정이 종료됨. UI까지 끝내면 QA1의 Agent 사건 사례와 중복됨 |
| 오류 원인 추적 | 오류 재현 성공률 또는 진단 시간 | 현재 양안의 원본, trace 보존은 공통이며 사람의 진단 시간은 숙련도 영향이 큼. 증거 완전성 검증으로 유지하고 임의의 원인 추적 우위를 만들지 않음 |

이 후보들은 필요 없는 품질이라는 뜻이 아니다. **현재 네 DP의 핵심 trade-off 평가에 적합하지 않다는 판정**이다. 최소 2개 DP 커버리지와 1순위 QA의 3~4개 DP 차이를 맞추기 위해 서로 다른 의미를 한 지표로 묶지 않았다.

## 3. 특히 DP-42에 대한 결론

DP-42 B는 대화와 업무 상태 권한을 나누고 별도 접수, event 반영을 수행한다. A는 강한 내부 모듈화와 비동기 worker를 허용한다. 따라서 다음 설명은 채택하지 않는다.

- 별도 process이므로 항상 첫 응답이 빠르다.
- 별도 서비스이므로 항상 코드 수정이 적거나 병행 충돌이 적다.
- 업무 이벤트가 들어오면 A의 대화 전체가 멈춘다.
- 사용자 발화 시각부터 B의 원격 gate까지 무지연으로 hold가 적용된다.

정상 사용에서 B가 제공할 독립 운영 이익이 실제로 강한 A를 넘어서는지 확인되지 않은 채 비용, 메모리, 왕복만 차이나면 설득력 있는 상반 이익은 부족하다. **추가 QA를 발명해 이 틈을 가리기보다 현재 설계의 정상 사용 필요와 실제 구조 차이를 다시 검토하는 것이 맞다.** 사용자 지정 DP-42를 이 문서에서 제외하거나 다른 번호로 바꾸지는 않는다.

## 4. 후속 리뷰에서 확인할 사항

1. 추가 후보의 지표가 기존 QA와 같은 값을 다른 이름으로 반복하고 있는가.
2. 비교 모집단을 고정하기 전에 원하는 우세안에 맞춰 수치를 배분했는가.
3. 공식 출처가 실제로 목표 숫자를 제공하는지, 작성자의 예산 제안인지 구별했는가.
4. 강한 A의 async, cache, handler 분리와 B의 연결, 버전 비용을 모두 포함했는가.
5. 실측하지 않은 모듈 수, 지연, 점수, 커버리지를 결과로 오인할 문장이 있는가.
6. 0~6점의 모든 구간이 겹치지 않고 목표, 예시와 일치하는가.

이 파일과 세 상세 명세는 작성자의 검토 결과다. 제3자 리뷰의 발견, 수정, 재검증은 전체 패키지의 리뷰 원장에 별도로 기록한다. 별도 리뷰를 받기 전에 독립 검증 완료로 표시하지 않는다.
