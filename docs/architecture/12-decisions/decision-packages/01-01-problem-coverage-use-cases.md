# 1단계 근거 — UC 필수 변형과 공통 경계

> 연결 대상: [문제 원장 P-01~16](./01-00-problem-coverage.md) · 원문: [05 대표 UC](../../05-representative-use-cases.md)
> **94개 명명된 필수 변형**의 문제 연결을 확인하는 문서다. 실행 시험 PASS나 모든 조합의 검증을 뜻하지 않는다.

각 행의 P 번호는 그 변형에서 중심이 되는 문제다. 해당 UC 머리말의 다른 문제와 공통 원칙도 함께 적용한다. 예를 들어 개인정보 조회 행에 P-03만 있어도 동의(P-11)를 면제하지 않는다. 반복되는 공통 조건을 각 행마다 복사하여 coverage를 부풀리지 않는다.

## UC-01. 일반 대화·직접 응답

[원문](../../05-representative-use-cases.md#uc-01) · 연결: P-04·09·10

**공통 완료·실패 경계:** S2S 직접 응답·Text 확인·후속 맥락. 최신/외부 근거가 필요하면 조회나 위임으로 전환하고 중복 답하지 않는다.

| 필수 변형 | 상황 | 중심 문제 | 이 변형에서 반드시 남길 결과·경계 |
| --- | --- | --- | --- |
| UC-01.1 | 일반 질문 | P-04 | S2S가 직접 답하고 Task 없이도 입력·답을 기록 |
| UC-01.2 | 앞 응답 일부 후속 | P-10 | 실제 이전 응답의 해당 부분과 연결 |
| UC-01.3 | 새 주제 | P-01 | 새 질문을 이전 요청의 보완으로 강제 연결하지 않음 |
| UC-01.4 | Text 입력 | P-09 | Text로 답하며 불필요한 S2S 음성 경유를 강제하지 않음 |

## coverage를 과장하지 않는 경계

이 표는 원문에 이름이 붙은 94개 변형을 전수 대조하고, 별도 문장으로 정한 화면 경계와 UC별 실패 조건을 추가한 것이다. 임의의 입력 문장 전부나 94개 변형의 모든 조합을 검증한 것이 아니다. 중요한 교차 사건은 [횡단 점검표](./01-02-problem-coverage-crosscutting.md)의 별도 절에 남겼다. 최종 시험 자료·반복 횟수·oracle·수치 목표는 만들지 않았다.
