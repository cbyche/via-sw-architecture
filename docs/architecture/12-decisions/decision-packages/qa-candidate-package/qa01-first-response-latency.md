## 1. 발표에서 설명할 한 문장

**입력이나 업무 사건 뒤 첫 내용 응답이 화면에 표시되기까지 걸린 시간의 산술평균이다.**

| 항목 | 현재 정의 |
| --- | --- |
| QA 이름 | 첫 응답 지연시간 |
| 단일 지표 | 평균 첫 응답 지연시간 `L` / 초 / 작을수록 좋음 |
| 목표 제안 | `L ≤ 1.00초` |
| 시작 | 실제 사용자 발화 종료 / 텍스트 제출 / 외부 Agent 사건의 최초 소비 가능 시각 |
| 종료 | 해당 Request/Task UI의 첫 완결된 내용 단위가 실제 표시된 시각 |
| 정답 여부 | 종료 조건이 아님. 오답도 같은 시간으로 포함 |
| 제외 | 인사, 알림음, spinner, 빈 카드, 의미 없는 첫 토큰, 미채택 내부 계획 |

화면에서 내용을 확인하는 대기다. 음성의 실제 전달은 QA09, 상세 표시와 전체 음성 준비를 포함한 목표 처리시간은 QA03에서 다룬다.

## 2. 왜 1순위인가

VIA는 사용자가 말과 화면으로 요청하고 진행 중인 업무에도 개입하는 소프트웨어다. 첫 내용이 늦으면 사용자는 입력이 해석됐는지 확인하기 어렵다. 사용자 가치에 따른 우선순위이며 모든 DP에서 큰 차이가 난다는 뜻은 아니다. **빠르지만 틀린 응답은 낮은 시간값과 낮은 정확도를 함께 갖는다.** 시간점수에 정확도 벌점을 섞지 않는다.

## 3. 첫 응답으로 인정하는 내용

| 종류 | 시간 종료에 필요한 내용 | 정확성은 별도 판정 |
| --- | --- | --- |
| 수행 안내 | 시스템이 채택한 대상 / 범위 / 수행 의도를 구체적으로 표시 | 사용자가 의도한 대상과 일치하는지 |
| 직접 답변 | 질문에 대응한 완결된 첫 내용 | 답이 맞는지 |
| 확인 질문 | 해결하려는 모호함을 구체적으로 제시 | 필요한 질문인지 |
| 업무 상태 / 결과 | 연결한 업무의 구체적인 상태 / 결과를 표시 | 실제 Task와 외부 사실에 맞는지 |

`네`, `알겠습니다`, `처리 중입니다`나 미해결 지칭을 되풀이한 빈 안내만으로 시계를 멈추지 않는다. 완결된 내용이라면 잘못된 대상, 불필요한 확인 질문, 사실과 다른 완료 안내도 실제 표시 시각을 사용하고 오류를 별도 기록한다. 내부 임시 후보가 아니라 실제 채택해 사용자에게 표시한 내용이어야 한다.

**위임은 선행조건이 아니다.** 구체적 수행 의도는 Agent 전송 전에 표시할 수 있다. 완료했다고 잘못 표시하는 행위는 여전히 기능 오류지만 시간값을 변경하는 근거로 사용하지 않는다.

Streaming의 첫 토큰은 종료점이 아니다. “매출표와…”는 미완결이며 “매출표와 비용 그래프를 비교하겠습니다.”가 완성된 첫 표시 프레임에서 멈춘다. 문장의 정답 여부는 따로 판정한다.

### 정정과 오답

- 0.4초에 첫 오답 내용이 표시되고 1.2초에 정답으로 고쳤다면 **이 사건의 시간값은 0.4초**다. 1.2초는 정정 이력으로 보존한다.
- 새 사용자 입력 revision은 별도 지정 사건이다. 앞 응답을 새 입력의 응답으로 재사용하지 않는다.
- 정상 폐기와 같은 Task의 진행 / 완료 병합은 공통 시나리오의 의무 사건 규칙을 따른다. 후보가 임의로 사건을 분모에서 빼지 않는다.
- S05/S11/S18/S19의 진행과 완료가 같은 최신 카드로 병합되면 두 사건의 종료 시각은 같아도 각각의 원래 source 시각부터 잰다.

## 4. 시계의 시작과 끝

| 입력 | 시작 시각 | 포함하는 대기 |
| --- | --- | --- |
| 음성 | 실제 마지막 음성 sample | endpoint 판단, 전사, 모델 / 네트워크, 채택, 표시 |
| 텍스트 | 제출 동작 | 입력 처리, 해석, 채택, 표시 |
| Agent 사건 | 외부 source에서 최초 제공 가능 | polling, 전달, 상태 연결, 표시 |

`t1`은 실제 UI 표시 프레임이다. 문자열 생성, UI enqueue, API 반환과 실제 표시는 구별한다. 응답 ID / revision과 화면 기록을 연결한다. 원격 시각은 동기화 오차를 기록하며 원격 제공 시각 대신 로컬 수신 시각을 몰래 사용하지 않는다. 계측 오차를 모르면 원값은 보존하고 작은 차이의 우열은 확정하지 않는다.

음성 재생 차례나 Agent 도메인 업무 완료까지 기다리지 않는다. 음성 준비와 실제 전달은 별도 기록한다.

## 5. 산식과 관측

```text
l_i = 첫 완결된 내용의 실제 UI 표시 시각 − 지정 입력 / 사건 시각
L = Σ l_i / N
N = 해당 비교에 등록한 관련 사건 수 × 5회
전체 제품 회귀 카탈로그를 사용할 때만 N = 120 × 5 = 600
```

**정답과 오답을 모두 같은 분모에 포함한다.** 오답을 제외하거나 정답이 나올 때까지 시간을 연장하지 않으며 `+∞`, timeout 대체값, 강제 0점도 사용하지 않는다. QA02 대상 지칭 오류는 QA02에서 판정하고 나머지 기능 오류도 별도 열에 기록한다.

표시 자체가 전혀 없으면 실제 지연을 얻지 못한 것이므로 `NOT_OBSERVED`로 남긴다. 30초 관측 종료 규칙은 시험 운영용일 뿐 30초라는 응답시간을 만들어 넣는 규칙이 아니다. 미관측 건수와 관측 범위를 공개하며 관측분 평균을 600건 전체 평균이라고 부르지 않는다. **이번 사고 실험은 등록한 DP별 관련 사건 모두 내용 표시가 있다고 가정하고 단일값을 산출**한다.

평균은 일부 긴 대기를 상쇄할 수 있다. 예를 들어 29건 0.2초와 1건 20초이면 평균 0.86초다. 이를 최대 1초 보장으로 설명하지 않는다. 원값과 분포는 보존하고 점수는 평균만 변환한다. 음수나 잘못된 시계는 계측 무효이며 빠른 값으로 인정하지 않는다.

## 6. 목표 1초의 근거

기존 조사에서 인용한 Nielsen의 사고 흐름 유지 1초 지침과 Microsoft Windows의 Pause 0.5~1초 구간을 첫 내용 표시 목표의 참조로 유지한다. **평균 1초로 집계하는 선택은 2026-10-15 사용자 지시**다. 외부 지침이 VIA의 평균이나 오류를 포함한 지표를 실증했다는 뜻은 아니다. 개별 응답마다 1초를 보장하지 않는다.

출처 확인일은 2026-10-14다. 문헌은 사용자 경험 지침과 특정 조건의 실험이다. **1초를 VIA의 합격선으로 채택하고 대표 시험의 산술평균에 적용한 부분은 본 과제의 제품 요구 제안**이다. 지침의 숫자를 기술적 달성 사실이나 모든 상황의 보편 법칙으로 바꾸지 않는다.

## 8. 이해 예시

`발화 종료 0.0 → “네” 0.1 → 내용 표시 0.8 → Agent 전송 1.3 → 음성 시작 2.5초`이면 0.8초다. 가상 4건의 시간 `0.8 / 0.6 / 1.0 / 0.8초`의 **평균은 0.8초 → 2점**이다. 그중 0.6초 응답이 오답이어도 평균은 0.8초다. 실제 측정값이 아니다.

## 9. 대표 사례와 DP별 예상 결론

DP별 비교에서는 DP-RELATED-v2의 관련 사건을 양안에 동일하게 사용하고 전체 600건 회귀 평균과 구별한다. 관련 경로 안의 쉬운 입력과 cache 적중도 유지하며 결과를 보고 사건을 빼지 않는다.

[72개 점추정과 산출 원장](./qa-dp-thought-experiment.md)은 이 가설을 수치화한 미측정 자료다. 작은 숫자 차이를 확정된 핵심 trade-off로 세지 않는다.

## 10. 후속 검증 범위

이번 요청은 사고 실험 문서화이며 PoC를 실행하지 않는다. 향후 검증할 경우 실제 UI 표시, 동일 입력과 클라우드 모델 조건, 각 await / queue / 호출 / oracle을 기록한다. 평균 차이의 실용 구분 제안은 `max(100ms, 느린 안 평균의 10%)`이며 수치 목표와 다른 기준이다. 양안의 오차를 고려하고 같은 5회 묶음의 방향을 확인한다. 오류 여부로 시간값이나 점수를 바꾸지 않는다. 관측 누락과 통계적 한계는 별도 보고한다.

## 11. 발표 한 장에 넣을 문안

> **첫 응답 지연시간:** 실제 입력 / 사건부터 첫 완결된 내용이 화면에 표시될 때까지의 산술평균.<br>
> **목표 평균 1초**, 0.2초 이내 6점. 600건 모두 정답 여부와 무관하게 실제 시간을 포함.<br>
> 인사와 spinner 제외. 구체적 수행 안내는 위임 전에 가능. 정확도와 음성 전달은 별도 QA.<br>
> 가상 0.8 / 0.6 / 1.0 / 0.8초 → 평균 0.8초 → 2점.
