# 독립 측정 리뷰 2차

> 2026-10-14 / 리뷰어 `review_measurement` / 1차 지적의 수정 검증과 QA1 전체 재검토 / 구현·측정 없음

## 결론

**1차 M-01~05의 문서상 결함은 모두 해결됐다.** QA1의 전체 본문을 다시 검토하면서 실제 관측 불확실성과 차이 판정의 연결에서 **새 P2 1건(M-06)**을 발견했다. P1은 없다. 이 문서는 문서상 재검토이며 PoC 실행 성공이나 품질 차이 입증을 의미하지 않는다.

## 1차 지적 재확인

## M-06 · P2 — QA1의 차이 확인이 실제 관측 오차보다 작아도 통과할 수 있다

- **위치:** [QA1 §4](../qa01-first-response-latency.md)의 clock·화면 관측 오차 문단과 §10의 5~6번. 검토 시점 65행 및 153~154행.
- **문제:** 현재 §4는 관측 오차가 10ms를 넘으면 공개하고 10ms보다 작은 차이로 승패를 내지 않는다고 한다. §10은 100ms 또는 느린 안 평균의 10%와 bootstrap 구간을 사용하지만 실제 관측 오차를 별도 자격 조건으로 적용하지 않는다. 두 안의 시각 상관에 각각 ±100ms 불확실성이 남고 평균 차이가 120ms인 경우처럼, 실제 차이를 분리할 수 없어도 100ms 기준과 반복성은 통과할 수 있다. 반복 bootstrap은 일정한 계측 편향을 제거하지 못한다.
- **최소 수정:** 차이 확인은 기존 실용 차이 기준에 더해 **A/B 차이의 결합 관측 불확실성보다 큰 경우에만** 허용한다고 명시한다. 각 시각의 상관·공통 오차가 제거되는 범위를 계측 근거로 정하고 차이의 보수적 오차 상한을 기록한다. 그 상한을 정할 수 없거나 관측 차이가 이를 넘지 못하면 수치는 보존하고 `판정 보류`로 보고한다. 특정 10ms를 모든 환경의 충분한 해상도로 오해하게 하는 문구를 이 규칙으로 바꾼다.
- **범위:** 정확한 장치 보정 자체는 후속 PoC 작업이다. 지금 필요한 것은 이미 알고 있는 계측 불확실성을 무시해 차이를 인정하지 않도록 판정 규칙을 닫는 일이다.

## QA1에서 다시 확인한 조작 방지 경계

- `네`, spinner, 빈 카드, 미완결 첫 token으로 종료점을 앞당길 수 없다.
- 원본 대상·범위와 수행 내용의 실제 채택이 있어야 하고 전송·접수·완료를 서로 바꾸어 안내할 수 없다.
- 발화 종료는 실제 sample이며 VAD나 전사 확정으로 시작을 늦출 수 없다. 외부 사건도 로컬 수신 이전 대기를 숨길 수 없다.
- UI queue·DOM/state 변경은 실제 표시를 대신하지 않는다. 음성 준비와 재생 대기는 UI 지표와 구별한다.
- 먼저 잘못 안내한 뒤 고쳐도 첫 정답까지의 시간과 앞선 기능 실패가 둘 다 남는다. 이 유한 진단값을 전체 기능 합격으로 해석하면 안 된다.
- 후보가 임의로 사건을 쪼개거나 폐기하여 분모를 늘리거나 줄일 수 없다. 정당한 정정에 의한 응답 의무 종료는 사전 fixture가 결정한다.
- 30초 제한 이후의 응답을 소급 성공으로 바꿀 수 없다. 미응답을 유한 벌점으로 잘라 빠른 표본과 상쇄하지 않는다.
- 선행 생산과 cache는 양안에 허용하되 같은 활동으로 준비하고 비용을 다른 QA의 원장에 보존한다. B만 준비시키거나 A만 지연시키는 비교를 허용하지 않는다.
- 문헌의 약 1초와 평균 1초 목표의 차이, 평균의 꼬리 지연 한계, 음성 청취와의 차이가 명시되어 있다.
- 44의 약한 가설과 42의 동점은 커버리지 달성으로 표시하지 않는다. 근거 없는 대안별 stub 지연을 추가할 수 없다.

## 남은 제품 판단과 검증 한계

평균 목표, 실패 한 번의 `+∞` 정책, 30초 관측 제한과 시험 유형의 비중은 구체화한 작성자 제안이다. 기술 문서의 모순을 해소한 것과 사용자가 이 정책을 채택한 것은 다르다. 본 재검토는 QA1 전체와 QA2·3·9의 수정 절 및 주변 계약을 읽어 수행했다. 새 문헌 검색이나 실제 Windows 계측·harness 실행은 하지 않았다. 1차에서 검증한 출처 범위를 이번에 독립 실험한 것처럼 확대하지 않는다.

M-06 보완 후 같은 120ms/±100ms 반례로 최종 재확인할 수 있다.
