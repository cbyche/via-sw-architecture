## Three necessary pre-run distinctions

1. **Independent semantic-goal concurrency is not clearly triggered.** S11/S18/S19 BG notifications use the same direct common Agent-fact path for A/B. Independent user questions follow the preceding final callback plus the authored wait/speech. S08 is a same-goal partial correction: its finalized transcript can overlap remaining old handoff/semantic work only if that work actually lasts beyond the wait/speech. Its overlap must be established from actual operations; it is not evidence for concurrent independent goals.
2. **The screen does not contain the small/dense/repeated-target condition.** S08/S15 are a single static source with five large uniquely visible objects. The actual parser path can run, but that does not make small-target robustness or arbitrary multi-page/free-region behavior observable. Those conditions cannot be validated by this sample.
3. **B's parser path still has an original-image Qwen producer.** The screen owner receives actual OmniParser output plus the original PNG to infer whole-item extents. A smaller binder/speech input does not mean the complete B path omits the image or costs less. Only actual native-selection sufficiency in S15 removes B's image/parser production calls. The local CPU helper's RAM and cold preparation remain part of this deployment, not a universal property of the originally proposed remote B service.
