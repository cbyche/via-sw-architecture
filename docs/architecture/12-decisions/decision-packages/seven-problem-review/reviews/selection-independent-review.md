## 1. 범위와 결과

검토 대상은 [06-agent-selection.md](../06-agent-selection.md), [현재 선택 근거 원장](../../../../../references/seven-problem-review/agent-selection.md), [고정 소스 원장 SEL-01~09](../../../../../references/five-problem-study/agent-selection.md), 공통 분석 기준과 accepted ADR-001~003이다. 이 검토에서 선택 문서와 원본 소스는 수정하지 않았다.

**현재 열린 P1/P2/P3 발견 없음. P3 2건 모두 수정 재확인 완료.** 기본 A 권고와 주요 DP 제외는 실제 성능 승리나 선택 기능의 삭제로 설명되지 않는다. 독립 성과 자료가 없다는 한계를 유지하면서 B의 반복 선택 이익과 다시 선택할 조건을 제시했다.

## 2. 발견

### SEL-R1 / P3: 기본 B의 전체 계약 재생산을 현재 구성으로 명시

- 위치: `06-agent-selection.md` §3.2 단계 3, 검토 시 61행. §9 B2, 검토 시 158행과 연결된다.
- 현재 문장은 누락 조건을 찾으면 “계약을 다시 만들고 선택”한다고 적고 B2에서 “전체 계약 재생산”을 보완한다. B의 두 판단을 분리하는 구조가 항상 전체 계약 재생산을 요구한다고 읽힐 여지가 있다.
- 제안: “이 기본 구성에서는 보완한 원문으로 요청 계약 전체를 다시 생산한다. 필드별 부분 갱신은 B2로 분리한다”라고 명시한다. 현재 기본 구성의 비용이라는 점을 밝히며, B 구조 자체의 필연적인 비용으로 일반화하지 않는다.
- 영향: 기존 비용 식과 추천을 뒤집는 발견은 아니다. 기본안과 선택 후 보완의 경계를 더 명확히 한다.
- 상태: **해소**. 2026-10-18 재확인에서 현재 기본 구성의 전체 재생산이며 모든 B 구조의 필연은 아니라는 설명과 B2 필드별 갱신 분리를 확인했다.

### SEL-R2 / P3: 통합 N-S 표에도 정당한 보류를 포함

- 위치: [09-qa-tradeoffs.md](../09-qa-tradeoffs.md) §5의 N-S 행, 검토 시 65행.
- 06 §7은 각 선택 기회의 허용 Agent 또는 정당한 보류를 기준으로 삼는다. 09는 “실제 선택한 Agent”만 적어 보류 사건이 분모에서 제외되거나 정당한 보류도 실패가 되는 정의로 읽힐 여지가 있다.
- 제안: “각 선택 기회의 Agent 선택 또는 보류가 독립 근거로 정한 허용 집합에 속함”으로 같은 정의를 유지한다. 해결 가능한 입력의 무조건 보류 금지는 06 §7과 함께 유지한다.
- 상태: **해소**. 2026-10-18 재확인에서 각 선택 기회의 Agent 선택 또는 보류를 같은 독립 허용 집합으로 판정하고, 허용되지 않는 보류는 실패로 기록한다는 문장을 확인했다. 06 §7과 정의가 일치한다. 선정 결론을 바꾸는 발견은 아니다.

## 3. 확인한 핵심 경계

| 검토 항목 | 확인 결과 |
| --- | --- |
| QA01과 QA03 | 선택 전에 이미 표시한 구체 안내 뒤의 선택 지연을 QA01에 넣지 않음. S15-G03 / S16 실제 결과 목표의 VIA 경로와 외부 대기를 구별 |
| QA04~06 | 실제 Rust diff 없이 변경 모듈 우위 없음. 전체 모델 비용과 로컬 RAM을 구별하며 IPC를 모델 요금으로 세지 않음 |
| N-S 독립 정답 | 후보 자기소개와 실제 capability / 업무 성과를 구별. 복수 허용 후보와 정당한 보류를 사전 정의하고 무조건 보류의 점수 이득을 금지 |
| A/B의 실제 근거 | 위임 도구에서 후보를 고르는 A와 별도 선택 문맥의 B를 구별. AutoGen의 후보 prompt가 최종 강제 적격성 검사라는 잘못된 확대 해석 없음 |
| VIA가 추가하는 계약 | registry / request revision과 최종 실행 허가를 harness의 완성된 기능이라고 주장하지 않음. B의 요청 계약은 VIA 설계 확장으로 읽힘 |
| 기능 및 상태 | 양안의 원본 보완, 사용자 지정, 단일 후보 경로, 적격성 재검사와 상태 불명 중복 방지가 유지됨. 취소 요청과 종료 사실 구별 |
| 제외 논리 | 기능의 중요도와 이 A/B의 현재 주요 DP 적합성을 분리. 세 번째 방향을 검토하고 적용 위치 또는 제외 이유를 기록 |
| 기존 ADR | 선택 제안 뒤 Task Manager / Agent Gateway로 실행을 넘김. adapter가 Task 원본을 직접 쓰거나 supervisor / 격리 경계를 교체한다고 주장하지 않음 |

## 4. 검토 한계

현재 문서와 이전에 확인한 고정 소스의 조사 기록을 대조한 검토다. 이번 독립 검토에서 모든 upstream 파일을 새로 내려받거나 전체 제품 동작을 실행하지 않았다. 실제 등록 후보의 연동 가능성, 독립 성과 기준, 정상 재선택 빈도와 QA 수치는 확인하지 않았다. 따라서 발견 없음은 선택 품질, 전체 기능 또는 성능의 검증 결과가 아니다.
