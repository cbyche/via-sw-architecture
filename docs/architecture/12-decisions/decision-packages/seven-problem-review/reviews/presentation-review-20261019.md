## 정규화 좌표 계약의 실행 전 교차 검토

실행/메모리 담당의 코드 검토에서 B의 정규화 wire 오류가 화면 생산자 `geometry_issues`에만 남고, 결합 모델 이후 공통 최종 검사에 강제 전달되지 않는 경로를 발견했다. 유효한 기존 pixel bbox 또는 중복 bbox가 포함되면 기존 pixel 검사를 통과할 가능성이 있었다. A는 wire 오류를 최종 issues에 포함하므로 같은 표현 계약이 비대칭적으로 적용될 수 있었다.

화면 담당은 host가 정규화 성공 여부를 응답마다 확정하는 `coordinate_wire_valid`를 추가하고 공통 최종 검사에서 생산자 확장 전·후 모두 확인하도록 수정했다. 기존 확장 한도는 그대로 유지했다. 독립 검토자는 재독 후 우회 경로가 닫혔고 공통 원본 축 변환, ties-even 반올림, raw cue pixel 단위, no-clamp와 frame/revision 검사가 일치함을 확인했다. 동결 전 native55/55, 실제 오프라인 정상8/8과 잘못된 pixel·중복 bbox 강제 거절 각4/4를 실행 담당이 확인했고 독립 검토자가 결과를 재독했다. 처음 test mock의 bbox 필드 가정 오류와 검사도구 수정 이력도 보존했다. 이 검토는 API 실행 후 결과를 보고 후보를 튜닝한 것이 아니다.

## PPTX 초안의 시각 수정

주 담당은 최초22장 PNG를 각 장 전체 크기로 확인했다. 다음 사항을 수정 대상으로 전달했다.

1. 모든 connector의 화살표가 출발점에 표시되는 문제: 목적지에 arrowhead를 붙이도록 수정.
2. 저장소 cylinder의 타원과 첫·마지막 텍스트 행 겹침: 높이·내부 여백·타원 크기 조정.
3. 세 열 구조에서 C안 상세가 압축되는 문제: DP1과 DP4를 각각 A/B 비교와 C 상세로 분리.
4. 선택 테두리와 장단점 문장의 겹침, 화살표 label 충돌: 별도 여백과 label 배치.
5. DP2 B의 짧은 답 직접 경로, 공통 호출 예산 및 DP3/DP4 최종 채택 gate의 누락: 실제 의미 흐름을 그림에 반영.
6. 표의 발표/저장소 번호 혼용과 문장 붙임·중복 조사: 발표 번호를 통일하고 본문 교정.

최종 슬라이드 수, native 편집 요소 확인, 패키지/geometry 검사와 전체 최종 PNG의 재검토는 최종 산출 시 아래에 기록한다. 초안 확인만으로 최종 품질 확인을 완료했다고 주장하지 않는다.

## 30장 두 번째 초안 확인

주 담당이 `renders-draft-v2/slide-01.png`부터30까지 전장을 전체 크기로 확인했다. 생성 담당도 별도로 시각 검토했다. native 도형354개, 연결선92개, 표17개, 그림0개로 초안 구조가 보고됐다. 최종 수치는 마지막 패키지에서 다시 확인한다.

- 8장 선택 테두리와 마지막 설명의 간격을 늘린다.
- 9장 호출 예산 label과 Request Controller 겹침을 해소하고 실제 표시를 명시한다.

- 21장 입력 token을21호출 합계로, 23장의 잘못된 첫 안내를 C 사례로 명시한다.
- 25장 DP3의 ‘선택을 바꿀 조건’을 미측정 QA 주석 대신 실제 구조 재검토 조건으로 고친다.

이 확인은 PPTX를 Artifact Tool로 다시 읽은 렌더 결과 기준이다. 실제 PowerPoint 앱이나 다른 OS의 글꼴 대체 결과를 검사했다는 뜻은 아니다.

## 세 번째 초안의 수정 확인

주 담당은 v3에서 바뀐 6·8·9·11·13·14·16·19·20·21·22·23·24·25·27·28·29장을 실제 PNG로 열어 확인했다. 나머지13장은 전장 열람한 v2와 PNG SHA가 같다. 생성 담당도 같은 범위를 별도 열람했다. 앞서 요청한 간격·권한 검사 순서·문구 수정이 반영됐으며 필수 수정 지적은 남지 않았다.
