# 네 DP PoC 실행 전 검토

2026-10-18 / 구현과 실제 실행은 사용자 승인 / 본 비교 수치 확정 전

## 수행 분담

계획과 평가 경계 및 결과 해석은 상위 담당이 검토한다. 구현, 코드 실행, 실제 Qwen 호출과 계측은 명시적으로 `gpt-6.1-sol`, `high`로 생성한 세 담당이 수행한다. 사용자 요청에 따라 기본안 10개 모두를 같은 네 episode와 세 반복으로 비교한다.

## 본 실행 전 발견한 사항

| 검토 사항 | 처리 |
| --- | --- |
| 의미 판단 실행에서 완료한 원래 결과를 관련 없는 후속 처리 끝까지 보류할 수 있음 | 결과 준비와 새 입력 관계의 판정 대기를 구분. 관계 판정에 필요한 보류와 무관한 처리 순서의 지연을 혼동하지 않도록 수정 |
| 의미 판단 실행 A가 완료된 이전 판단 문맥을 재사용하지 않아 B와 입력이 같음 | A는 대화에 유지한 판단 자료를, B는 공통 상태와 별도 요청 실행 상태를 사용하도록 수정 |
| 정정 뒤 재판단 결과로 원래 입력의 관계 판정 기록을 덮어쓸 수 있음 | 최초 입력의 관계 판정과 이후 정정 답변을 분리. 채점은 입력 ID와 revision으로 연결 |
| 인계 기록이 원본 정정 또는 접근 철회 뒤에도 다음 모델 입력에 남을 수 있음 | 다음 모델 전송 전에 기존 기록을 무효화하고 생산물 및 인계 설명의 출처, 판본, 허용 범위를 검사 |
| 근거 공급에서 이미 충분한 근거가 있어도 모든 안에 모델 두 호출을 강제 | 세 안 모두 공통으로 현재 유효 근거에서 즉시 답하거나 부족한 원본을 읽도록 수정. 유지 문맥과 게시 근거의 실제 재사용 경로를 보존 |
| 인계 채점기가 실제 중첩 계약 구조와 맞지 않음 | 실제 위임 ID와 mandatory 계약 및 출처 구조를 사용하는 전용 채점기로 연결 |
| 조기 실행 실패 뒤 아직 처리하지 않은 입력이 분모에서 사라질 수 있음 | 고정 입력에 지정된 전체 목표로 미응답과 미완료를 계산 |

## 이번 수치의 해석 경계

- 의미 모델과 이미지 입력은 실제 호출이다. 마이크, ASR, TTS, 실제 외부 앱 업무는 실행하지 않는다.
- QA01은 `DISPLAY_PROXY` 표시 콜백 관측이다. 물리적 화면 또는 음성 출력 지연으로 표시하지 않는다.
- QA02는 사전에 지정한 지칭 표현의 최초 채택 집합을 검사한다. 01의 원본 ID 집합과 04의 화면 대상 집합을 사용하며 일반 문장 품질로 확대하지 않는다.
- N-H는 외부 허가 시점의 인계 계약과 원본 출처를 검사한다. 자유문 설명이나 downstream 결과의 전체 사실 정확도에 대한 점수가 아니다.
- QA04는 실제 두 변경의 운영 Rust 모듈 diff와 확인 결과를 사용한다. 공통 adapter 때문에 모든 안이 같아도 그대로 보고한다.
- QA06은 측정한 프로세스와 카운터 범위를 명시한다. 원격 모델 메모리나 전체 VIA 제품의 메모리로 환산하지 않는다.
- 작성한 입력을 세 번 반복한 소규모 비교다. 동점과 예상 밖의 결과를 보존하고 대안 간 차이를 만들기 위해 결과나 모집단을 고치지 않는다.

최종 코드 및 입력 버전, 본 실행 건수와 수치는 결과 디렉터리의 freeze 및 실행 보고서에서 확인한다. 이 문서는 측정 완료나 최종 Architecture 채택을 선언하지 않는다.
