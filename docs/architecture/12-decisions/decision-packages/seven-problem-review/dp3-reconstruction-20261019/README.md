# DP3의 구조적 선택과 QA trade-off 재검토

2026-10-19 / 사용자 요청에 따른 설계 재탐색 / 새 구현·모델 실행·측정 없음

## 1. 결론과 검토 상태

DP3의 화면·발화 지칭 기능을 유지한다. 기존의 원본 공동 판단 A와 독립 후보 생산·결합 B를 주요 QA trade-off가 입증된 최종 비교로 취급하지 않는다. B의 병렬 실행은 현재 설계의 기본 동작이며, 과거 실행 ID B4의 pixel 실측을 활용할 수 있다. 순차 B와 병렬 B의 의미 판단 로직 차이를 정확도 이익으로 세지 않는다.

재탐색에서 가장 유망한 비교축은 **완성 입력 이후 공동 판단과, 발화 중 잠정 지칭 상태를 만들고 수정하는 구조의 비교**다. 전자는 버릴 계산과 활성 상태를 줄이는 조건이 있고, 후자는 사용자가 말하는 시간과 지칭 판단을 겹쳐 응답 대기를 줄이는 조건이 있다. 이는 실행 전 구조적 가설이며, 새 수치나 선택된 설계가 아니다.

이 축은 종전 문서의 A3/B3 증분 보완에서 출발한다. 새롭게 발견한 메커니즘이라고 주장하지 않는다. 종전의 화면/발화 분해축에 적용하던 보완을 **별도의 판단 단위·상태 수명 선택으로 재검토**한 것이다. 한 번의 호출 시작 시점만 바꾸는 수준으로 끝난다면 주요 DP로 승격하지 않는다. 의미 의존 상태, 무효화와 복구, 최종 채택의 계약이 실제로 달라지는지 확인해야 한다.

**QA02가 서로 다른 주요 QA trade-off라는 근거는 여전히 확보하지 못했다.** 이번 유망축의 핵심은 QA01 응답 대기와 QA05 전체 계산 비용의 상충이다. QA03과 QA06에도 경로가 있지만 실제 차이는 미확정이며, QA04는 실제 Rust 변경 없이 우위를 부여하지 않는다. 과정의 QA×DP coverage가 모두 충족됐다고 해석하지 않는다.
