# DP3 A/B 상세 설계 검토 기록

2026-10-21 / 문서와 구조 검토 / 구현·모델 실행·성능 평가 아님

## 검토 범위

두 독립 검토자가 [설계 문서](README.md)를 각각 검토했다. 첫 검토는 A의 기능 대등성, QA01/03 경계와 시간식, QA02/07의 중첩과 비용 계상을 확인했다. 둘째 검토는 B의 A+α 여부, 시각 생산과 의도 해석의 구분, 기존 DP47 계열과의 관계, 공식 구현 근거의 적용 범위를 확인했다.

## 발견 및 수정

| 중요도 | 발견 | 반영 |
| --- | --- | --- |
| P2 | 정확한 timestamp만으로 desktop pointer와 확대/crop frame 좌표를 연결할 수 없음 | 공통 좌표계 계약과 `coordinate_frames`를 추가. frame 크기, monitor/DPI, desktop/window 변환, crop offset/scale과 불확실성을 보존하며 불명확한 변환은 unknown 처리. |
| P2 | B 초기 생산 시간과 확장 경로에 같은 재생산 구간이 중복될 수 있음 | `P_B`는 첫 후보 revision까지, `G_B`는 이후 결합과 추가 조회·재생산·재결합으로 구분. 병렬 구간은 실제 의존 그래프를 따름. |
| P2 | QA03 제외 설명에서 후속 사용자 발화와 순수 청취·재생 차례가 빠짐 | 기존 QA03의 제외 항목과 VIA 포함 항목을 명시. 확인 질문 생성 및 답변 이후 재해석은 포함. |

검토에서 A의 원본 확대·재조회·복수 추론·native 정보·재사용을 제한한 문제는 보고되지 않았다. B의 후보 누락·경계 오류·identity drift를 공개하고, QA07 개선을 QA02와 독립 효과로 부풀리지 않은 점도 확인했다. 동일 시각 생산을 A의 보완으로 추가했을 때 B의 전체 계약이 실제로 필요한지 반증할 조건을 유지한다.

두 검토자가 각자 제기한 수정부를 다시 확인했으며, 위 세 P2의 해소를 보고했다. 해당 검토 범위에서 남은 P1/P2는 없다. 구조의 실제 성능을 확인한 리뷰는 아니다.

## 검증의 한계

문서의 로컬 링크, 그림의 XML·ID·좌표와 SVG/draw.io 생성물 동기화를 확인했다. macOS AppKit으로 SVG를 오프라인 PNG로 렌더하여 실제 그림을 확인하고, 여러 줄 텍스트와 화살촉의 렌더 호환성을 수정했다. 이러한 검사는 모델 capability, 실제 QA 우열, 제품 구현의 현재성이나 측정 결과를 입증하지 않는다. 기존 DP47 실측과 이번 제안 구성의 결과를 혼합하지 않았다.
