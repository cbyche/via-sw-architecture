## A 추가 교정 — 실제 모델 왕복과 연속 조회 판단 (2026-10-11)

사용자는 새 B 그림을 승인했고 A가 모델 한 번, 도구 한 번으로 끝나는 것처럼 보인다고 지적했다. B의 모든 scene 도형/텍스트/경로를 보존하면서 A만 교정했다. 전문 용어 대신 실제 클라우드 모델과 로컬 해석 제어기 사이의 호출/다음 행동 반환을 서로 다른 수직선으로 표시했다. 읽기 도구에서 임시 해석 맥락으로 돌아오는 큰 반환선과 제어기의 재호출 연결을 유지하고, 반복에서 검증기로 나가는 의미/확인 질문 제안 경로를 구별했다.

문서형 출력 예시는 첫 판단의 `task_retrieve`/`context_retrieve`와 조회 결과를 받은 다음 판단의 `interaction_retrieve`를 분리한다. 추가 결과도 같은 맥락으로 반환한다. 이 순서는 설명용 사례이며 도구 종류나 호출 횟수를 고정하지 않는다. 보고서 두 후보를 자동 확정하지 않고 실제 질문/새 답변 뒤의 Task1 의미 제안을 유지했다. Module 협력 구조와 아래의 별도 순서도를 합치거나 새로운 Component를 만들지 않았다.

- B 단독 scene을 수정 전/후 JSON으로 대조하여 정확히 일치함을 확인했다. 브라우저 PNG의 B 영역에서는 기존 그림과 세 픽셀의 미세한 raster 차이만 있었으며 도형/텍스트/경로 변경은 없다. A의 SVG 글자 geometry/겹침 오류는 0건이다.
- 두 PPTX는 41 비교 slide/notes part만 변경하고 나머지 package part와 장수를 보존했다. 최종 PPTX를 다시 import한 PNG를 검수했고 41 장의 native 도형/텍스트/경로 및 평면 이미지 0개를 확인했다. 원본 통합 PPTX, 다른 DP, MAIN과 사건도는 보존했다.
- 비교 생성 일치와 두 Python 버전의 41 생성 검사, 기존 MAIN/사건도 검사, RequestFrame 계약 검사, 재구체화 계약, 활성 용어, 159개 활성 Markdown 링크와 diff 검사를 통과했다. 기존 비선택 45 장의 layout 경고는 이번 변경과 별개로 보존한다.

## 최신 사용자 교정 — A/B 칸 독립, 비교 설명 행 제거
