# 이관과 독립 검토 기록

2026-10-21 / **SYNTHETIC_AUTHORED_NOT_MEASURED**

## 1. 이번 작업의 범위

DP3 세션에서 전달된 최신 A/B-R1/B-R2/B-R3 논의를 DP2와 DP5의 공통 QA 작업에 연결했다. 새 모델 실행이나 제품 계측은 하지 않았다. DP3 원본 폴더, 원본 생성기 및 PPTX는 읽기 참조로만 사용했다. 진행 중인 다른 세션의 수정은 이 작업에 포함하지 않는다.

원래 공통판에 Voice 수치를 덧붙이는 대신 **공통 의미를 가진 두 층의 통합판**을 만들었다. 이는 전달 요청에 제시된 명시적 voice-screen 층별 평가 방식이다. 동일한 모든 조합을 양쪽 workload에서 평가한 새 제품 구성을 작성했다는 뜻은 아니다. 해당 범위를 [공통 계약](01-common-contract.md)과 [구성 registry](02-configurations-and-scenarios.md)에 고정했다.

## 2. 원본 보존과 계산 변경

| 항목 | 원본 상태 | v2 처리 | 수치 영향 |
| --- | --- | --- | --- |
| Text 공통판 | 3구성, 120에피소드 | T- 접두와 Text profile 등록, 원장 재집계 | 21개 대표값 동일 |
| DP3 Voice/Screen | 4구성, 120평가+60준비 | V- 접두와 별도 Voice profile 등록, 원장 재집계 | 28개 대표값 동일 |
| QA02 판정 | DP3 source는 list equality | 공통 순서 무관 exact set | 현재 데이터의 판정 수 동일 |
| QA03 | Text goal projection, Voice 직렬식과 DAG | 부모 edge를 보존하고 각 목표 DAG 재검산 | 기존 시간 동일 |
| 채택 시각 | Voice가 채택/표시를 한 stage로 작성 | 해당 구간을 보존. 정밀한 가상 순간을 새로 추가하지 않음 | QA01 값 동일 |
| QA04 | C01~06가 각 source에 있음 | 같은 acceptance를 연결하고 구성당 6과제 유지 | 42개 구성별 변경 행, 과제 42종이 아님 |
| 비용 | source별 다른 usage schema | amount, rate, role, phase 공통 필드로 변환 | VIA 및 수신 비용 동일 |
| RAM | Text point, Voice stage 전체 snapshot | 소유 성분 합과 peak witness 보존 | 전체 peak 동일 |
| 원장 ID | 서로 다른 namespace | input, expression, goal ID와 출처 키 정규화 | 연결 수정, 수치 변화 없음 |

[manifest](../../../../presentations_files/qa-common-synthetic-v2-20261021/manifest.json)는 `parents/text.json`, `parents/voice.json`의 SHA256과 원본 경로를 기록한다. 원본 자료가 나중에 수정돼도 이미 생성한 부모 사본을 덮어쓰지 않는다. 생성기는 처음 사본을 만든 뒤 재실행할 때 그 사본만 읽는다. 새 원본 판본을 받아들이려면 새 dataset과 출력 경로를 만든다.

가상 시각과 비용, 오류 빈도의 현실성은 hash로 입증되지 않는다. hash는 사용한 문서 세대와 계산 연결을 식별한다. 원장의 모델 사용량은 작성값이며 공급자의 tokenizer나 청구 자료가 아니다.

## 3. 독립 검토와 반영

| 검토 | 발견과 판단 | 처리 |
| --- | --- | --- |
| 공통 경계 감사 | 모델 시간식, 기반 RAM, 준비 분모와 DP3 고정 주변 축이 Text와 다름 | 별도 두 profile, 교차 합계 금지, V의 DP2/DP5를 `FIXED_UNMAPPED`로 기록 |
| DP3 원장 독립 재산출 | 480응답, 9,540단계, 9,420사용량, 9,540RAM행, 24변경행의 산술 일치 | 현재 원값 보존. 실측 검증으로 표현하지 않음 |
| 통합 adapter 독립 검토 P2 | 시나리오 입력 ID는 원본, 응답 ID는 접두를 사용해 직접 join 불가 | input, goal, expression 모두 namespace 정규화. 원본 ID 별도 보존 및 모든 연결 assertion 추가. 재검토에서 해결 확인 |
| S3 근거 해석 | 실제 픽셀 없이 action 명세에 동일 객체라는 정답이 있음. 오답은 L→Z 대체 | 명세만으로 모델 식별 능력이나 중복 출력 오류를 입증하지 않는다는 한계 명시. DP3 원본은 수정하지 않음 |
| Voice coverage | 120평가가 모두 revision 1 신규 목표 | 후속 정정이나 DP2 겹침효과를 평가했다고 주장하지 않음 |

원장과 경계의 독립 재검토에서 남은 P1/P2는 없었다. 응답 1,200행, 지칭 1,230행, 목표 1,020행이 모두 시나리오 은행에 연결되고 49개 값과 manifest 해시가 일치했다. 이는 합성 계산과 의미 경계에 대한 검토 범위다.

별도 문서 검토에서도 49개 대표값과 60개 사례군/구성 행의 수치 및 분모가 일치했다. DP2 B, DP3 A, DP5 B는 각 층과 기존 우선순위에 한정된 개별 권고이며 결합 성능을 주장하지 않는 점을 확인했다. S3와 신규 목표 범위의 한계, R2 상주와 R3 독립 복구의 구분에 남은 P1/P2는 없었다.

원장 검증은 [validation.json](../../../../presentations_files/qa-common-synthetic-v2-20261021/validation.json)에 있다. 입력, 지칭과 목표의 정답 및 연결, 첫 표시, 외부 duration 제거 DAG, 사용량×단가, 소유 메모리 합, 6변경 과제, 원본 49개 값, 같은 profile 비교쌍을 확인한다. 오류/terminal의 의미 불일치는 별도로 보존한다.

Excel과 HTML의 검사 범위 및 저장된 수식 확인은 [산출물 안내](../../../../presentations_files/qa-common-synthetic-v2-20261021/README.md)에 기록한다. 계산 일치는 실제 대상 장치 성능, 사용자 오류율, Windows Excel 표시나 실제 화면/음성 출력을 검증한 것이 아니다.

최종 저장소 검사에서 활성 용어와 이번 변경 범위 링크는 통과했다. 전체 활성 링크 검사는 기존 `four-dp-presentation-20261019`의 보존 복사본에 남은 누락 링크 14건으로 실패했다. 이 작업의 원장이나 문서에서 발생한 오류가 아니며 보존 원본은 수정하지 않았다.

## 4. 다음 DP와 결합안을 추가할 때

이 판본을 후속 세션의 현재 진입점으로 사용한다. [v1의 인계 지침](../qa-common-synthetic-20261021/06-session-handoff.md)은 이전 세대의 생성 경로 설명으로 보존하며, 최신 dataset/registry와 원장은 이 문서의 링크를 따른다.

1. 새 DP의 최신 문서와 합의를 확인하고 실제로 바꾸는 실행, 상태 및 근거 생산 축을 등록한다. 원본 세션이나 미추적 파일이 있다는 이유로 준비 완료를 추정하지 않는다.
2. 현재 층과 같은 원본, 정답, 자원 및 완료 조건이면 그 층에 새 구성을 작성한다. 새 층이면 새로운 profile과 예정 분모를 먼저 등록한다. 적용하지 않은 셀을 0이나 동점으로 채우지 않는다.
3. 지금처럼 source를 보존한 층별 통합인지, 하나의 제품 구성을 모든 workload에서 비교하는 것인지 명시한다. 후자이면 고정 주변 축을 완전히 지정하고 기존 DP도 같은 새 조건에서 재작성한다.
4. 동일 작업의 중복 사용량, 공통 메모리 소유와 현재성 guard를 합성 구성에서 한 번만 센다. 개별 peak와 이익의 합으로 조합 수치를 만들지 않는다. interaction은 네 교차 구성이 있을 때만 계산한다.
5. Voice 정정이나 화면과 과거 평가의 결합을 추가하면 입력, 지칭 expression, 기존 goal revision, 원본 이용 가능 시점을 새 corpus에 작성한다. S3의 동일 객체 추론을 실행 검증하려면 evaluator-only 관계와 후보가 보는 시각 근거를 먼저 분리한다.
6. 새 판본의 모든 파생물을 같은 원장에서 재생성하고 독립 검토한다. 기존 가상 결과를 실제 실행 근거로 바꾸지 않는다. 새로운 실측은 별도 실행 dataset이다.

새 QA07의 우선순위와 점수, 기존 accepted ADR 및 실제 PoC 결과는 이 작업에서 변경하지 않았다. 개별 DP 권고와 결합 제품 채택도 구별한다.
