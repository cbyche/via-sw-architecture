# 설계 비교 발표 틀 검수 — 2026-10-06

두 독립 담당이 최신 실제 PNG를 다시 확인하여 **미해결 P1/P2 없음**을 보고했다. QA 수치의 우열, 원형 점수와 장단점의 방향은 서로 일치하며 예상 예시 및 미측정 표시를 확인했다. 실제 심사위원의 이해도 실험은 아니다.

## 검증 범위

- 다섯 장 모두 1920×1080, 개별 SVG/draw.io/PNG 및 통합 5페이지 draw.io 제공.
- 렌더러의 텍스트 경계, 선언 폭과 텍스트 간 겹침 모두 문제 0건. 화살표와 상태 경계는 실제 PNG로 별도 확인.
- 생성기에서 QA 이름의 발표자료 일치, 수치와 원형 점수의 방향 일치, 모든 이익/비용의 QA 대응, XML 셀 ID 및 SVG 화살촉 참조 검사.
- SVG와 PNG 해시를 기록하여 수정 후 미갱신 PNG 검출.
- 작업 시작 시 저장한 Architecture 및 배경 자료 314개 파일을 바이트 수준으로 보전. 기존 구조 비교와 배경을 덮어쓰지 않음.
- 별도 작업 중인 품질속성 발표 파일은 읽기만 수행하며 이번 변경 및 게시 범위에서 제외.
- 활성 링크와 용어 검사, QA 카탈로그, 기존 배경 생성기 일치 및 diff 검사 수행.

기존 참조 Architecture, QA/ADR, 대안 미선정 및 미측정 상태는 유지한다. PPT 제작은 이번 범위에 포함하지 않는다.
