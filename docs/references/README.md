# References

이 디렉터리는 VIA Architecture를 이해하거나 외부 주장의 출처를 추적하기 위한 참고자료를 보존한다.

References는 다음 역할만 한다.

- 공개 specification, paper, presentation 또는 내부 reference implementation의 provenance 제공
- planning profile이나 Architecture 고려사항의 배경 제공
- active 문서의 주장을 검토할 수 있는 출처 제공

References 자체는 요구사항, measurement contract, Architecture Decision 또는 VIA 측정 결과가 아니다. 적용 범위와 한계는 반드시 `docs/architecture/`의 active 문서에 명시한다. 현재 Architecture가 reference와 충돌하면 reference를 직접 기준으로 삼지 말고 충돌을 보고한다.

현재 내부 구현 참고자료는 [internal Rust voice agent](./internal-rust-voice-agent/README.md)에 있다.
