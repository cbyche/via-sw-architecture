# QA 문서의 주제별 목차 정리 전 기록

2026-10-10 사용자가 03-02 문서를 합의한 9개 목차로 먼저 정리하도록 지시해 보존한 논의 누적형 원본이다. [당시 문서](./03-02-quality-attribute-definitions.md)는 당시 §7~8의 정확성 논의와 §9 Voice PoC v2 평가 설계를 포함한다. 실행 결과는 없다. 상대 링크는 당시 활성 경로를 기준으로 보존했다.

[현재 03-02](../../architecture/12-decisions/decision-packages/03-02-quality-attribute-definitions.md)는 §3에 정확성의 현재 정의/평가를, §8에 공통 시험 환경/A/B 구성을, §9에 합의/변경 이력을 둔다. 본 기록은 현재 정의를 대체하지 않는다. 목차 정리는 Voice PoC v2의 지표/분모/목표나 DP 선택을 변경하지 않았다.
