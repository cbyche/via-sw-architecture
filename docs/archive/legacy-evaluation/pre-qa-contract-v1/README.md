# Legacy VIA Evaluation Before QA Contract v1

Everything below this directory is preserved historical material. Its QA identifiers, metrics, populations, targets, and scoring semantics are not those of QA Evaluation Contract v1.

The archived quality-attribute documents retain the complete legacy definitions used to interpret DP-00 work. Stable redirect files remain at their former paths under `docs/evaluation/quality-attributes/`.

Do not reuse legacy scores as QA-v1 scores without creating the required QA-v1 populations and running a new compliant evaluation. Do not rewrite historical numerical results.
