# 공통 활동 연결을 보완하기 전 ASR-QA-v4

2026-10-11 사용자 리뷰는 비용/메모리의 8시간 조건과 활동량 근거가 불명확하고, 정확성/시간의 사례와 구체적으로 연결되지 않았다고 지적했다. v4 정의/계산/발표/재현 코드를 원래 bytes/hash로 보존했다. 링크와 코드는 당시 배치를 전제로 한 역사 자료다. 실행된 후보 성능은 없었다.

현재 정의는 [03-02](../../architecture/12-decisions/decision-packages/03-02-quality-attribute-definitions.md)의 ASR-QA-v5와 공통 활동 W100을 따른다. 기존 v3의 18개 원문/정답과 v4의 시간 전용 추가 사건/30분 입력/8시간·3session 가정은 이 archive에 보존했다.
