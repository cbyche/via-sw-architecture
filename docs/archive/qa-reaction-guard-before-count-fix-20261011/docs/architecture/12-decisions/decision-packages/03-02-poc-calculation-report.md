## 모델 근거와 공통 활동 예산

의미 모델은 Alibaba Cloud Model Studio Singapore/International의 Qwen3-30B-A3B-Instruct-2507 non-thinking 입력 $0.20/출력 $0.80 per 1M token이다. 생성률 100/130/160 token/s와 별도 TTFT는 작성자 가정으로, 공개 API 보장/실측이 아니다. 화면 사례는 공통 observation 사실의 Text 직렬화를 입력하며 별도 픽셀 인식 모델은 이 예산에 포함하지 않는다. 음성은 GPT Realtime의 별도 단가(audio 입력 $32/출력 $64, Text 입력 $4/출력 $16 per 1M token)다. 신규 audio 길이 환산은 이력 audio 재입력/특수 token을 포함한 총 청구가 아니므로 실제 modality별 usage를 합산한다. 공통 모델/설정은 양안에서 동일하다.

P21은 메커니즘별로 선정한 21개(사용자19/Agent단독2, 집중장면 내부Agent4사건)의 공통 묶음이다. 전체5회만 반복하며 정확성105/630, 반응135, 처리95의 모든 관측을 함께 읽는다. 계획 발화21개의 입력50초, 출력179초는 fixture/작성자 예산이고 실제 사용통계나 실행결과가 아니다.

## 선택한 Qwen의 공개 속도와 이전 단가 비교

현재 Qwen의 같은 token 예산은 P21 의미 비용 $0.03472, GPT Realtime 신규 audio/청구 Text 포함 기본 소계 $0.35184다. 이전 Gemini 단가로는 의미 $0.09920/기본 $0.41632였으며 단가 민감도 비교만 보존한다. tokenizer/출력/호출/정확성 동등성이나 후보 실행 결과를 주장하지 않는다.

Qwen 공식 H20/SGLang benchmark는 Qwen3-30B-A3B 원본의 (입력+출력)/전체시간이다. 2048 출력과 BF16 입력1: 137.18로부터 전체 약14.94초/유효 출력률137.11을 복원하고, 입력6144: 490.10으로부터 약16.72초/유효 출력률122.53을 복원한다. 이 합산율을 Instruct-2507 API decode rate로 사용하지 않는다. 수치 규모를 참고하여 130 token/s의 별도 decode 가정과 100/130/160 민감도를 둔다. TTFT는 benchmark에서 분리해 추출한 값이 아니며 입력 처리 시간을 중복 합산하지 않는다. 가격/속도 reference는 다른 배포 조건이다.

## 41의 충분한 typed 근거 조건

## 짧은 전이와 cache/생산 비용

42의 S6-04 정상 답변 한 번은 A 0.010초/B 0.025초라는 지역 commit/receipt 가정이며 차이 0.015초다. 44의 S5-04 callback/stage 6회는 A 6×0.010=0.060초/B 6×0.005+join 0.020=0.050초이며 차이 0.010초다. 두 차이는 대표 사이클의 0.5초 차이 기준에 못 미친다. 이 일부 구간을 전체 QA 평균으로 소개하지 않는다.

45의 S2-02/04/05 과거 근거 처리만 보면 A 3회 cache miss $0.00288, 강한 cache의 A 1회 miss $0.00096, B가 초기/새 근거/갱신을 합쳐 4회 관계 생산하는 가정 $0.00608다. A miss 6.333333회에서 비용이 같고 실제 생산/재사용 빈도에 따라 순위가 바뀐다. 원천 갱신 수가 생산 수를 강제하지 않는다. 이 비용이 공통 예산 호출과 겹치면 교체하고, 별도 호출이면 추가하여 중복 계산하지 않는다.
