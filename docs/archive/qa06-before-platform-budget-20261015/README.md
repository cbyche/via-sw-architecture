# QA06 시스템 요구사항 반영 전 기록

2026-10-15 개정 직전 `1609e0a9037b00999fe2cf4116bb82dc6b7251ce`의 문서 사본이다. 과거 출처와 링크를 원형으로 보존했으므로 이 폴더의 상대 링크를 현재 읽기 경로로 사용하지 않는다.

이 판본은 QA06의 부적절한 512MiB 참조를 철회한 뒤 새 목표를 확보하기 전의 기록이다. 이후 사용자가 과제의 PC 플랫폼 및 기술기획 측 시스템 요구사항으로 **512 MB**를 지정했다. 현재 정의와 RAM-v3-MB 점수는 [활성 QA06](../../architecture/12-decisions/decision-packages/qa-candidate-package/qa06-local-memory.md)에서 확인한다. 이 기록은 현재 목표나 측정 결과가 아니다.
