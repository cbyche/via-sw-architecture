# 후보 문서 경로 안내

현재 후보는 [VIA-DP-01~18](../README.md)에서 관리한다. 이 디렉터리의 이전 계열 파일은 링크 호환 안내다. 과거의 ‘4개만 비교’, ‘fast path 고정’, ‘나머지 축 재개 금지’는 현행 inventory의 제외 기준이 아니다.

- [전체 요약](../dp-executive-summary.md)
- [이전 계열 매핑과 누락 점검](../legacy-dp-mapping.md)
- [공통 후보 계약](./common-contract.md)

기존 승인 ADR의 상태는 유지한다. 현행 QA에 대한 구현·측정과 최종 ASR 선정은 완료하지 않았다. 이전 문서 사본은 docs/archive/dp-review-pre-inventory-2026-09-25/candidates에 보존했다.
