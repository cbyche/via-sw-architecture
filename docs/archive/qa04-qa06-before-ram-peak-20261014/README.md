# QA04와 QA06의 목표 재검토 전 기록

2026-10-14 사용자가 QA04의 데이터 형식 변경 1개와 기능 확장 5개 모듈 가정 및 QA06의 1GiB 확보량 목표를 지적하기 직전의 상세 문서를 보존한다. 원본은 commit `19a677850a1fc36e03529c563ddd4fd14364dce5`와 같다.

- QA04의 평균 3개와 CHG-v1 점수는 실제 수정 경로에서 도출하지 않아 철회했다.
- QA06의 MEM-v2는 확보량을 측정했으며 실제 RAM 사용 중 최고량과 다르다. 내부 예산 합산으로 1GiB를 정당화한 근거와 점수는 철회했다.
- 이 기록은 현재 목표나 결과가 아니다. 당시 상대 링크는 원래 위치를 기준으로 보존한다.

현재 문서는 [QA04](../../architecture/12-decisions/decision-packages/qa-candidate-package/qa04-change-scope.md)와 [QA06](../../architecture/12-decisions/decision-packages/qa-candidate-package/qa06-local-memory.md)이다.
