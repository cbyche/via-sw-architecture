# 46 이름/연결 중심 MAIN — 표현 수정 전 이력

사용자는 실제 동작 차이가 그림에서 이름 차이로만 보인다고 지적했다. 이 파일들은 2026-10-10 MAIN 표현 수정 직전 기록이며 현재 도식의 원본이 아니다. 실제 A/B 설계, 기능과 QA 가설의 변경 기록이 아니다. 보존한 generator의 경로는 당시 레이아웃이며 재실행용 현재 경로가 아니다.

현재 [46](../../architecture/12-decisions/decision-packages/04-46-input-and-context-evidence.md)의 MAIN은 조회/원본 결합과 생산/게시/조회가 주고받는 실제 자료와 조건을 드러내도록 다시 배치한다.
