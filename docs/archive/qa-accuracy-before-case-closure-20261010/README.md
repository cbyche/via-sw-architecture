# 정확성의 18개 사례 상세 명세를 닫기 전 기록

2026-10-10 사용자가 초기 상황, 입력, 사건 순서와 채점을 먼저 닫도록 지시하기 전의 Voice PoC v2 문서다. 대표 상황과 채점 요약은 있었지만 실제 자료 내용, 후속 답변, 경쟁 사건 순서와 사례별 통과 조건에는 빈칸이 남아 있었다. 현재 명세의 완결성 근거로 사용하지 않는다. 구현/모델 실행/실측 결과는 없다. 상대 링크는 당시 활성 경로로 보존했다.

[현재 03-02](../../architecture/12-decisions/decision-packages/03-02-quality-attribute-definitions.md)의 Voice PoC v3은 §3.2.2에 18개 상세 명세, §3.3.1에 공통 판정 규칙을 둔다. 사례 수/6개 채점 유형/5회 반복/목표 비율은 유지하며 초기 값과 정답에 영향을 미치던 사건 순서를 구체화했다.
