# QA02 지칭 대상 식별 정확도 조사 부록

> 조사 확인일 2026-10-14 / [현재 QA02 명세](../qa02-referent-accuracy.md)

## 1. 조사 질문과 제품 요구

“50건당 1번 틀려도 된다”는 허용 오류를 다른 말로 반복할 뿐 목표의 외부 근거가 아니었다. 사용자가 화면과 과거 자료를 직접 찾아 선택하는 수고를 음성 지칭으로 줄이면서 **기존 직접 선택의 신뢰 수준을 유지한다**는 요구로 다시 구성했다.

## 2. 수동 선택 연구의 조건과 수치

| 출처와 위치 | 실험 조건 | 확인한 수치 | 사용할 범위 |
| --- | --- | --- | --- |
| [Sasangohar, MacKenzie & Scott, HFES 2009](https://www.yorku.ca/mack/hfes2009) / Error Rates | 12명. Tabletop에서 표적 폭과 거리 16조건의 반복 선택. 마우스 emulator 한계가 보고됨 | 마우스 오류 2.1% → 성공 97.9%. 터치 오류 9.8% | 수동 선택의 참조 사례. 일반 PC 사용 전체의 평균이나 VIA 실험이 아님 |
| [Rajanna & Hammond, Can Gaze Beat Touch?, 2022](https://arxiv.org/html/2208.01248) / Table 2 및 실험 설계 | 12명. Desktop ISO 9241-9 선택 과제. 입력 방식별 2,496회. 표적 폭 230/330px | 마우스 오류 1.3% → 성공 98.7% | 제품 목표의 주요 참조값. 큰 표적의 운동 과제이며 의미 해석과 복수 대상의 동등 과제는 아님 |

후자의 성공률 98.7%를 정수 단위로 올린 99%를 제안했다. 두 실험의 성공률을 평균내지 않았고 실험별 표본을 합쳐 더 강한 통계 근거를 만들지도 않았다. “오류 1%를 사용자가 감내한다”는 만족도 조사로 바꾸지 않는다.

## 3. 다른 연구와 통계 자료

| 자료 | 조사한 내용 | 목표값에 직접 사용하지 않은 이유 |
| --- | --- | --- |
| [ReCLIP, ACL 2022](https://aclanthology.org/2022.acl-long.357/) | 자연어 지칭과 영상 대상의 연결 및 공간 관계 추론 | 과제의 연구 배경을 뒷받침한다. VIA의 99%나 DP-47 B의 우세를 직접 제공하지 않음 |
| [Shuang Xu, Understanding Users' Perception of Speech Recognition Errors, 2009](https://condor.depaul.edu/sxu/Publications/J2_UnderstandingUsersPerceptionOfSpeechRecognitionErrors.pdf) / p.11 | 주요 음성 받아쓰기 수단으로 채택할 정확도 기대를 다룸 | 받아쓰기 인식 정확도와 지칭 대상 집합 일치율은 다른 지표이므로 수치를 전용하지 않음 |
| [NIST TN 2045](https://www.nist.gov/publications/confirming-performance-threshold-binary-experimental-response) | 이진 성공 결과에서 목표 성능을 확인하는 표본과 수용 기준 | 목표의 선택과 실제 통계적 입증을 구별할 근거 |
| [NIST 이항비율 신뢰구간](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm) | 작은 표본과 적은 실패에서의 정확 이항 구간 | PoC 관측 비율을 모집단 성능 보장으로 확대하지 않기 위한 방법 |

독립 시행 100건이 모두 성공해도 단측 95% 신뢰하한은 약 97.05%다. 산식은 `0.05^(1/100)`이다. 현재 20개 fixture를 5회 반복한 설계에는 같은 사례의 의존성이 있으므로 이를 독립적인 실제 사용자 상황 100개로 간주해 이 신뢰구간을 적용하지 않는다.

## 4. Downstream 복구율 논리를 사용하지 않은 이유

사용자의 예시인 `VIA 성공 90% + VIA 실패 10% × downstream 복구 90% = 전체 99%`는 두 확률의 조건이 맞아야 성립한다. 필요한 후자의 값은 **VIA가 잘못 해석한 요청을 받은 조건에서 의도를 복구한 성공률**이다. 일반 PC Agent benchmark의 업무 성공률은 이 조건부 복구율이 아니다. 그 값을 그대로 대입하는 논리는 채택하지 않았다.

잘못 전달된 대상이 명확한 지시처럼 보이면 downstream이 오히려 그 대상을 충실히 처리할 수 있다. 따라서 임의의 복구 가정으로 VIA의 정확도 목표를 완화하지 않는다.

## 5. 발표에 사용할 집합 예시와 점수 해상도

“이 두 개”라는 지칭의 정답이 `{표 A, 그래프 D}`이면 다음과 같이 판단한다.

| 채택 집합 | 사건 판정 | 이유 |
| --- | ---: | --- |
| `{표 A, 그래프 D}` | 1 | 전체 일치 |
| `{표 A}` | 0 | 대상 누락 |
| `{표 A, 그래프 C}` | 0 | 다른 대상 |
| `{표 A, 그래프 C, 그래프 D}` | 0 | 불필요한 대상 추가 |

가상 100판정 중 99번 일치하면 99%와 1점이다. 정수 계수 100건에서는 합격 점수가 99%의 1점과 100%의 6점만 나올 수 있다. 중간 점수 칸을 채우려고 사례를 복제하거나 분모를 늘리지 않는다. 원본과 범위 및 필요한 버전의 정답 규칙은 현재 명세를 따른다.

## 6. 발표자 노트와 후속 검증

- **핵심 답변:** “수동 선택을 음성 지칭으로 대체할 때 유지해야 할 신뢰 수준을 참조했습니다. 같은 과제의 비열등성 실험을 완료했다는 의미는 아닙니다.”
- 화면 지칭과 과거 지칭에 같은 집합 일치율을 적용하되 다른 DP의 점수를 직접 대조하지 않는다.
- 근거 부족 사례의 확인 질문과 식별 가능한 사례의 정확도를 사전에 구별한다. 결과를 본 뒤 어려운 실패를 모호한 사례로 빼지 않는다.
- DP-47의 양안은 원본 재조회와 부분 정정이 가능하므로 후보 분리만으로 정확도 이익을 주장하지 않는다. 같은 지표의 적용 가능성과 실제 차이는 별개다.
- 후속 자료: 지칭 단위별 oracle과 source revision, 채택 집합, 최초 오답과 수정 이력, 두 검토자의 판정 근거를 준비한다.
