# 46 A/B 배치를 다르게 그린 MAIN — 사용자 반려 이력

사용자는 A/B의 세로/가로 배치 차이가 설계 차이처럼 보이게 하는 표현을 반려했다. 이 산출물은 현재 설명 원본이 아니다. 실제 A/B 설계는 바꾸지 않고 동일 Component/원본/요청 좌표에서 읽기/쓰기 경로를 비교하도록 표현을 수정한다.

현재 [46](../../architecture/12-decisions/decision-packages/04-46-input-and-context-evidence.md)을 읽는다. 보존한 generator는 재실행용 현재 경로가 아니다.
