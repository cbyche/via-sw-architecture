## 검토 범위와 수정

- DP-44/47/45/42의 A/B에 QA01~09 모두를 적용한 72개 원값과 점수를 작성했다. [현재 원장](../qa-dp-thought-experiment.md).
- QA01/03은 사용자 지시대로 산술평균이며 오답에도 실제 시간을 사용한다. 이전 최대값 / 정답 대기 / 시간 실패 벌점 제안은 archive에 보존했다.
- 후속 점검에서 발표 원고 QA03 산식에 남아 있던 바깥 max와 조사 메모의 최대값 예시를 평균으로 고쳤다. 한 목표 내부의 최장 경로와 QA06 RAM 최고값은 유지한다.
- QA02의 뒤늦은 정답이 QA01 시간을 바꾼다는 이전 문구를 제거했다. 첫 오답의 실제 표시시간이 그대로 남는다.
- 새 사고 실험에서는 QA09도 채택된 내용의 실제 전달시간을 사용하며 기능 실패 벌점을 섞지 않는다는 범위를 표시했다. 기존 음성 기능 검증 계약의 통과를 주장하지 않는다.
- 네 A는 같은 통제 구조이며 B 하나만 바꾼다. 44A의 비동기 worker, 47B의 원본 확장, 45A의 cache, 42A의 모듈화와 독립 논리 수명을 유지한다.
- 비용 원장에는 B45의 각 S 초기 생산과 입력 이후 갱신이 포함되고 모델 출력량은 참조 예산과 기대 사용량을 구별한다. RAM은 같은 순간의 resident 구성이고 공유 영역을 중복 가산하지 않는다.
- QA04 계획 모듈 집합에서 QA08 교집합을 직접 산출했다. 실재 Rust diff가 아니므로 DESIGN_CHANGE_REVIEW를 표시했다.
- 배점 경계를 조절하지 않았다. 47 QA01 약 29ms와 45B 비용 $0.00038 초과가 점수 차이를 만드는 민감한 경계임을 밝혔다.
