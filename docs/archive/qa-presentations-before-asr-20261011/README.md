# ASR-QA 발표자료 전환 이전 기록

사용자 지시로 2026-10-11 이전 V-01~10 발표자료, 문안, 상세 시험 초안과 생성/검사 코드를 원래 경로 구조 및 byte 그대로 보존했다. manifest.json은 원본 경로와 SHA-256이다. 이곳의 링크/코드는 당시 경로를 전제로 한 역사 자료이며 현재 실행 계약이 아니다. 최신 정의는 [03-02](../../architecture/12-decisions/decision-packages/03-02-quality-attribute-definitions.md), 새 발표자료는 [요약](../../presentations_files/quality-attributes/README.md)과 [QA별 근거](../../presentations_files/quality-metrics/README.md)다.
