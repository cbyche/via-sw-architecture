# 33의 A/B 비교 보존본

2026-10-05 A/B/C 재구성 이전의 문서, 두 그림 쌍과 생성기다. 역사적 근거이며 현재 요구나 추천이 아니다. 생성기는 당시 공유 모듈 및 다른 주제 자료에 의존하므로 이 경로에서 실행하는 독립 도구가 아니다. 원문의 상대 링크는 당시 위치를 보존한다.

현재 설계는 [33 A/B/C 비교](../../architecture/12-decisions/decision-packages/04-33-dialogue-coordination.md)를 읽는다. 이전 B의 Task 없는 주제 actor까지 포함하는 설명은 현행 B의 공통 대화 처리와 Task별 처리 구분으로 대체했다. 최종 구조 선택이나 성능 검증은 없다.
