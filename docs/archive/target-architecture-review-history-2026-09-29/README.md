중복 설명 문서 `interaction-and-memory-design.md`는 활성 폴더에서 삭제했다. 직접 응답 예시는 제어 계약에, 복합 요청 책임 경계의 예외는 Architecture 본문에, 기억 정책과 모델 계약은 각 상세 문서에 통합했다. 삭제 전 문서 전체는 위 Git commit에 보존되어 있다.
