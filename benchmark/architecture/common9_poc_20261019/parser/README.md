The live dependency is OmniParser-v2.0's legacy YOLO detector, EasyOCR Korean+English and Florence2 icon caption model on local CPU, two inference threads. Official source is pinned to `354021201345a96178360b28733573e27269f2de`. This is an actual local deployment diagnostic; the originally proposed cloud parser's service latency and price remain unmeasured. All helper RSS belongs to the measured local process sum.

Task-local Python runtime: `/private/tmp/via-dp04-omniparser-venv/bin/python`. Common9 runtime source: `/private/tmp/via-common9-omniparser`; its model/cache directories reuse the already downloaded task-local files through recorded filesystem aliases. No model is duplicated per role or request. The common9 adapter keeps one helper per episode, loads on the first actual need and reuses parses only for the same frame/source revision/content SHA. The runtime samples its exported PID registry before initialization completes. Native selection alone can satisfy the S15 path without launching the helper; unselected S08 pointer targets require actual visual production.

Then `parser/probe.py` checks the real helper and adapter/cache/PID protocol without sending cloud model calls. `write_inventory.py` records actual loaded weights, remote code, upstream adapter diff and package lock. The result inventory stores SHA256 for all four loaded checkpoint files, totaling1,223,774,646 bytes. Extra cached English-only OCR weights are not loaded by the common9 configuration.

A local alias points to the same caption checkpoint; no learned weight or model algorithm was changed. The exact diff and hashes are under `results/architecture-evaluation/current/common9-poc-20261019/parser-feasibility/`.

The first two attempts initialized the complete stack but failed caption attention-mask shape checks because the checkpoint path omitted the official Florence suffix. Both configurations' actual preflights remain preserved; they are not pooled or claimed as common9 QA outcomes.

`GroundingAdapter(root,buffers)` exports mutable `processes: dict[pid,role]`, `process_history`, `call(payload,meta)` and `close()`. The common bridge intercepts `grounding.local_screen_parser`; this call must never reach Qwen with `max_tokens:0`. Records classify the operation `LOCAL_MODEL`, distinguish initialization/inference/cache hits, preserve failures and raw responses, and explicitly leave monetized local compute cost unmeasured. Zero API charge is not zero resource cost.

The sampler merges this with actual Rust process metadata. This supports the pre-formal startup-zero policy without delaying registration, initialization or the stimulus.
