# QA-v1 Frozen Corpus

This directory contains the materialized, deterministic evaluation populations
for QA Evaluation Contract v1. The authoritative population status and artifact
hashes are in `benchmark/contracts/qa-v1/corpus-manifest-v1.json`.

`goals/catalog.json` is the shared source for the 600 QA-02 goals. QA-01 refers
to a 150-goal fast subset rather than duplicating goal definitions. Every
counted population has stable family, instance, oracle, and population-manifest
artifacts. QA-07 is deliberately a non-counted fixed timeline whose instance
artifact lives under `benchmark/fixtures/qa-v1/resource/`.

Every family and materialized case carries product-semantic `use_case_tags`.
The generated coverage authority is
`benchmark/contracts/qa-v1/use-case-coverage-v1.json`; tags never prescribe a
candidate route or component.

The official corpus is generated by:

```sh
.venv/bin/python benchmark/scenarios/qa-v1/materialize_corpus.py
```

Generation is deterministic and uses no random source, Cloud API, model API,
network request, or API key. Semantic decisions use frozen replay fixtures;
Agent behavior uses anonymous deterministic capability profiles. Historical E2
artifacts contribute semantic concepts only. No historical observation or
legacy score is part of this corpus.

Materialization creates the measurement instrument. It does not evaluate an
architecture and does not establish production representativeness.
