# Architecture Request Suite

The production request suite is maintained here as structured YAML/JSON later.
This markdown file documents initial scenario categories.

## Categories

- Local voice / fast path
- Screen-context / pointer grounding
- Downstream Agent delegation
- Conversation / task continuity
- Concurrent task / recovery / conflict
- Natural long / compound speech

## Natural-speech principle

At least half of voice performance scenarios should use natural 6–15 second utterances including some of:

- hesitation
- fillers
- self-correction
- omitted app/source
- deictic expressions
- mid-utterance priority change
- multiple requests

See approved requirements baseline for the current detailed suite.
