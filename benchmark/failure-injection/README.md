# Failure Injection Suite

Future scored recovery cases belong to `qa08-recovery-v1` and must follow QA Evaluation Contract v1 plus the corpus manifest. The examples below are planning inputs, not generated QA-v1 instances or evidence.

Planned cases include:

- voice connection disconnect
- Task Manager restart
- Downstream Agent timeout
- model endpoint unavailable
- duplicate AgentEvent
- cancel/completion race
- Context Connector failure
- exclusive-resource conflict
