# VIA Evaluation Results

These directories contain historical evidence unless a result explicitly carries a valid QA-v1 provenance envelope with `qa_contract_id = qa-evaluation-contract-v1` and matching artifact hashes.

- `raw/`: immutable observations and execution evidence.
- `derived/`: recomputable metrics produced under their recorded analyzer/contract.
- `reports/`: human-readable and machine-readable summaries.

Legacy names such as `qa03-v1` refer to their historical experiment version, not QA Evaluation Contract v1. Never translate their scores or denominators.
