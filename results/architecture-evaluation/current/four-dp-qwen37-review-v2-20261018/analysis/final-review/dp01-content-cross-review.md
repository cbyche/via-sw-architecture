# DP01 수동 내용 진단 독립 교차검토

2026-10-18. **선별29문안에 한정한 독립 원문 대조**다. 저자의108문안 전수판정을 독립 재심사한 것은 아니다. API·후보·동결 source·자동 scorer·QA02·실행 파일은 바꾸지 않았다.

## 범위와 결론

E3의18문안(2질문×A/B/C×3회), E4q2 조건 비교의9문안(A/B/C×3회), E4q3의 번역/계약한계 경계2문안(A r1,B r3)을 읽었다. 각 actual_detailed_text를 **실제 raw GOAL_COMPLETE text와 SHA**로 대조했고, 저자가 인용한 source 파일 SHA와 원문 행도 확인했다. 29/29 일치한다. 증빙은 `dp01-content-cross-review-checks.json`이다.

선별 범위에서 저자 판정18 PASS/7 FAIL/4 PARTIAL에 동의한다. A/B의 실제 누락은 실패로 두면서 같은 내용을 영어로 제공한 C를 통과시킨 것은 합리적이다. C의 불완전한 조건 표현에도 같은 기준을 적용했다. **비교 기준을 C에만 느슨하게 적용한 구체적 사례는 이 범위에서 발견하지 못했다.** 이 결론을 전체108문안이나 일반 의미판정 정확도로 확대하지 않는다.

## E3 — A/B FAIL와 C PASS의 차이가 실제로 존재하는가

Frozen `vendor-quote-v2.txt` line2는 “유지보수36개월과 수량12대는 유지…납기는11월1일로 정정”이다. q2의 사전 content_check에도1180000,36개월/36months,11월1일/11/1/november1이 각각 고정돼 있다. 실제 요청은 “그 설명 기준과 이제 최신으로 정정된 견적만 다시 정리”다.

| 대상 | 실제 표시 내용 | 독립 판단 |
| --- | --- | --- |
| E3q2 A/B 각3회, 총6문안 | 1,180,000원·36개월·설치비·구매미결정은 있지만 납기 날짜 자체가 없음 | 정정된 핵심 필수 사실의 실제 누락. FAIL 유지가 타당하다. |
| E3q2 C 각3회 | `November 1st` 또는 `November 1`,1,180,000 KRW,36-month/36 months를 실제 본문에 표시 | 한국어와 영어의 표현 차이이며 값이 존재한다. 같은 의미의 PASS가 타당하다. 원래 literal 결과는 별도 보존한다. |
| E3q1 A/B/C 총9문안 | 실제 설명한 가격/유지보수 기준, 동가일 때 긴 유지보수 우선, 구매미결정과 v1 견적의 핵심 값을 제공 | PASS에 동의한다. 설치를 “이전에 실제 설명했다”고 허위 주장하지 않는다. C 일부 요약이 설치비 액수를 생략한 것은 q1의 고정 필수값이나 요약 요청의 핵심과 다른 문제로, q2의 필수 정정 날짜 누락과 동일 취급할 근거는 없다. |

대표 실제 trace:

- `basic-dp01-e3-A-r1-1f39fd`, `basic-dp01-e3-B-r1-1599b2`: q2에 날짜 없음. r2/r3도 같은 누락을 직접 확인했다.
- `basic-dp01-e3-C-r1-fa7160`, `...C-r2-11ac89`, `...C-r3-fed7ee`: q2에 각각 November1 표현이 있다.

E3 C r1 q1의 저자 reason에는 같은 episode의 q2 날짜도 함께 언급돼 있다. **q1 PASS를 정당화하는 데 미래 q2는 필요 없다.** 이번 독립 검토는 q1 자체의 표시문과 q1 필수조건만으로 통과시켰다. 판정 숫자를 바꿀 오류는 아니지만 설명 문구를 goal별로 분리하면 더 명료하다.

## E4 — 조건 누락에 같은 엄격도를 적용했는가

원문 `old-research-v1.txt` line2는 같은 monitor와 power-saving 설정을, `old-price-v1.txt` line2는8대·tax·shipping을 명시한다. q2는 두 원본의 “조건 차이”를 요구하고, 고정 marker에도 이 다섯 조건이 각각 있다.

| 반복 | A | B | C | 독립 대조 |
| --- | --- | --- | --- | --- |
| r1 | PARTIAL | PARTIAL | PARTIAL | A/B는 구체적 monitor/절전조건을 누락했다. C의 `specific hardware settings`도 동일 monitor와 power-saving이라는 두 조건을 전달하지 않으므로 C도 PARTIAL이 맞다. |
| r2 | PASS | PASS | PASS | 세 안 모두 같은 monitor·절전설정,8대·세금·배송을 실제 표시했다. C의 operating-cost 한계는 old-explanation line3에도 근거가 있다. |
| r3 | PASS | PASS | PARTIAL | C는 같은 monitor·절전설정은 썼지만8대·세금·배송을 생략했다. 이 경우 C에 PASS를 주지 않은 것이 일관적이다. |

C E4q2r2는 본문이 맞더라도 QA02에서 old-explanation을 지칭 대상에 추가한 오류가 별도로 남는다. 내용의 PASS와 최초 referent exact-set 오답을 양쪽 모두 그대로 두는 것이 현재 정의에 부합한다.

추가 두 경계 문안:

- A E4q3r1의 `long-term power ratios`는 원문의 장기 **전력비**를 다른 물리량으로 바꾼다. 단순 표기 차이가 아니라 핵심 항목의 의미 변화라 FAIL에 동의한다.
- B E4q3r3의 “확인되지 않은 사항은 고부하 작업 전력 및 장기 전력비…실제 구매 계약 여부”는 해당 원본이 확립하지 못한 범위를 전달하는 자연스러운 표현이다. 원문에서 미측정인 전력 항목과 견적이 현재 계약을 입증하지 않는 한계를 보존하므로 PASS에 동의한다. literal 단어가 다르다는 이유만으로 의미 실패로 바꾸지 않는다.

- 현재15의 DP01 QA01/02/03/04/05/06 표는 완료된 BASIC summary의 값과 일치한다. 시간 단위를 초로 표시한 것도 dp01-explanation의 ms 값과 일치한다.
