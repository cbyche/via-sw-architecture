A2는 변경되지 않은 평가기준 원문을 유지해 E3당 원문 재조회1회(전체3회)를 줄였다. 실제 모델 호출은4회/episode로 같았다. 첫 답변3개는 모두 요구 조건을 보존했고, 두 번째 정정 답변3개는 모두 납기 **11월 1일을 누락**했다. 따라서 읽기 감소가 본문 내용 성공의 개선을 뜻하지 않는다. 시간 지표는 runtime의 동결 exporter 결과와 별도 대조하며 이 검토에서 재정의하지 않는다.
