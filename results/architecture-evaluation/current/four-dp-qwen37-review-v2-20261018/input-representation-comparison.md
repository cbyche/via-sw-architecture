**메모리 비교 한계:** 이 진단의 fresh Python worker는 실행 전 prerequisites에서 이전 전체 runs.jsonl을 파싱한다. 측정 초기 Python RSS부터 약694MB이며, 안별 같은 시각 최고 합계는 약703MB다. 이 선행 검증/allocator 부담을 formatter나 후보 구조의 RAM 증가로 해석하거나 기본 QA06와 순위 비교하지 않는다. formatter 복사본 논리 bytes는 별도 중첩 카운터이고 RSS가 아니다. 정확한 allocator 원인 분해는 추가 profiling하지 않았다. 초기/역할/peak 원시는 memory-option-peaks.json에 그대로 보존했다.

단위는 ms·USD다. DP05 QA03는 명시한 receiver-shim HTTP 내부 구간 제외 proxy이며 전체 wall과 함께 읽는다. 논리적 줄 번호 표시는 실제원문에 prefix를 추가한 모델입력 표현일 뿐, 새로운 근거·정답·범위 확대가 아니다. 각 actual call의 변환 전 payload/SHA와 실제 request는 원시 trace의 input_representation_diagnostic에 연결되어 있다. 내용 marker·의미 수동 검토와 host completion은 별도다.
