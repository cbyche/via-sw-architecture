# DP05 C/C1 h3-mail 독립 검토

저자 판정 사전 미노출 6건. 실제 표시 본문 기준 PASS4 / UNRESOLVED2. 자동 QA/host 완료와 별도이며 모호성을 성공으로 바꾸지 않는다.

- C r1: **PASS** — 실제 가격/납기/한계를 정확히 전달하고 추천 미확정을 보존한다. 동률 규칙을 반복하지 않았으나 현재 선택에 오용하지 않았다.
- C1 r1: **PASS** — 가격 동일시만 긴 유지보수 우선이며 현재 가격 상이를 명시한다.
- C1 r2: **PASS** — 동률 전제와 현재 비동률, 서로 다른 가격/유지보수 우위를 구별한다.
- C r2: **UNRESOLVED** — 가격 동점 해소 규칙이라는 명칭과 적용 시 조건문은 있으나, 현재 비동률 선택에서 긴 유지보수 우선 고려/Aster 우위라고 연결한다. 가정적 설명과 현재 권고 사이 해석 모호성. 명확한 full-PASS로 세지 않는다.
- C r3: **UNRESOLVED** — 현재 비동률 선택에서 긴 유지보수 우선 고려라고 시작하지만 마지막에 동률 규칙이고 실제 가격차가 있다고 명시한다. 현재 권고/가정 설명 해석의 긴장이 남아 full-PASS로 세지 않는다.
- C1 r3: **PASS** — 실제 가격/납기/한계를 정확히 전달하고 추천 미확정을 보존한다. 반복하지 않은 휴면 동률 규칙의 오용은 없다.
