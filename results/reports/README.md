# Evaluation Reports

Existing reports preserve historical conclusions and numerical results. They are not current QA-v1 scores unless their result object explicitly identifies `qa-evaluation-contract-v1`, Reference Environment v1, the corpus manifest, all three hashes, architecture commit, DP/alternative/tactic identity, run ID, and evidence mode.

The words “v1” in an older campaign path do not establish QA Contract v1 provenance.
